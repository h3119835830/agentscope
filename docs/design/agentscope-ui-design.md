# AgentScope 界面设计约定

针对 AgentScope 界面工作，先读本文件，再核对当前代码和真实页面。以下来自用户 2026-10-10 的明确要求；后续直接指令优先。

## 信息与导航
- 模块名只放左侧导航和面包屑。页面内部不重复放“Agent”“系统”等大标题，不展示“第二层 · Agent 专属策略”等实现层级标签。
- 保留 Agent连接；会话作为其下方子入口。会话按已连接的 Agent 产品筛选，不按编码/研究等任务类型分类。任务历史位于导航最后。
- 会话目录只展示会话记录；去掉工作区、连接信息页签和工作区详情入口。“查看安全”改为“查看策略详情”。
- 策略列表以结构化记录表展示名称、匹配对象、操作、处置、状态等字段；详情提供可读、可配置的表单。不要把列表改成卡片墙或把全部配置堆在首屏。
- 会话策略区分系统策略、Agent 专属策略、会话策略；会话策略可区分场景生成和运行时生成。提供类型筛选。移除“基于/来源”长说明。
- 关系页展示策略域关系，去掉 Agent 关系和 OS 进程图；系统调用匹配记录与工具拦截 trace 分开呈现。去掉工作区、策略版本和无明确用户用途的执行记录页签。

## Agent 与系统
- 审批记录直接展示 Agent 产品、核验的当前 PID、关联生成会话、状态与提交时间；可按 Agent、会话、PID 搜索并打开对应记录。详情区分当前 PID、提交时 PID、生成时 PID。没有可信会话关联时明确“未关联会话”，不可按名称、PID 或当前选择猜测归属。已知产品不展示 RQ5 等测试登记别名，后台身份和原生用户内容保持原义。
- 审批有独立侧栏入口。助手候选提供可读详情和提交审批。批准只保存决定；已批准待应用须再次显式核对并点击应用，才调用加载接口。详情展示准确范围、前后变更、材料与执行事实，能力来自服务端投影。策略选择使用可搜索的记录表。
- Agent 页是简洁的策略助手对话框。支持在对话中选取模板/候选、补充参数并起草对应 Agent 的策略；目标采用 Agent连接的真实实例身份。
- 系统模块管理系统策略、策略与模板和生成记录。系统策略供全部受控 Agent 继承；策略与模板供指定 Agent 使用。不要“服务与能力”模块。
- 生成记录只读，详情展示保存的需求、匹配、处置和目标，按需展开 DSL；不嵌套旧生成或最终审核流程。DSL 保存校验后转交审批，草案状态与审批中心共用服务端投影。
- 不向客户展示“查看生成说明”、IR 缺口、英文内部阻塞码、原始 JSON、内部生成 ID 等诊断。用简短可操作的提示表达缺少的信息，技术证据放独立验收文档。
- 详情需认真设计密度、对齐、分组、排版和反馈，避免几个大框、编号步骤和大片空白。改后展示真实页面截图或打开可检查页面，不能只口头描述。

## 策略与真实边界

- 2026-10-15 正文参考：策略助手可按需展开“读取工作区参考文件”，通过接口显式读取本实例登记资源中的选定正文。资料回执绑定实例和文件/策略版本，不改变作用范围；修改选择或读取失败需重新读取或明确取消参考。依据以折叠文本呈现，生成结果展示可读资料来源；禁止 computer use、任意 DSL、新模板发布或自动审批/应用。
- Agent 页统一配置入口，以作用范围字段选择全部受控 Agent 或指定 Agent；不再以长期基线/工作区拆分入口。工作区作为参考资料，具体路径由策略参数限定；历史工作区草案保持原归属且只读，禁止自动扩大范围。指定 Agent 无需选择会话；模板参数草案不等于已核验执行来源，实际提交/加载仍走服务端校验。配置表展示范围，继承规则只读；材料与提交快照冻结。
- 会话默认列新增约束；继承的系统/Agent/工作区规则折叠只读，以运行代次加载回执展示实际约束。共享域中未可信关联到本会话的事件不得作为会话命中。
- 策略来源必须核对 ActPlane 源码与已连接 Agent 的实际启动身份；不能把通用 `source AGENT = exec "**"` 当成已绑定具体 Agent。脚本启动器、解释器和受控进程域要分别核对，不能按产品名伪造可执行文件。
- 模板/助手只生成候选；绑定精确目标，带入对应 DSL 编辑器。生成、保存、校验、人工确认、加载、生效和内核拦截是不同事实。
- 策略应用由用户确认。切换 Agent 后不得串用对话、候选或执行范围。不可为得到 DSL 而伪造已验证工作区或绕过服务端校验。

## 2026-10-11 第二步实现补充

生成记录使用只读产品投影，详情展示保存的需求、匹配、处置和历史目标，按需展开 DSL；不嵌套旧生成或最终审核流程。DSL 保存校验后转交审批，草案与审批中心复用同一服务端状态投影。小屏优先显示来源、状态与查看操作。该实现完成源码与隔离预览验收，18003 尚未发布；详见 RFC/REVIEW 的 `20261011-AgentScope-ui-consolidation-step2` 文档。

## 研究编号与产品展示

客户界面的列表、配置详情、补充说明和新生成的 DSL 预览不展示 RQ1–RQ5 等研究编号。模板名称和保护用途是产品标识；内部模板 ID、研究来源和证据仍保留用于兼容与追溯，不改写用户既有 DSL。验收必须打开每个模板详情与 DSL 预览检查可见文本，不能仅以截图或源码检索代替浏览器行为验收。

### 2026-10-14 系统审批与结束操作

系统策略的审批列表用“全部受控 Agent”范围摘要，不枚举所有 Agent/PID；冻结目标数标明“提交时涉及”，详细影响默认折叠。单实例审批保留精确导航。停止生成、拒绝/撤回候选、停用生效文档、删除未生效配置和停止整个 Agent 使用不同入口与说明；停用要先批准再单独应用，删除保留历史，停止弹窗冻结确认身份。中文会话显示名称按精确实例/会话键维护，原始标题保留；改名不恢复冷会话。

## 2026-10-14 会话安全面板实施补充

按用户确认的面板改造，会话详情允许左侧真实会话目录切换；当前已接入约束默认展开，包含系统/Agent 继承和通用结构化配置。DSL 与原始证据按需查看。编辑和停用只提交明确所属层的候选，继承范围在确认时完整展示；不支持独立原生会话配置时显式提示，不伪造局部生效。

会话目录支持独立收起/展开，并在本机浏览器记住状态；收起后释放主面板空间，保留明确的展开入口。窄屏入口横排，不影响当前会话、筛选、审批或策略状态。
