# AgentScope 界面设计约定

针对 AgentScope 界面工作，先读本文件，再核对当前代码和真实页面。以下来自用户 2026-10-10 的明确要求；后续直接指令优先。

## 信息与导航
2026-10-20 全模块宽度要求：总览、Agent连接、会话、审批、Agent、系统和历史档案的主内容区均占满侧栏之外的可用宽度，不再限制为 1180/1280/1440px。助手外框同步铺满，消息正文保留阅读宽度；弹窗、抽屉尺寸保持原约定。系统模板表至少铺满容器，列宽总和更大时表内滚动；窄屏不能撑宽整个页面。
本期以 RFC-20261020-AgentScope-unified-state-central-config 为准：三轴状态由后端投影，8 秒到期前端降级；旧发布记录仅作历史，不作为当前能力说明。
- 模块名只放左侧导航和面包屑。页面内部不重复放“Agent”“系统”等大标题，不展示“第二层 · Agent 专属策略”等实现层级标签。
- 保留 Agent连接；会话作为其下方的独立同级导航项，与其他导航项采用相同尺寸、对齐及选中样式，不使用子菜单容器或缩进（2026-10-16 用户新要求取代原子入口约定）。会话按已连接的 Agent 产品筛选，不按编码/研究等任务类型分类。任务历史位于导航最后。
- 会话目录只展示会话记录；去掉工作区、连接信息页签和工作区详情入口。“查看安全”改为“查看策略详情”。
- 策略列表以结构化记录表展示名称、匹配对象、操作、处置、状态等字段；详情提供可读、可配置的表单。不要把列表改成卡片墙或把全部配置堆在首屏。
- 会话详情优先展示当前经核验的 ActPlane 已加载策略，归属只有系统策略、Agent 策略（2026-10-20 新要求取代旧会话策略分类）。配置名称来自加载快照，表格展示对象、操作／处置和已加载状态；无加载证据不以默认保护说明填充。轮询失败、断连或证据过期时保留最后成功快照供查看，但必须使用中性的“上次核验”状态并明确不代表当前仍已加载。
- 会话仅保留“已加载策略 / 运行事件 / 信息流”；作用范围并入加载摘要。运行事件内部切换“内核命中 / 工具调用”，不合并证据类别。旧关系页链接兼容到加载摘要。

## Agent 与系统
- 2026-10-20 连接列表新要求：只显示 DeepSeek Harness / Hermes 等产品名，取消工作区列，展示有当前新鲜运行证据的 PID，无证据显示“—”。仅列表调整，详情与历史登记名保留；同产品实例不合并，按钮仍绑定实例 ID，PID 不作身份或授权依据。
- 总览保留“安全亮点”场景公告和“使用说明”两个按需入口。场景公告复用当前主线的 12 个示意案例，只读弹窗独立滚动；关闭 / Esc 恢复入口焦点，不改变任何策略或运行状态。
- 审批记录展示用户连接名、Agent 类型、生成会话、配置进度与提交时间。PID、提交/生成时身份和哈希收进技术证据；没有可信会话关联时明确未关联，不猜测。用户已有名字原样保留，同名/缺名追加稳定短标识，不能按研究名称隐藏记录。
- 审批有独立侧栏入口。助手仅起草和只读展示；提交、修改、停用、归档从系统发起。批准只保存决定，应用须再次显式核对。准确范围、影响、材料和能力继续来自服务端权威接口。
- 审批页支持当前筛选结果全选及记录多选：待审批批量批准、待应用单独批量应用、需要处理按能力批量重新校验。先预览内容和范围、一次核对确认，逐项使用原有权威接口并显示结果；同范围冲突不能自行合并。需要处理明确说明失效、未通过、未完成及暂不能应用，无法恢复的记录给出原因和返回配置入口，已处理保持只读。
- 审批记录支持“清理当前结果”和“清理所选”，严格遵循当前状态页签、搜索及勾选范围；清理仅收起列表并保留原始记录和审计，配套“已清理记录”查看及恢复。待审批、待应用、应用中不能直接清理；清理已应用记录不停止策略，不能代替拒绝、撤回或停用。
- 2026-10-20 小步收敛：Agent 移除与会话重复的“当前加载记录”，本步保留“策略助手”“运行事件”；运行事件重复入口留后续处理。旧加载链接进入原实例的会话目录，不自动选择会话、扩大范围或借用其他实例；无准确目标留在助手选择页，历史工作区仍只读。运行前助手只保留一个对话输入框，支持文字和添加 UTF-8 文本文件；不放手工模板选择、新增、编辑或参考工作区入口。“发送”后由助手在本 Agent 有权限的已登记工作区中按需选择资料、选择模板并填参，当前目标最近 3 轮前文分开传递；实际读取材料在生成结果中举证。草案、模板、手工 DSL 与期望配置统一在“系统 › 策略与配置”管理，仍需人工审批后单独应用。所有 Agent 范围只使用提供的材料，不扫描单实例。文件格式与限额失败明确显示，上传正文和实际工作区读取分别举证。
- 运行事件页仅展示已有可信工具结果、拒绝及采集事件，不展示 RQ4/generation 等研发进度块。自动生成/单调增量/热装载是后续方向，本期不实现、不以手工候选冒充。当前加载与新期望配置独立，共享域事件不能冒充单会话。
- 系统模块“策略与配置”是模板、助手草案、手工 DSL 和全部作用范围期望配置的唯一管理入口。主列表仅展示策略模板（含分类）、说明、默认动作、子配置数量和操作；不再单列参数汇总“配置项”，参数定义保留在模板详情中。触发操作是实例参数，主表不展示其固定值。左侧箭头单独展开 / 收起子配置；“详情”默认只读；高级“维护模板”才打开编辑，支持名称、说明、配置项名称 / 默认值和默认动作。参数键、填写方式由执行器固定，暂不支持新增 / 删除 / 改类型，必须明确提示。模板保存为不可变新版本，旧子配置与审批继续绑定原版本，新建配置及助手使用最新版；保存模板不加载运行策略。子记录保留自己的字段、行内审批与停用，助手仍在 Agent 页。
- 系统模板主表表头边界可拖动调整列宽，也可用左右方向键微调；各列有最小 / 最大宽度。浏览器刷新及页面刷新按钮恢复统一默认列宽，不持久化临时宽度。子配置保留自身字段与行内操作，展开区限制在主表可见区域宽度内并保持横向位置；子表独立横向滚动，溢出时在记录下方直接显示可拖动滚动条，也支持键盘滚动。主表与子表分别滚动，禁止覆盖相邻列。
- Git 模板按 commit / push 及相应检查事件分别组织，路径等资源变化使用参数。详情在现有样式内展示真实参数与服务端能力事实，限制按需展开；执行后参数匹配不能宣称为事前阻断。缺少提交内容、远端/分支、单次授权或平台合并检查能力时只保存参数草案，不生成 DSL，服务端禁止提交审批或应用。旧模板版本与配置不迁移；Agent 对话沿用自动配置与生成时快照。
- 生成记录只读，详情展示保存的需求、匹配、处置和目标，按需展开 DSL；不嵌套旧生成或最终审核流程。DSL 保存校验后转交审批，草案状态与审批中心共用服务端投影。
- 不向客户展示“查看生成说明”、IR 缺口、英文内部阻塞码、原始 JSON、内部生成 ID 等诊断。用简短可操作的提示表达缺少的信息，技术证据放独立验收文档。
- 详情需认真设计密度、对齐、分组、排版和反馈，避免几个大框、编号步骤和大片空白。改后展示真实页面截图或打开可检查页面，不能只口头描述。

## 策略与真实边界

- 2026-10-16 自主资料选择：用户只提供场景，策略 Agent 通过受限接口浏览本实例已登记且有读取权限的目录、选择正文，不再要求填写参考路径。实际依据与拒绝记录按需展开，未读正文如实标注；全部 Agent 范围不扫描单实例资料。沿用已有模板、准确目标及人工核对/审批/应用边界，不使用 computer use。此条接续下述前一日手工选择流程，旧 API 保留兼容。
- 2026-10-15 正文参考：策略助手可按需展开“读取工作区参考文件”，通过接口显式读取本实例登记资源中的选定正文。资料回执绑定实例和文件/策略版本，不改变作用范围；修改选择或读取失败需重新读取或明确取消参考。依据以折叠文本呈现，生成结果展示可读资料来源；禁止 computer use、任意 DSL、新模板发布或自动审批/应用。
- 系统是全部受控 Agent 和指定 Agent 配置的唯一管理入口；Agent 只负责起草。工作区用于参考资料，历史配置保持原范围只读。未选择准确目标不能新增，不默认扩大范围。
- 会话默认列当前已加载策略，全部只读；移除生成、添加、编辑和停用入口。系统／Agent 配置仍走原模块与审批流程。同一进程中的工作区和会话共享执行域，不画独立策略节点。共享域中未可信关联到本会话的事件不得作为会话命中。
- 策略来源必须核对 ActPlane 源码与已连接 Agent 的实际启动身份；不能把通用 `source AGENT = exec "**"` 当成已绑定具体 Agent。脚本启动器、解释器和受控进程域要分别核对，不能按产品名伪造可执行文件。
- 模板/助手只生成候选；绑定精确目标，带入对应 DSL 编辑器。生成、保存、校验、人工确认、加载、生效和内核拦截是不同事实。
- 策略应用由用户确认。切换 Agent 后不得串用对话、候选或执行范围。不可为得到 DSL 而伪造已验证工作区或绕过服务端校验。

### 2026-10-14 系统审批与结束操作

系统策略的审批列表用“全部受控 Agent”范围摘要，不枚举所有 Agent/PID；冻结目标数标明“提交时涉及”，详细影响默认折叠。单实例审批保留精确导航。停止生成、拒绝/撤回候选、停用生效文档、删除未生效配置和停止整个 Agent 使用不同入口与说明；停用要先批准再单独应用，删除保留历史，停止弹窗冻结确认身份。中文会话显示名称按精确实例/会话键维护，原始标题保留；改名不恢复冷会话。

## 2026-10-14 会话安全面板实施补充

历史设计（已被 2026-10-20 要求取代）：原面板汇总通用结构化配置、继承保护和 DSL，并允许提交所属层变更。现会话页只读加载快照；旧候选 API 保留兼容，不作为当前列表的数据源。

会话目录支持独立收起/展开，并在本机浏览器记住状态；收起后释放主面板空间，保留明确的展开入口。窄屏入口横排，不影响当前会话、筛选、审批或策略状态。

- 2026-10-20：Git 程序和 commit/push 为模板只读固定事实，新模板参数不允许覆盖，历史版本不能用于新增降级；模板详情和未保存子配置均展示服务端 DSL 预览，动作/默认参数变化更新预览，缺参标明占位。block 明确禁用并说明执行边界。预览不编译/审批/加载，已有 DSL 按保存版本另行只读查看。

- 2026-10-20 全模板实测：详情展示服务端支持、暂不支持、执行边界和按合同绑定的运行/拒绝验证记录；不作为当前实例已启用的凭据。历史 Git 模板与配置只读并由服务端禁用新增、编辑、重新提交/应用，保留审批停用。

## 2026-10-20 会话当前加载视图

移除“查看 Agent 基线”“选择生成策略”、泛化保护横条和执行方式列。会话仅保留已加载策略、运行事件、信息流；作用范围并入加载摘要，只有系统/Agent 两类来源。

遵循记录表＋详情抽屉。名称、标签来源版本、原始 DSL 与编译子句均来自实际加载快照，不借用最新未应用配置。只以核验通过的当前运行身份和同代次／同域／同哈希回执显示已加载；停止、历史、缺失或失配不显示旧绿色行。已加载不等于已命中、执行获准或所有执行机制均受控。详情默认折叠技术证据；旧审批、旧 DSL 和其他模块的配置流程不变。

轮询传输状态与内容快照分离：已有成功快照后，单次读取失败不能清空会话目录、会话详情或 Agent 行；页面继续显示最后内容和读取提示。证据到期仍按 8 秒合同撤销绿色运行/加载声明，过期加载记录改为“上次核验”。切换 Agent、会话、标签或筛选目标时仍清理不匹配快照，禁止跨目标复用。

信息流移除常驻的黄色共享范围说明栏；范围下拉框保持“当前会话／Agent 共享执行域”的明确标识。解释收进“查看范围”旁默认关闭的 ⓘ，点击或键盘展开，采用不挤占图形空间的小浮层；切换范围自动收起。采集失败、证据缺口等真正异常仍显式提示。此变更不改变会话归因、事件查询或标签传播语义。
