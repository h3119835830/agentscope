# ADR：采用分层图与单一配置归属

日期：2026-10-09。状态：采纳于独立原型。

1. 总览展示系统范围连接，会话展示任务范围进程；点击节点逐层定位，避免一张图同时铺开所有进程与规则。
2. 进程父子树和策略域继承图切换展示。普通后代进程可延续所属域，不凭父子关系推断新域。
3. 平台配置、会话实际约束、研究模板和审批记录各有归属。图只定位同一规则表；策略库只查看模板并跳转底线编辑器；审批使用同一提案状态。
4. 复用已验收的编辑器与 catalogue，通过构建器生成新 HTML，保留原有 HTML 作为上一版对照。
5. 独立原型统一标注未连接运行时；以明确空状态展示缺失的执行证据。界面演示状态不能成为真实授权。

取舍：先验证用户的浏览与配置路径；暂不迁移 React，也不引入生产服务连接或加载合同的变化。
