# ADR：连接列表与会话三种关系视图

日期：2026-10-09。状态：采纳于独立原型。

1. 总览采用连接记录表和服务职责列表，替代首版全局图；图仅用于具体会话。
2. 会话提供 Agent 关系、OS 进程、策略域三个视图。进程内 Agent 无独立 PID，OS 树展示共享宿主和工具进程，域图表示配置目标。委派及父子关系均不能证明实际策略绑定。
3. 平台配置、会话约束、研究模板、审批各有归属；节点详情直接展示策略，编辑定位唯一规则表，模板跳转唯一底线编辑器，审批共用提案。
4. 复用已验收编辑器与 catalogue，保留原 HTML 对照。生命周期说明按需打开，避免增加首屏说明负担。
5. 样例始终标注未连接运行时；缺少执行证据时使用空状态，演示状态不能成为授权。
6. 图和记录表共用关系模型；主、子会话身份集中管理，策略表和节点详情共用策略选择函数。共享 PID 按所选关联会话显示配置，不能自动推断专属策略绑定。
7. 按用户后续确认，“打开”采用外部 Agent 实例首页，替代原先强制指定会话导航的要求。按钮明确标为“打开 Agent 首页”，用户在原生界面选择历史会话。绑定与并发按实例管理，主、子会话共用入口；不新建会话，不宣称首页已定位指定会话。未绑定时不可执行。

依据：本机 DSH 0.2.0-rc.2 SessionController、Agent loop、headless 与进程内子 Agent driver。取消首版“每个 Agent 均有独立 PID”的样例表达。

取舍：验证用户的浏览和配置路径；不迁移 React，不改变生产加载合同，不引入新的运行时隔离机制。
