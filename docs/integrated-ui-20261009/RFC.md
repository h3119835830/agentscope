# RFC：合并安全配置与会话运行视图

日期：2026-10-09。状态：独立 UI 原型；生产接口未变更。

五项导航为总览、会话、审批、策略库、系统。安全规则是会话详情默认页；平台底线属于系统。研究模板不等于默认授权，平台草案不等于现有会话快照。

总览用记录表展示实例、关联会话数量与连接观测；名称、ID、Agent 和工作区由会话目录及详情负责。会话内分别展示 Agent 委派/工具调用、OS 父子进程、目标策略域继承，每类可切换关系图和记录表，复用同一关系模型。节点详情默认直接展示策略，另一个页签展示会话元数据；编辑仍定位同一规则表，不增加第二个编辑器。

DSH Web 0.2.0-rc.2 的 Session/Agent 是逻辑对象，宿主可承载多个会话；进程内子 Agent 不默认拥有独立 PID。回复后的 idle、对象释放、工具进程退出和宿主退出分别表示。一次性 headless 完成本轮保存后退出。只读代码依据见 README。

目标域图是拟配置模型。共享 PID 上的会话与子 Agent 不因模型自动获得独立 OS 域；正式接口必须提供可信执行归属及实际绑定证据。未核验的节点显示“未验证”，不展示为安全已生效。连接时效、实例身份、会话绑定、策略加载及探针分别核验。

提案与全局审批共用记录；模板库与底线复用编辑器。反馈草案按会话隔离。源 catalogue 的 15 类模板、13 条来源与既有能力限制不改变。原型无 API、进程发现或规则加载。

原生打开与安全视图解耦。平台不承载聊天内容，原生适配器按 `{instanceId, sessionId}` 提供 `inspect`、`resume(ref, revision)`、`reconnect` 与 `resolveSessionEntry`。这只是新增客户端合同，未增加生产 API。`inspect` 须确认支持会话导航；恢复只针对确认停止且通过安全许可的执行端，后端负责权威状态、并发和授权。入口须回传相同身份及 `scope=session`，不可退化为实例首页或新建会话。

控制器在用户点击时预开新标签，禁用 opener；拦截弹窗则不调用后端，并发点击合并。失败关闭本次空白标签，释放重试状态；认证 URL 只用于临时导航，不写入证据。样例未绑定适配器，按钮保持禁用。

当前 DSH 实例接口与插件只有根入口，无原生会话深链接；不声称本轮已真实打开指定会话。需要原生客户端导航能力与旧会话恢复合同，随后核对选中 ID 和历史连续性。当前实例共享策略事实与拟配置的会话域模型分别表达，不能用该 UI 绕过运行时隔离缺口。
