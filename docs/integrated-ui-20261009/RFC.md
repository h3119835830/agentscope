# RFC：合并安全配置与连接视图

日期：2026-10-09。状态：UI 设计原型验收通过；生产接口未变更。

五项一级导航为总览、会话、审批、策略库、系统。安全规则是会话详情默认页；平台底线属于系统设置。研究模板不等于平台默认授权，平台草案不等于现有会话快照。

总览图展示 Agent、会话与工作区的关联；选中会话进入任务范围的运行关系。进程树使用父子关系，策略域图使用继承关系；二者通过节点所属域关联到同一规则表，不增加图内编辑入口。

服务链路是独立视图，展示控制 API、Pi、Broker、ActPlane、DSH 与 OS 层职责。原型只使用明确标注的样例数据，既无 API 请求，也无进程发现。正式实现应分别采集连接观测及其时效、实例身份、会话绑定、策略版本/加载与实际探针证据，不从其中一项推断其他状态。

会话提案和全局审批引用同一记录；平台底线和模板库复用同一编辑器。反馈草案按会话隔离。源 catalogue 的 15 类模板、13 条来源记录与既有安全能力限制不改变。
