# AgentScope 合并界面原型

日期：2026-10-09。状态：可点击的独立 HTML 设计原型，未接入真实运行时。

入口：`docs/prototype/AgentScope-合并界面原型.html`。支持直接打开，也可由静态 HTTP 服务预览。

## 页面分工

| 入口 | 内容 | 配置归属 |
|---|---|---|
| 总览 | 当前连接图、服务链路图 | 只展示关联，点击会话进入详情 |
| 会话 | 会话列表；安全规则、运行关系、工作区、执行记录、策略版本 | 继承只读，本地规则保存草案 |
| 审批 | 所有会话共用的变更记录，支持按会话过滤 | 会话入口和审批入口引用同一条提案 |
| 策略库 | 15 类模板与研究来源 | 模板查看后跳到平台底线的同一个编辑器 |
| 系统 | 安全底线、服务与能力 | 平台默认配置与新基线草案 |

模块名只出现在导航。反馈、DSL、能力边界和研究证据进入详情，不在首屏重复铺开。

## 可以直接演示的路径

1. 总览点“登录表单修复”，进入会话执行进程树。
2. 点“测试 Agent”，看 PID、父 PID 与策略域；点“查看约束”，进入 D-A1 的同一张安全规则表。
3. 运行关系切到“策略域”，查看规则继承模型；执行进程父子关系与域继承分别呈现。
4. 会话点“待处理”，进入统一审批记录；存为待审草案后，两个入口的数量与状态同步更新。
5. 策略库搜索 SSH，查看模板，再到平台底线配置；改动平台草案后，现有会话继承快照仍保持 v0.1。

所有连接、PID、域、工作区与会话均为样例；图不执行进程扫描。D0 是继承模型的示意来源，不能据图认定运行时已经创建了全局 D0。连接观测、策略加载与实际保护分开表述；执行记录保持空状态，没有编造内核事件。
