# BUG：独立安全页缺少整体定位

日期：2026-10-09。

## UX-002：两页原型不能展示完整平台路径

复现：上一版独立原型只有“会话安全”和“平台安全底线”入口；与完整原型的总览、审批、策略库等模块分开，无法在同一壳层演示从全局连接到会话进程，再到对应约束的路径。

本次在新合并 HTML 中提供五项导航，将底线归入系统、约束归入会话，补齐全局连接图及节点跳转。审批复用提案记录，模板复用底线编辑器，避免重复配置。35/35 项交互与响应式验收通过；上一版原型仍保留用于对照。

未发现新增运行时问题，因为本轮未运行生产服务或实施安全规则。现有编译支持限制与已记录的内核保护缺口没有被本轮关闭。
