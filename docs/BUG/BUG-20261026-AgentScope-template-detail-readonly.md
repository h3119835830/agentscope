# BUG：模板详情只剩配置项标题

日期：2026-10-26。状态：源码修复、隔离验收通过；正式入口尚未发布。

复现：系统 → 策略与配置 → 环境凭据文件 → 详情。参数区域只显示名称，没有 .env、默认操作、可选动作、反馈原因和 DSL 预览，正文贴左边缘并留下大片空白。

根因：TemplateDefinitionDialog 的只读分支只渲染 label 与可选 help，默认值、选项和服务端预览未接入；该分支也没有正文边距样式。浏览器实测原正文 padding 为 0，并非内容被滚动区域裁切。

修复：补齐同版本模板参数和反馈信息，复用服务端 DSL 预览结果；增加正文边距、分组和响应式布局。

验收：429/429 前端测试、Vite 生产构建通过；37 个模板逐个打开详情及 DSL 入口，含 17 个完整预览、16 个缺参预览和 4 个不支持提示；640px 窄屏无正文横向溢出，Esc 关闭并恢复入口焦点。维护入口固定命令和退出码 0 保持正确。证据见同名 REVIEW。
