# 审批列表缺少清理操作

## 复现

已处理与旧异常记录持续显示，用户不能一次收起当前筛选结果，也不能勾选后清理。批量审批与重新校验不解决历史记录整理需求。

## 修复

增加清理当前结果、清理所选、已清理记录和恢复。清理持久化可见性标记并保留所有原始记录及审计。未完成的审批或应用不能被直接清理。预览后状态变化、旧请求重放、重复请求及错误身份由接口拒绝或幂等处理。

## 验收

隔离数据库验证一键清理、多选清理、刷新持久化、所选恢复和批量恢复。清理与恢复前后，配置、审批和应用等 8 张权威表完全一致。状态漂移、权限、请求重放、清理已应用记录不改变实际策略均有自动化覆盖，完整结果见同名 REVIEW。
