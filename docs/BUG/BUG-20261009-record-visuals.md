# 记录模块缺少状态配色和表格层次

日期：2026-10-09。状态：已复现、已修复、UI 验收通过。

## 原始问题

在 18003 点击 Agent连接，连接情况与安全覆盖仅显示普通文字，字段、表头和记录区域层次弱，与总览已有的标签风格不一致。根因是共用配色只覆盖既有 tag 元素，后续记录值没有使用标签组件，表格主题也缺少明确表面。

修复：接入共享 RecordBadge 与记录作用域样式，覆盖连接详情、安全规则、连接历史及任务处理结果，同时统一工作台、策略库和持久治理的记录表面与字段底色。

## 验收期间复现的问题与修复

1. 423px 手机视口：操作列被压缩，按钮文字逐字换行，行高达 273.53px。修复操作列最小宽度和按钮不换行后，行高为 89.19/88.69px，页面宽度仍为 423px，表格在容器内滚动。
2. 1146px 桌面视口：初版最小操作列过宽，表格 997.19px 超出 878px 容器，右侧按钮露不全。调整操作列宽度和紧凑窗口单元格间距后，最终表格与容器均为 876px；1280px 下也完整显示。
3. 正式验收脚本初次使用 record-fields 选择器，实际详情为 task-fields，导致字段底色检查误报。修正为详情面板内 dd 后，8 个字段实测均为 rgb(246, 248, 252)。此项为验收选择器错误，没有修改产品逻辑。
