用户随后明确授权“压缩路径、把文件夹放在其他位置或改名”。本轮采用真实短执行根，不再等待前述父目录级保护澄清，也不扩大保护范围。源工作区与旧失败上下文仍保留；通过新的关联恢复快照重新生成 Pi 候选。

全量检查发现现布局最长资产路径为 78 字节，不止 rate_limiter.py 的 73 字节。Rust set_pat 为 64 字节缓冲区保留结尾 NUL，因此安全可表示长度实际为 63 字节；Python 能力合同此前宣称 64 字节，存在边界截断风险，整改同步将共享上限收紧为 63，执行器 ABI 不变。
