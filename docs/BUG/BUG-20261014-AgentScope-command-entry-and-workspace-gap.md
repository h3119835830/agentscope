# BUG：连接入口不能配置命令，原生工作区投影不完整

复现：18003 添加连接只要求产品及资源目录，后台固定启动命令；未提供可配置终端入口。18020 的受控文件视图仅包含旧映射，用户无法选择新桌面项目；会话汇总无法展示刚在 DSH 添加且尚无会话的工作区。

原因：执行启动配置、文件授权范围和原生工作区登记在产品入口中混合。连接适配器只支持固定原生网页命令；工作区呈现依赖 session 元数据。

修复：独立命令配置及网页/PTY 入口，保留旧连接行为；资源访问范围移入安全配置，默认启动目录只读；原生 registry 独立投影，按实例/workspace ID 在受控权限内列出目录和文件。命令并发修改和审批快照增加 launch_hash；已有 DSL 时阻止资源重排造成短路径规则静默换对象。

验收状态：进行中。单元及真实隔离进程通过的项目见 REVIEW；发布与浏览器证据完成后闭环。测试首次假设 deny errno=13，但实际 ActPlane 返回 EPERM(1)，并有根拥有的内核阻断记录；验收判定应接受 EPERM/EACCES，同时要求实际阻断事件，不能以文件不存在或模型口头拒绝判断。

浏览器并发复现：终端持续 poll 与实例观察争锁时，原非阻塞 inventory 将健康连接投影为 starting；终端 HTTP 路由又以观察快照 active 作为授权，导致误断开。修复为短时等锁，必要时以受信 PID/domain/protection 核验更新已有元数据；无当前保护时仍显示未知。终端操作验证保存的 gate/代次/策略身份，再由 Broker 实时核验保护及 admission gate，拒绝旧代次和冻结域。补充两种保护状态的并发观察回归与浏览器持续输入验收。

边界复核：排序资源变更还会影响 DSH 持久化的 `/w/N` 工作区路径，未配置 DSL 也不能静默换对象。服务端已拒绝重排、替换和移除，只允许稳定末尾追加；界面明确此限制，回归覆盖原生别名不换对象。
