# BUG：连接页重复标签及工作区关联不可见

状态：已修复并验收，详见同名 REVIEW。

## 已复现

连接页同时在侧栏、顶部面包屑与大标题展示 Agent 连接，额外展示执行后端胶囊状态。原生和受管实例纵向分为两张卡片，即使受管实例为空仍占据页面。工作区只显示文件读取与新建任务入口，已有 session_ids 和任务 workspace_id 关联没有被展示。

## 修复

移除当前连接模块的重复可视标题和顶部状态胶囊；状态作为字段展示。合并实例表，新增工作区关联记录与只读策略记录，保留原文件及任务流程。来源任务精确匹配工作区 ID。策略记录包含完整操作对象，显示处理结果，不显示 V1/V2 或伪装成当前保护状态。

## 验收要求

覆盖真实工作区的一条原生会话及两条来源任务；策略阶段、任务切换、文件刷新、搜索、关闭恢复焦点、刷新和历史导航；检查桌面与窄屏没有整页横向溢出。测试同名同路径不同身份不串关联、普通收紧不误渲染为禁止、历史加载不误报当前生效。

前端 130 项及浏览器 15 项检查通过。验收另复现 320px 窗口因 body 固定最小宽度造成 15px 页面溢出，移除此下限后列表及抽屉均复验通过；首次失败与修复证据一并保留。
