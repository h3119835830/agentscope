# BUG：隔离预览遗漏审批接口造成跨页矛盾

日期：2026-10-26。状态：隔离预览修复并验收，生产记录未删除。

现象：助手显示发布清单配置已应用，切到审批却为空。原因：preview_policy_response.mjs 未接入 /api/console/approvals 及详情，统一 API 兜底返回 200 与空列表；助手使用的历史状态本身有真实回执。

修复：引入真实只读审批列表/详情，启动时核对精确配置与版本；未知接口改为明确 501，不再假装无记录。审批完成记录在“已处理”显示，已清理数量真实为 0。所有写接口继续禁用；未通过新审批或伪造数据补齐。

闭环：426 项测试通过；浏览器打开对应记录，列表与详情均为已应用；正式接口前后稳定，关联配置第 1 版未变。详见同名 REVIEW 和独立验收数据。
