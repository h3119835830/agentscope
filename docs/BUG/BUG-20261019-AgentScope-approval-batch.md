# 审批列表缺少批量操作和异常分类说明

## 复现

待审批、待应用及需要处理列表只有查看详情入口。多条记录必须逐项进入详情处理，列表也没有解释“需要处理”包含哪些状态，无法直观看出能否重新校验。

## 修复

增加记录多选、当前筛选结果全选和批量预览。待审批批量批准，待应用批量应用，需要处理批量重新校验。增加具体分类说明和记录原因，不能恢复的记录显示跳过原因及返回所属配置入口。已处理记录继续只读。

## 验收边界

验证筛选/页签切换清空选择、核对前不提交、批准与应用分开、逐项候选与范围校验、同范围冲突、部分失败、请求幂等键、重新校验计划绑定、无法读回状态不声称应用成功。隔离浏览器验收只使用合成配置和模拟特权执行，不改变正式审批决定。完整记录见同名 REVIEW。
