# BUG：历史运行时页面遗漏 Hook 触发点总览

状态：已复现，修复与验收中，2026-10-08。

旧工作台运行时列表有“触发方式”入口，显示 Hook 来源和处理链。切换到独立历史档案后，主列表没有消费旧 `hook.events/sequence`，因此用户看不到该总览。

真实页面复核：历史任务运行时列表没有触发方式入口；打开单条策略的上下文，仍能在“触发与上下文原始字段”看到“原生上下文变化”、轮次、修订和 observations。问题是展示遗漏，不能据此认定实际触发记录全部丢失。

整改：恢复运行时可见 Hook 模块；分别展示当前机制定义与任务实际触发；只读任务投影、分页、去重与缺失材料提示；保留已有逐句 DSL 和加载事实。
