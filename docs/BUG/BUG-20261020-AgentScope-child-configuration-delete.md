# 未使用子配置缺少行内删除入口

日期：2026-10-20。状态：已修复并通过正式 18003 静态发布与浏览器复验。

## 复现

系统 → 策略与配置 → 展开环境凭据文件 → 已拒绝子配置。原操作列仅详情、提交审批、查看审批、停用；停用不可用，未使用记录持续占据列表。

## 原因及修复

统一子配置表未使用后端已有 archive 能力；停用按钮不区分是否存在已应用版本。本次有应用版本时保留停用，无应用版本时提供删除；审批中等状态禁用删除并说明先处理审批。删除确认明确只移出列表、历史保留；不物理删除、不改执行权限。

## 验收

372 项前端测试、44 项相关后端测试、生产构建通过；浏览器合成记录确认/取消及 API 删除后刷新已验证。旧版应用、新版拒绝的后端删除请求返回 409；精确作用范围及审批历史保留。正式页面已出现删除按钮，确认弹窗核对后取消，未删除正式记录。发布提交 `58f7c21`，详细证据见同名 REVIEW。
