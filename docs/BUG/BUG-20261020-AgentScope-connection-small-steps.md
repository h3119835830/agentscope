# 连接布局及打开入口问题

## B1：已有连接表单未应用紧凑布局

- 复现：18003 → Agent连接 → 配置 → 连接设置，全部字段纵排，较添加连接占用更多空间。
- 原因：既有紧凑 CSS 仅匹配 `.instance-add`，不匹配现有连接抽屉；不是该紧凑布局提交未合并。
- 修复：为连接设置面板增加限定选择器，不改变字段或行为。
- 验收：388 项前端测试、构建、5 项发布防串包测试通过；真实浏览器 1280px 双列 / 600px 单列，均无表单横向溢出。添加连接、资源页签、关闭/Esc、禁用行为正常。
- 当前：源码和只读浏览器验收通过，待 CSS-only 发布；结果见 REVIEW。

## B2：未知状态连接只剩“查看入口”

- 复现：两个 DSH 连接显示状态未知、未核验、查看入口；配置抽屉没有打开按钮。
- 数据：两个受控实例 `connected=false`，无当前观察时间；数据库仍有 `gate=open`。以服务身份查询 Broker inventory 成功，但仅返回 native-dsh 和 installed-wsl-hermes，没有这两个受控实例。
- 原因：`canStart` 新增“运行状态明确 stopped”条件，未知状态既不可直接打开也不可启动；界面回退为查看入口。Broker 缺失实例的更早原因尚未证明，不能归因成此次 CSS 或信息流改动。
- 风险：旧 start 实现恢复未知状态时可能先停止登记执行域，不可静默调用。
- 当前：已获用户同意单独修复打开交互，不自动重启；本次 CSS 发布不包含该修复。不得将此项标记修复完成。
