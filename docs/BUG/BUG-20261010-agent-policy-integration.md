# BUG：模板与会话真实接入问题闭环

日期：2026-10-10。

## 产品筛选在单个结果时消失

复现：会话选 Hermes 后，接口只返回该产品连接，旧条件 connections.length > 1 隐藏整个选择器，无法切回 DSH。修复：始终保留产品选择器，独立读取真实连接目录作为选项。回归测试覆盖单产品与映射未知，真实浏览器从 Hermes 切回 DSH 通过。

## 未取得映射被当成零会话

复现：空记录且 count_complete=false 时，外层空表文案仍显示没有匹配会话。修复：显示尚未取得映射、数量未知。测试与真实 Hermes 接口反馈通过。

## JSON 字符串转义不等于 ActPlane 转义

代码核对：真实词法器保留反斜杠，不能用 JSON 转义安全表达内嵌引号。模板参数现拒绝引号和反斜杠，以及控制字符、相对路径和目录穿越，避免候选语义改变。自动测试覆盖。

## 模板转入替换已有 DSL 或混淆目标

原型到真实编辑器需携带精确目标、模板 ID/UID 和文档。已实现 fresh GET + 追加已有文档，系统层/其他实例/仅观测目标拒绝。重复 ID、文档数和总字节数受限，内容/说明/名称改变或当前版本变化使旧校验失效。自动测试及 DSH/Hermes 浏览器交接通过。

## 历史 RQ1 编译成功被误用

新增实际解析/编译测试证实 RQ1-CHECK 的 argv block 当前不受支持。模板保留原始研究结果但不继承 compiled；界面标明运行时限制，真实候选保持 invalid，不能应用。不是通过提示词或文本包装将失败标为成功。


## 首版策略与模板布局偏离记录要求（已修复）

复现：系统模板页展示六张纵向卡片及常驻表单；Agent 助手重复同一目录。结果是列表字段不可对比、Agent 首页拥挤。修复：模板与配置改为记录表；详情抽屉按三个配置分区与三个页签组织；Agent 首页换为单一对话框。通过组件交互测试、真实表格/筛选/详情/导入验收。

## Agent 关联上下文被误识别成生成参数（已修复传递方式）

验收批次 `184d2eb5efa34800a32f7f901771966b`：把 agent_id/product/resources/scope 拼入策略输入后，结构化生成器将这些字段列为 required_parameters。修复：原句只提交用户约束和此前用户需求，精确 Agent 归属保留在会话指针及导入动作；不加入针对本条规则的特殊提示词。修订后的批次 `762d4987cdb9430aa0ef91120711f1db` 已无这些人工引入的绑定参数；原失败记录保留。

## 生成服务尚无 Agent 层的环境适配合同（仍待后续）

实际代码 `history/pipeline.py:generate_policy_artifact` 的结构化生成分支要求服务端 resolved_context.workspace；现有 registry 仅能根据 task_id 核验任务环境。修订后批次仍为 requires_context / needs_adaptation，未产生 DSL。此次 UI 用客户可读提示要求补充执行范围，并在同一助手对话内提供“选择策略”模板配置入口；没有把注册资源或聊天路径冒充可信任务快照，也没有放宽校验。真实自然语言到 Agent 环境适配的完整闭环尚未验收，不能写成助手 DSL 生成成功。

## 重复模块标题与内部诊断进入客户主流程（本轮修复）

用户截图复现 Agent 大标题、“第二层 · Agent 专属策略”、查看生成说明内的英文/IR 阻塞码。修复：模块名只保留导航与面包屑，目标选择移入对话框；删除内部生成诊断及生成 ID 的主流程展示。真实浏览器确认首屏无重复模块标题，输入区可见。

## 系统配置过度分块与继承表单间距（本轮修复）

用户否定上轮三编号分区的布局。重做为紧凑表单+实时配置摘要，移除编号步骤及重复说明。浏览器发现全局 label margin/input margin 叠加导致过大空白；局部重置继承间距，不改变全站业务表单。1280×720 首屏可以读取保护路径、反馈与固定操作栏。

## 模板候选使用通用 source AGENT（候选构造已修复，执行验收未完成）

复现：系统/Agent 模板候选固定 `source AGENT = exec "**"`，无法解释对应连接身份。根据 ActPlane lower_exec 和本系统真实 runner 合同，DSH 映射 node，Hermes 映射 python；系统集合去重，Agent 精确目标导入。未知来源不静默回退，生成 DSL 的 AGENT exec 声明在导入前重新绑定目标；其他 provenance source 不移除。新来源经隔离的真实 AST/编译器校验，但尚未加载到当前实例，不宣称标签传播或内核拦截验收通过。

## 对话选模板后追问缺少候选配置上下文（本轮修复）

模板候选只显示在对话而未带入后续生成上下文，会让追问丢失已选路径。现在最近四轮中已配置候选的保护对象、操作、处置与反馈作为显式候选上下文；保留未应用状态，不把浏览器输入变成服务端核验。测试覆盖真实路径进入后续输入、最新需求优先和不注入 Agent 内部身份。

## Agent 层环境适配（保持未关闭）

会话内模板选择可直接构造候选并交给现有 DSL 校验流程；自由描述生成仍受历史生成服务的服务端任务环境合同约束。选择模板不等于补齐任意自由描述策略的可信上下文；本轮没有为获得 DSL 放宽该合同，也没有新增原生 Agent 聊天或会话级应用接口。
