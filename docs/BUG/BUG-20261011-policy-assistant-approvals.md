# 助手候选难以查看且缺少审批入口

日期：2026-10-11；状态：已修复并验收。

复现：在 Agent 策略助手生成需求后，结果卡片重复整段请求；选择策略弹出小型原生菜单；未完整生成的候选缺少结构化详情；可用候选只能进入 DSL 编辑器处理；侧栏没有独立审批入口。已校验草案重新打开时未恢复 preview，影响后续明确确认操作。

原因：助手直接展示生成声明，策略选择使用原生 select；DSL 提案生命周期未投影为客户审批记录；编辑器仅初始化文档没有初始化已验证提案。

修复：候选按实际 IR 提取保护对象、操作和处置；新增详情抽屉和记录式策略选择；新增 DSL 审批表和详情，提交与批准分离；恢复已校验草案的 preview，基线过时禁止确认，移除策略的空候选保持原义；新增拒绝提案接口且不触发运行操作。测试发现隐藏实例审批详情未转换为 404，同步修复。

验收：214 项前端测试、945 项后端测试通过（52 跳过），构建通过；真实页面完成候选查看、搜索、复用待审批、审批详情恢复、目标隔离和窄窗口验证。对比部署前后 Agent、DSL scopes 和全部提案状态完全一致。截图与边界见同日期 REVIEW。用户仍自行决定批准应用。
