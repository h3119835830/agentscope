# 策略生成仍要求用户填写资料路径

日期：2026-10-16。状态：源码与隔离验收已修复，正式更新结果见同日 REVIEW。

## 现象与根因

用户已经描述业务场景，助手仍显示工作区选择/参考文件路径输入，需要用户自行找到并填写正文。原实现只接入安全读取回执，模型在一次生成前收到用户选好的正文，没有可选目录/读取接口与多轮结果反馈。这是 Agent 工作流能力缺失，不是模型不智能。

## 修复

主界面移除必填路径流程，场景生成默认启用受限自主资料选择。服务端提供精确目标工作区、降权目录浏览、已列出文件正文读取，并把实际结果/拒绝反馈送入下一轮。全部来源回执绑定子配置；未知工具、跨目标、任意 DSL、新模板或预算超限不能保存配置。批准与应用仍由用户决定。

累计文件/字节额度跨调用和工作区共享，读取程序校验剩余字节额度；同键并发短事务只启动一次生成；最终模型响应过期也不保存。保留原手工读取 API 供兼容，但不要求用户先填路径。

## 关闭依据

真实模型/隔离 HTTP 在无用户路径的中文订单日报场景下，自行浏览并读取资料，从正文获得随机员工名册路径，填写 FILE-READ v2；4 轮、6 次接口、4 文件，未启动 Agent 或应用策略。文件改变后旧结果 409。后端 1,353 项、前端 310 项与构建通过。正式 API/UI 更新及运行实例保护比较仍需记录后关闭发布状态。
