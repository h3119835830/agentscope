# BUG：单条策略记录展示完整包及控制台连接页

日期：2026-10-06。状态：已修复并复验。

| 复现 | 原因 | 修正 | 验收 |
|---|---|---|---|
| 语义指导/no_change 的 DSL 出现所有策略 | 作业级记录直接展示完整编译包/规则块 | 逐句身份，按实际 target_pattern/clause_text 映射；语义指导无 DSL | 真实 acceptance.txt 仅两子句；只读指导无代码 |
| 同一 source_text 带入其他文件 | 以整条规则块而非编译子句投影 | 仅相关 clause，并记录行号/哈希引用 | 双目标单测排除相邻对象和其他底线 |
| 语义指导继承同作业 OS 已加载状态/增量 | 共用作业 receipt 和 delta | 单条语句隔离加载及增量 | 混合 restrict + semantic 回归通过 |
| 无识别语句的评估混入策略列表 | 列表单位为作业 | 只展示语句，后台保留计数 | 无注释评估默认不显示 |
| 同作业多个语句可能跨页丢失 | 游标只有作业 rowid | rowid:statement-index | 20 条按 12/8 分页完整 |
| 新标签要求重新连接 | 现场收到成功 local-browser-close；DB 会话被显式撤销 | 恢复可信本机浏览入口；锁按钮明确文字；close 增加审计 | 现有用户标签恢复、刷新/API 重启保持登录 |

连接页不是 DSH 断线；未删除认证、自动重开显式锁定或改动会话 TTL。并无证据把现场问题归因为跨端口 cookie 覆盖。本次不做这种推测性修改。

未写专门场景提示词。修正在记录模型、来源/子句映射、逐句状态以及页面动作表达。
