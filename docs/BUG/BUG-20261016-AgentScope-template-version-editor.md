# 模板主表误展示参数值、详情误用展开（2026-10-16）

用户截图与代码复现：主表触发操作值来自模板初始值，但子配置可改变该参数；详情与箭头重复控制同一展开状态，实际没有模板编辑接口。此前将模板与实例参数混合，且误把详情当展开操作。

修复：移除主表触发操作值列；箭头只展开子配置，详情打开独立模板编辑。新增持久化版本接口，编辑名称 / 说明 / 配置项名称与默认值 / 默认动作，不覆盖旧版本或旧子配置。既有 renderer 改用已校验的默认动作，保证实际 DSL 与保存值一致；旧定义的默认渲染结果不变。参数键 / 类型及任意执行定义不开放修改，UI 明确能力限制。

闭环：323 项前端、1376 项后端全量回归、构建及隔离浏览器保存 / 刷新 / 旧新子配置版本分离通过。正式环境只发布功能，不用正式模板做保存测试；18003 结果与截图见同名 REVIEW 证据目录。
