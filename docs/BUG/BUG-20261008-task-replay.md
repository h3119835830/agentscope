# BUG：旧任务回放入口与原工作台展示能力难以找到

状态：已复现问题修复并通过验收；截图路由现象仍未复现。

## 已复现

任务历史默认已结束筛选只返回已结束记录，旧 RQ5 失败任务 d5e21e674b464d16 未记录 ended_at/closed，因而被隐藏。当前库已有 117 个 OpenAgentSafety 任务，字面搜索 RQ5 不匹配其来源字段。旧记录存在，不能据此判断历史被删除。

档案采用侧边抽屉和简化栏目后，原工作台的任务选择、完整执行监控及命名明确的文件证据、生成过程和版本入口不够可发现。用户明确要求恢复以前完整模块展示模式。

历史 URL 保留当前 task 参数时，隐藏的 ManagedWorkbench 仍挂载并轮询当前接口；AgentWorkspaces 的 active 标记也未阻止隐藏组件的查询。已改为历史页不挂载这两个在线组件，并暂停主页面全局轮询。切回工作台仍使用原 task 参数，查询历史不更换工作台任务。

真实桌面验收从历史列表靠后记录打开全页回放，复现沿用列表 scrollY 导致任务标题和选择器位于屏幕上方。回放进入时须回顶部；返回列表恢复原搜索、页码与滚动，不能把二者混用。

## 修复

历史列表增加全部旧任务和 OpenAgentSafety 快捷筛选；选任务进入全页只读回放，保留任务选择和原工作台式主栏目。策略逐句 DSL、独立整包、审计来源及历史域版本继续保留，不回退到父作业整包冒充逐句 DSL 的旧错误。
