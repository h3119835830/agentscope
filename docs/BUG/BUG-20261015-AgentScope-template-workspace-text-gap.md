# 模板助手不能引用工作区正文

日期：2026-10-15。状态：已修复并发布；模块、隔离 HTTP/真实模型和正式 HTTP 核对通过。

## 复现与原因

统一 Agent 策略页原本只能浏览原生目录，模板助手只接受用户要求与手工补充材料；浏览文件元信息不会把正文提供给模板生成。因此不能声称已经按工作区任务事实配置参数。

## 修复

提供精确实例已登记资源目录与受限正文读取 API，返回冻结资料回执。助手以回执取得脱敏正文和系统/实例约束，只允许填写已发布模板参数。生成、提交、应用时校验资料，变化时拒绝继续；不启动或重启 Agent，不自动批准或应用。

## 关闭条件

真实 HTTP 能读取允许的中文资料；真实模型从资料得出可核验参数；禁止/越界/跨实例/链接/敏感材料/超限拒绝；文件变化失效；未知模板/DSL 拒绝；旧来源失效仍允许明确停用；正式发布保留 Broker/Agent 身份和策略，文档与接口事实一致。

## 验收结果

132 项相关后端、300 项前端及生产构建通过；真实文件读取与真实模型完成隔离验收。正式健康、HTML/资产、参考目录 API 核对通过，Broker/Agent 身份与策略不变。遵照用户要求未使用 computer use；未进行浏览器像素验收，也未在正式环境生成或应用策略。详见本次 REVIEW 及证据目录。
