# 连接观测无法跨 API 重启和实例结束保留

问题确认：原实现只有 `Observer.rows`，后台刷新替换此字典，snapshot 会剔除已结束受管实例。工作区来源和任务档案虽保留部分身份，但不能回查完整连接过程；清单中已有的历史工作区来源不等于连接历史。

修复：追加元数据事件与只读分页接口；人工检查和状态变化落库，结束绑定 / 移除登记保留生命周期回执；持久化回查不恢复绿色在线状态。生命周期补记使用持久化最后事件，即使内存已被读取接口剔除或 API 已重启仍可关闭绑定。

另覆盖恢复边界：控制接口不可达时不写“离线”；短时未知后的新进程代次仍识别为实例重启；存储失败不把已核验连接改成未知。

独立回归包含去重、每次人工检查、代次变化、重启保留、历史不具授权能力、只读查询、实例间游标隔离、鉴权、冻结来源关联、退出绑定和存储故障。详细验收状态见对应 REVIEW。并行服务部署发生覆盖后，停止本分支部署操作，统一整合的浏览器验收尚待完成。
