# BUG：旧运行时语句被生成批次淹没与 Pi 长路径失败

状态：根因已复现，修复已部署，真实验收见 REVIEW。

## 已复现

f39a5521abb04104 混合运行记录 41 条，其中 39 条无语句作业和 2 条真实语句；d5e21e674b464d16 为 42 条、37 条作业和 5 条真实语句。首屏大部分显示“本次未记录策略语句”，使已保存的真实语句难以找到。旧指导作业未保存独立 guidance 字段，不能补造指导语句。

失败任务 0dae79b573f14bca 的启动作业 d5cb5fcc 路径达 77–92 字节。来源快照保留 workspace/transaction-verification-service 嵌套，超过 ActPlane 的 64 字节限制；Pi 补齐读取回执后仍因精确路径被拒绝。RPC 续接状态又把最后工具显示为 rpc_lifecycle，未传播业务诊断/剩余验证预算，最终显示笼统 settled without a server-validated submission。

## 整改

纯语句 view 和独立生成记录分页；复用原记录行、标签、抽屉与监控控件。固定新任务前给独立项目根短映射并保留来源证据；共享 ABI 常量、结构化长路径诊断、业务状态和预算终止。原失败上下文/历史保留，真实新同源任务在审核前验证。

独立评审发现短项目 a→p0 会反而加长路径，已增加只在 prefix UTF-8 字节确实缩短时采用的 guard 及回归。全回归还发现 ABI 敏感测试隐式使用 /var/tmp 导致 66 字节；该成功测试显式使用可写 /tmp/a 并断言目标符合 ABI，不放宽生产限制、不修改系统 /tmp 权限。

真实同源复验 ad7c53a17c334c7b 已生成并编译成功、提交服务器验证候选，停在人工审核前；原失败 0dae 保留。同源复验不意味着已加载权限或已执行项目功能测试。
