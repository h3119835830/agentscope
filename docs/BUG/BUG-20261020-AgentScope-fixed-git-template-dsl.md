# BUG：Git 固定命令可编辑、未保存时 DSL 为空（2026-10-20）

复现：Git 提交执行约束的新配置把 git 显示为可改 program；没有独立显示固定 commit；原始 DSL 在保存前仅提示保存后查看，模板详情也没有默认规则骨架。动作列表缺少 block 的不可用原因。

根因：程序身份与命令常量混在变量参数中；DSL 渲染仅绑定保存流程。单独增加预览文本会导致双重渲染漂移，因此采用共享服务端渲染和版本化固定合同。

修复：六个可执行 Git 模板追加固定合同版本；固定命令只读展示，禁止 API 注入 program/command/DSL 和历史合同新建降级。模板默认值与子配置当前输入都能只读预览真实规则，缺参显示占位位置，不支持能力不产生伪 DSL。禁用 block 并说明事后 argv 限制，未改变运行能力。对子配置表单正文/保存栏增加高度约束，避免长内容使底部操作离开弹窗。

验收：1421 项后端、352 项前端、构建通过；真实 Git/ActPlane 13 项；真实模型只选择新模板并填 effect。界面验证未保存 notify/kill 切换、默认值 exits 2、模板保存后新配置继承及旧配置不变；390×760 视口保存栏和 DSL 可见。正式发布证据见 REVIEW。
