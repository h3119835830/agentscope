# 全屏模块留白与模板表半宽

## 复现与原因

2026-10-20，18003 全屏系统页：策略表固定为五列默认宽度总和 836px，而容器为 1388px，右侧留出大块空白；页面外层还受 1440px 上限限制。其他模块分别受通用 1180/1440px、审批 1280px、会话 1480px 和助手外框 1040px 等规则影响。

## 修复

两个生产 CSS 文件调整：recordVisuals.css 统一主内容区全宽并放开助手外框；unifiedPolicyLibrary.css 使模板表至少铺满容器。登记数据和运行行为不变。

## 验收

- 前端 403/403，构建通过。
- 1920/1280/600px 七个模块逐页检查，无页面级横向溢出；主内容区宽度等于 main。
- 1920px 系统页表格宽度等于滚动容器宽度，侧栏收起后继续填满；600px 主表和子表独立横向滚动。
- 说明列键盘调整 300→310，刷新恢复 300；助手指定实例、系统标签/生成记录、子配置展开正常；无 console error/warn。
- 发布及主服务复验结果见 REVIEW；截图保存在指定技术文档目录的 REVIEW/evidence/full-width-20261020。
