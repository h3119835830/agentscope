# BUG：运行时来源工具与候选合同不一致

日期：2026-10-26。范围：隔离试验。

## 概括要求无法使用记忆解析目标

旧 restriction_authorizations 要求保护关键词与登记路径出现在同一句用户要求中。“清理缓存，不要动生产配置，具体位置见记忆”没有字面路径时，授权目标为空，即使 Agent 已读取记忆和项目对象也无法提交。试验引入基于已读取证据的对象解析，仍要求当前用户来源，不让记忆独立授权。

## 首次现场失败

任务 5b09c886bae44627：真实 Pi 将运行前式绝对执行路径提交给只接受相对路径的试验校验器；随后待澄清用户编号和记忆触发编号混用，候选未能提交，任务按原合同失败关闭。没有加载新限制。原始失败记录保留在独立试验 evidence 下。

修复合同而不添加用例提示词：规范绝对工作区映射转换为同一登记相对对象；上下文单独提供 pending_user_request_ids；能力 schema 明确必要 OS 缺口与任务指导的区别，不允许 unresolved 与执行 atoms 同时提交。验收提示词先停止原固定清理任务，使当前任务意图明确；这属于公开试验任务输入，未改变 Agent 针对某个文件的提示规则。

现场闭环以同目录 REVIEW 的最终结果为准；自动化通过不等于真实内核验收通过。
