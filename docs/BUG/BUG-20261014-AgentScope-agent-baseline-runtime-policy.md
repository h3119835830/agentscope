# BUG：配置层与真实运行时目标不一致的遗留跟踪

日期：2026-10-14。状态：设计目标已收敛；应用迁移和运行验收开放，本轮不能认定运行修复完成。

## 已复现的设计不一致

前轮主 RFC 和 ADR 保留系统/Agent/工作区/会话四个固定配置层，用户现明确只要求固定到 Agent，其余运行时新增。若仍按旧目标建设局部策略库，或将共享 Agent 域里的增量标为单会话规则，会继续造成界面、审批和实际绑定不一致。

本轮同步主文和部分取代关系，工作区/会话改为来源与视图；增量按真实 ActPlane 域起草。此为文档设计闭环，不是运行事故复现或代码修复验收。

## 开放项与退出项

| 项目 | 状态与门槛 |
|---|---|
| 必须实现工作区/会话独立策略层 | 退出当前固定需求；原生可信子域可选，不算已实现 |
| 同域活动版本、串行协调、前置版本与可信 fencing | 开放；控制面 CAS 不能代替 Broker/执行侧防止失效写入 |
| 加载部分失败与共享安全读模型一致性 | 开放；不能虚报旧版本仍有效或已回滚 |
| RuntimeChange 范围、审批、显式应用和幂等 | 开放；须按真实域及共享影响实现和验收 |
| 运行代次、来源结束、未来会话准入、规则长期化 | 开放；不得隐式删除、继承或提升范围 |
| 通用停用/删除/替换及不重启更新 | 未证明完整支持；Add 不能代替这些能力 |
| 会话目标/加载 DSL、共享范围和覆盖状态 | 当前合同待 UI/接口实现验收，本轮未改 UI |
| 旧候选/API 与历史已批准权限兼容 | 保留原语义，不静默扩大；新目标重新起草审批 |

后续验收采用[新 RFC](../RFC/RFC-20261014-AgentScope-agent-baseline-runtime-policy.md) N01–N12，包含双会话共享域同效、另一 Agent 不受影响、未应用不改权限、原生流程保持及完整安全任务。静态检查见[validation.json](../REVIEW/evidence/agent-baseline-runtime-policy-20261014/validation.json)，修订评审见[REVIEW](../REVIEW/REVIEW-20261014-AgentScope-agent-baseline-runtime-policy.md)。

默认共享运行架构已明确，相关设计静态检查见[回执](../REVIEW/evidence/agent-shared-runtime-design-20261014/validation.json)；开放项未因设计补齐改为已修复。
