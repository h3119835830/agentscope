## 本地预览修复：PREVIEW-ECHO-01

复现：打开审批确认窗口后，预览宿主回显相同已保存状态，窗口立即被重置关闭。原因是同一状态的回显被当成外部新状态处理。修复：对完全相同的状态回显不重建瞬态确认窗口；真正外部更新仍恢复状态。已在浏览器复测确认窗口、勾选、批准不应用、单独模拟应用与共享会话一致性。本项只属于本地示例预览，不能记为真实审批/API/内核修复。
