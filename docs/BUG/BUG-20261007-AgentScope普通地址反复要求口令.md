# BUG：普通地址反复要求管理员口令

> 状态：已废弃。2026-10-07 用户要求直接删除登录流程，当前实现见 BUG-20261007-AgentScopeDemo删除登录.md。以下为历史方案及当时验收，不代表当前代码。

日期：2026-10-07。

复现：直接打开 18003 的任务工作台普通地址，浏览器没有有效本机会话，页面显示“连接 AgentScope / 管理员口令”。一次性启动链接兑换后会被移除，会话 8 小时到期；普通地址不会自行取得新会话。用户截图已复现。

原因：原免口令方案只覆盖受信启动器的一次性票据入口，未覆盖普通地址或自动续接。过期票据兑换失败还会阻断后续模式查询。

修复：18003 显式开启本机自用自动会话；页面先查模式，自动连接，旧票据不阻断自用入口；401 自动续接并重试一次。保留默认部署及任务/生成接口认证。

验收状态：已关闭。专项后端 26 项、前端续接 4 项、完整后端 326 项通过（3 项跳过）；用户原普通地址无需口令进入，刷新后保持任务选择，管理请求与会话重新连接通过。结果见对应 REVIEW。
