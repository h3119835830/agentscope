# Agent 页工作区策略入口混淆作用范围

日期：2026-10-15。状态：源码和隔离页面验收通过，待正式静态入口核对。

## 复现

进入 Agent 策略助手，页面出现“Agent 长期基线 / 工作区策略”切换。该入口同时表达资料选择和应用目标，工作区缺少独立绑定时又不能应用，增加用户理解成本。用户要求统一模块，用范围字段标注全部或指定 Agent。

## 修复

统一作用范围字段；工作区只作参考目录，保护对象使用模板参数。旧工作区 URL 保留原目标只读，禁止自动改为整个 Agent 配置。所有人工审批和应用资格沿用服务端合同。

## 关闭条件

指定 Agent 和全部范围可在同模块查看；配置表含范围；旧工作区草案不被扩大；切换不发送策略变更；窄屏、键盘和错误提示可用；正式发布不改变 API/Broker/Agent 身份及策略。

## 当前证据

新增范围与历史隔离测试 7 项通过，前端总计 291 项通过，生产构建通过。只读真实预览核对范围字段、记录表、键盘和窄屏；正式入口发布证据随后补录 REVIEW。
