# BUG：WSL 无前台会话退出导致 18003 间歇不可达

日期：2026-10-09。关联：[ui-redesign 接入验收](../REVIEW/REVIEW-ui-redesign样式接入-20261009.md)。

## 复现与诊断

用户报告 Windows / Codex 浏览器无法打开 http://127.0.0.1:18003/。Windows GET 实测连接被拒绝且无对应监听；执行 WSL 命令期间 API、Broker 均 active，Linux ss 可见 127.0.0.1:18003。systemd 日志出现短周期停止及新的 boot 分段，说明仅检查服务 active 或短时 HTTP 200 不能证明 Windows 后续持续可达。

在受工具管理的前台执行会话运行 `wsl -d Ubuntu -u happy -- sleep 120` 后，Windows 首页立即返回 200。随后使用受工具管理的长期前台会话 `wsl -d Ubuntu -u happy -- sleep infinity` 保持 WSL 运行，不修改 .wslconfig、网络绑定、防火墙、普通业务代码或 Agent 策略。

## 修复及验收

采用现有 systemd 托管 API/Broker，并保持一个 Windows 侧 WSL 前台驻留会话。该会话是本次工具执行管理的运行会话，没有安装登录启动项或计划任务，也不是永久开机启动保证；关闭驻留会话、退出管理进程或显式 shutdown WSL 后需重新启动。

Windows 实测：首页、index-_VyB5nR7.js、index-DSLHCQMK.css、/api/status 全部 HTTP 200。这些资源仍为 ui-redesign 样式构建产物。最终复查在前述 120 秒诊断会话退出后进行，以确认恢复不依赖短时诊断。

最初尝试创建隐藏的 Windows 常驻辅助进程被自动审批拒绝，工具仅返回 blocked by policy，没有详细原因；没有继续采用该后台方案，改用受工具管理、可停止的前台执行会话。

## 验收边界

此次证明 Windows 到 WSL 的页面、静态资源和状态接口可达。没有重跑 DSH/Hermes 或内核执行安全案例；API active、HTTP 200 均不能代替当前策略加载、进程绑定或内核拦截证据。浏览器工具此前的 URL 策略限制尚未解除，本轮不宣称实际浏览器截图验收。此前样式接入检查遗漏了 WSL 无前台驻留后持续可达这一项，现补充记录。

## 2026-10-10 复发：WSL 停机后控制台及 DSH 连接丢失

用户再次报告 18003 无法访问。上一个 journal 分段显示 2026-10-09 23:07:52 开始系统关机，23:07:56 完成 System Power Off 并停止日志；今天首次诊断时 WSL uptime 仅 8 秒，旧 DSH 进程已不存在。Windows 上次系统启动为 2026-09-10，本轮查询未找到昨晚对应的 Windows 重启/电源事件。确认是 WSL 系统环境停止导致连接丢失，不能断言具体由用户、程序或空闲回收触发。

此前驻留依赖工具管理的前台会话，关闭该会话后无持续保证；systemd 服务本身不能阻止 WSL 退出。这是已确认的运行维护缺口，但不等同于已找到本次 poweroff 的直接发起者。

恢复：WSL 正常启动后 API/Broker 由现有 unit 拉起；2026-10-10 13:31:11 启动独立隐藏的 Windows 驻留进程，再通过既有实例 start 接口恢复 DSH。恢复沿用原 policy_hash，没有扩大权限。新 DSH PID=1343，generation=d47ddb8cffe4422d89a33c4e03227d15，domain_id=627647253；旧运行信息没有作为验收依据。

Windows 13:33:57 实测首页、两个静态资源、health 均成功，DSH connected/active=true、gate=open；启动核验 passed、protected_integrity、grants_verified、network_verified、root_owned_events 全部为 true，7 条本次启动内核事件，IPv4/IPv6 拒绝计数各 1。会话接口返回 7 条记录，当前 4 个受管进程的 domain_verified=true。会话记录数量不表示全部会话正在执行任务。

恢复后检查超过临时诊断命令生命周期，驻留进程、DSH PID 与 generation 保持。该措施不含登录/开机自启，主动关闭 WSL 后不会自行恢复。浏览器自动绑定/刷新原错误页被 URL 协议安全策略拦截，未绕过，也没有实际页面截图验收。原停机直接发起者取证仍开放，连接恢复与启动安全核验通过。详见 [验收记录](../REVIEW/REVIEW-20261010-18003与DSH连接恢复.md)。
