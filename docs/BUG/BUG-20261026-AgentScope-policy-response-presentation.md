# BUG：策略助手结果重复铺开与工具误标

日期：2026-10-26。状态：代码修复、隔离验收通过；正式服务待升级。

复现：打开发布维护 Agent 的运行前策略助手。页面同时铺开多次失败、三项配置旧结果和一项配置新结果；生成依据与文件列表分别折叠，每项参数竖排；PolicyContextEvidence 将除 list_directory 以外的工具统一称为读取正文。新接入的填参、资源检查和匹配预览也因此出现错误读取标签。

根因：回复使用单个组件内联堆叠；配置采用重复文章式布局；工具显示采用二元判断。单项结果本身不是数量丢失，实际服务端最新运行前响应即为一项，符合只保护发布清单并保留正常维护的最小限制需求。

修复：独立回复组件，生成依据和已读文件可见，配置使用记录表；长文、工具步骤、此前轮次和总配置表按需展开。显式映射读取、搜索、检查、模板填写和匹配验证，失败预览不得称为成功。精确版本 execution 投影提供真实操作与处置，未知字段不猜测；不改模型提示词、原结果或策略数量。
