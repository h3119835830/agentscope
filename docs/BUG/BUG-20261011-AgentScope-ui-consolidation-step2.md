# BUG：第二步界面问题与修复闭环

日期：2026-10-11。状态：源码/隔离预览已修复，18003 尚未发布。

| 问题与复现 | 修复 | 验收 |
|---|---|---|
| 系统 → 生成记录仍嵌套“策略生成/历史策略记录/生成记录”，可再次生成和最终审核 | 替换为只读记录表及独立白名单详情，旧链接归并 | 浏览器确认无旧子导航、生成/审核按钮和内部诊断；搜索分页、空态、错误可用 |
| 生成详情包含 PolicyIR、原始 JSON、编译/模型内部数据与 hash | 仅投影需求、匹配、处置、历史目标和折叠 DSL | 测试验证私有诊断不进入响应；页面文本检查无内部生成 ID/阻塞码 |
| 目标/基线变化后，审批中心失效但 DSL 草案仍显示校验通过待应用 | 草案复用统一审批投影，禁用失效候选转交；编辑器不再直接确认应用 | 后端漂移读取不写入；真实浏览器三个位置一致为需重新校验 |
| 重新校验旧草案后，旧投影可能继续覆盖新候选 | 根据当前候选 ID 选择投影并持续追踪新候选 | 新候选转交测试通过，转交 ID 为 fresh |
| 恢复草案时把候选文档覆盖编辑器的当前配置，前/后对照易混淆 | 当前配置与候选文档分别初始化 | 移除空草案、保存校验、恢复编辑与目标隔离回归通过 |
| 总览、连接、任务历史的模块名重复出现；系统侧徽标指向旧历史审核数 | 模块名留在导航/面包屑，总览待审批使用统一计数，移除系统旧审核徽标 | 三个模块正文无重复 h1，浏览器导航确认面包屑正确 |
| 窄屏列表操作列被挤到横向滚动区域 | 小屏优先显示来源、状态、查看；详情展示时间 | 390px/720px 查看入口和详情边界通过 |

这些问题对应初始架构评审 BUG-01、BUG-02 和 BUG-04 的界面整改。共享执行器提示、真实工作区场景读取、会话域隔离与新增内核场景不在本阶段关闭范围。没有因预览夹具错误修改 Agent 提示词或放宽权限。
