## 复现

## 根因与修复

- 增加 typed agent_context 选择凭据与服务端环境快照，读取可信会话的实际执行目录，绑定资源、运行代次与策略修订。
- 真实模型验收进一步复现旧任务能力仅声明 write/unlink，实例 open/read 被误判不支持。已按实例后端提供正确能力，沿用实际 AST/编译/Broker 检查。
- 仅目录上下文时模型仍将额外路径/操作可能性列为缺口。已补通用文件对象适配阶段：模型定位用户原始字面对象，服务端解析/核验，产生不可变适配版本。评审注释留档，不作为新增用户要求注入 IR。没有添加针对 .env 的修复提示词，也没有绕过 required_context/unresolved。
- 生成记录按真实 Agent 与原生会话持久关联；助手可选候选、会话可按记录选用。导入、保存和确认继续核对环境，人工确认边界保留。
