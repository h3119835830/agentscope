# 系统配置误把功能说明当作用户规则

日期：2026-10-10。状态：已修复并通过在线界面验收。

复现：Agent连接 → 配置 → 安全配置 → 系统配置。旧页只有“运行隔离、控制面访问、权限变更、控制失联处理”四行，只读、不可添加规则，也没有共享策略存储。用户需要自己配置所有 Agent 共用的安全规则。

修复：移除四行功能说明，接入独立系统规则列表、详情、添加、编辑、删除及网络编辑；提交后列出变更与受影响连接，明确确认才应用。当前 Agent 页面只编辑本层规则，继承的系统禁止不能被取消；观测连接不宣称受控。保留既有平台隔离和心跳实现，不把它们当作用户规则。

回归覆盖系统/本层隔离、跨会话和未来连接继承、文件资源边界、禁止与授权组合、管理员权限、幂等、过期确认、并发、停止及核验失败、重启后的 blocked 恢复和停止连接保持停止。在线界面与部署证据见 [REVIEW](../REVIEW/REVIEW-20261010-system-security-rules.md)。
