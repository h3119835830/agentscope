# 子配置小屏没有独立横向滚动条（2026-10-16）

复现：在小屏展开模板子配置，右侧动作、状态与行内操作无法直接查看。子表容器跟随整张主表宽度，默认 overflow-x:visible，本身没有溢出，内容被外层可见窗口裁切；主表滚动条又位于全部模板之后。前次仅验收主表列宽，遗漏子表鼠标拖到操作列的场景。

修复：详情宽度受主表可见窗口约束并保持横向位置，子配置表独立横向滚动；溢出时在记录下方显示可拖动滚动条，支持键盘，宽屏无需时自动隐藏。修正展开行 padding 覆盖，使左右位置准确；不固定操作列覆盖内容，不改审批 / 停用资格或策略数据。

闭环：322 项前端回归、构建及 826 / 390 / 1430 宽真实数据预览通过；鼠标滚动到最右后四个操作可见，主表不跟动，提审核对取消不写入。18003 发布结果及真实截图保存在对应 REVIEW 证据目录。
