# BUG：系统审批重复枚举、结束操作不显式及历史会话英文标题

日期：2026-10-14。状态：已修复并通过本次验收。

## 复现与原因

系统审批行枚举每个 Agent/PID，重复显示全局范围，使单项配置占据多行；同一个通用 Agent 列未区分全局与实例作用域。停用策略、归档配置和停止执行虽有后端合同，但入口分散；Agent 停止缺少单独影响确认。英文历史会话源于原生标题，中文实验任务不能追溯改写已存标题。原生 rename 的 resolveAgent 可能恢复会话，因此直接批量改名会有副作用。

## 修复

全局审批一行摘要、详情折叠影响范围；生成作业增加合作式取消，当前基线助手和原生会话助手均提供入口；生效文档停用创建新审批，批准后另行应用；未生效配置删除需确认且保留历史；Agent 停止需影响确认并核对代次/策略。会话显示名称按精确键管理员 CAS 保存，保留原始标题，审批和目录使用同一投影。移除候选持久保存变更名称，避免应用后显示“0 项变更”或误列保留文档。另修复系统配置库预览回调仍按旧 confirm 请求体调用 approve/apply 的问题：补齐幂等键和批准回执，批准后保留待应用弹窗，另行应用才更新运行视图。

## 验收与关闭条件

要求整合版本前后端回归、18186 真实内核拒绝/待审批和已批准仍拒绝/应用后允许、旧确认拒绝、历史保留、停止进程退出，以及正式页面中文名称、摘要和现有 Agent 身份/策略不变。发布证据归入本次 REVIEW。

独立开放：失效审批仍缺少一键创建新版本的恢复入口，见 BUG-20261014-AgentScope-stale-approval-recovery.md；局部原生会话/工作区不能独立加载的能力缺口未在本次关闭。系统策略停用重建执行器会中断该范围的在途原生会话，必须由管理员显式应用。

验收结论：270 项前端、170 项相关后端测试通过；18186 真实内核链路和正式页面验收通过，既有三个 Agent 身份和策略不变。详见 [本次 REVIEW](../REVIEW/REVIEW-20261014-AgentScope-policy-controls-and-session-names.md)。
