# 助手对话缺少实际生成配置内容

## 复现

Agent 页提交安全场景，生成成功后，助手消息只有“已起草 N 项配置”和资料依据。实际策略名称、模板版本及参数没有在该轮展示，需要到下方当前配置记录推测；当前记录后来编辑时无法直接解释旧轮次的生成内容。

此外，固定文案“待提交审批”在该配置已提交后仍会留在历史回复，不能代表其当前审批状态。

## 修复

同一生成事务保存展示快照，并在每轮回复中呈现。审批状态只关联该轮配置版本；摘要只说明本轮起草数量。没有补造历史 Agent 名称，没有新增手工入口，没有改变审批与应用权限。

## 验收

测试覆盖生成后修改配置、更新模板标签与默认动作、重命名 Agent、请求重试、跨轮次和跨范围隔离、新版审批不得出现在旧版、旧版审批过期、提交/批准/应用/停用的只读状态、历史兼容、缺失版本、输出转义及空结果。完整结果、页面截图和 18003 发布事实见同名 REVIEW。
