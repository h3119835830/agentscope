# BUG：系统策略配置表达不足与后缀能力边界

日期：2026-10-11。

## 1. 配置界面只有三项、固定具体路径和 block

复现：当前系统页面提供 ENV、SSH、策略记录三类写死候选；ENV 指向 `/workspace/.env`，详情缺少动作选择。用户无法表达任意 `.env` 后缀与 notify/kill，表格在可用宽度内出现横向滚动。

原因：产品配置模型和展示维度不足，不是 ActPlane 只有三条可用策略。

整改：独立预览增加 12 类有来源和边界的候选、匹配语义选择、三动作、实时 DSL、统一系统范围确认、适应窗口的表格。8 项模型测试、36 组真实编译与浏览器交互通过。

状态：**预览整改验收通过；运行控制台替换尚未实施。** 不将预览状态称为生产修复。

## 2. 文件后缀编译通过却无法在当前固定受控 profile 加载

复现依据：编译器将 `**/*.env` 降低为 M_SUFFIX；当前 adapter 的运行 ABI 能力检查将文件路径后缀标为 pinned_runtime_unsupported；Broker 在加载前拒绝。

风险：只展示“编译通过”可能使用户误以为所有 `.env` 已被保护。替换成固定文件路径或不等价 contains 会改变需求。

整改：预览明确显示“可保存、暂不能载入”；全体载入预览保留全部所选项并阻止确认加载。当前预览本来就不提供真实加载写接口。

状态：**误导展示已在预览避免；引擎能力待专项实现与真实运行验收。** 此次未更改固定引擎配置。

## 3. 窄屏操作文字换行

复现：600px 宽度下操作列过窄，“配置”逐字换行，侧栏会话文字残留。

修复：操作列预留宽度且按钮不换行；窄屏子导航遵循同一图标布局。复查 body 宽 585、viewport 600、表格右界 568，无横向溢出，配置面板底部可操作。

状态：已修复、浏览器验证通过。
