# Scope Demo 工作台设计

使用对象：研究者和导师。首要工作是沿同一个真实任务理解并审核文件权限的变化。
用户明确要求简约、逻辑清楚，执行记录不在外侧铺开长文字。

## 设计取舍

采用 Anthropic frontend-design 的“计划、对照需求、实现、截图评审”流程。
来源：https://github.com/anthropics/skills/tree/8a1541c4a3ffa5a20a5a91de0dcf3f0bab1d1ef4/skills/frontend-design
同时参考 Impeccable distill 的渐进披露原则；不引入其运行器、浏览器扩展或自动 hooks。

颜色：画布 #F5F7FA、内容 #FFFFFF、正文 #23344B、次级文字 #607086、
操作蓝 #245DA8、核验绿 #246B52。绿色只表示已经核验或已经清理的事实。
字体：中文优先 Microsoft YaHei / Noto Sans CJK SC，英文继承同一家族；
正文 14px，次级 12px，小标题 18px，任务标题 26px。技术原文才使用等宽字体。
布局：左对齐，最大内容宽度 1080px。五阶段权限路径是唯一醒目的结构。
不添加统计卡片、装饰性图表或多层卡片。

~~~
AgentScope     任务工作台 / 历史策略库                 连接 / 锁定
动态权限演示与具体任务示例                          切换 / 新建 / 设置
默认只读 —— 任务授权 —— 按需收紧(可选) —— 报告扩权 —— 结束撤销
当前权限 | 变更审核 | 执行记录
当前页签的一个主要工作区域                           当前需要的操作
~~~

## 信息与交互合同

- 顶部显示权限演示用途、具体任务示例、当前运行状态与有效版本；ID 放入任务详情。
- 阶段只有实际核验快照或已确认结束才标记完成；未发生的阶段仍显示待进行。
  点击已发生阶段查看历史权限，不改变当前 Scope。
- 权限页展示六类资源。结束后明确标记撤销，并将表格命名为结束前的历史权限。
  执行域失联或失败时展示最近核验记录，不称为当前有效权限。
- 审核页展示待处理申请和变化目录。用户原文、Pi 解释、保护项、审核/编译/加载/核验
  状态进入审核抽屉；批准按钮在看到具体差异后提供。过期、失败、结束、未生成候选不能批准。
- 新请求表单按操作打开；不常驻占据审核页。澄清重用原要求，但创建新分析。
  拒绝收紧候选仍保留用户收紧要求和等待状态。
- 执行记录默认只看权限关键事件，每页八行。Agent 操作和内核拦截另行筛选。
  行内只放时间、短标题、结果；原始解释、路径、DSL、hash、JSON 收进详情抽屉。
  事件 API 的最近 150 条窗口明确标注，不能冒充全部审计历史。
- 抽屉支持 Escape、焦点返回和键盘；423px 使用紧凑布局，阶段栏可横向滚动，
  页面本身不得水平溢出。刷新恢复 URL 中当前选择的任务。
- 纯展示投影不改变 ScopeManager 的审批和核验权威。已结束不等于业务功能验收成功；
  Agent 自报仅在详情中标注来源，不能将其变成独立验收结论。

## 对照需求后的修订

保留三页签以免从上到下堆叠全部功能；去掉 Demo 中的七项重复侧栏；
保留历史策略库独立入口。大标题解释权限演示用途，下一行给出具体任务示例。
没有用批准数量推导阶段，权限路径来自核验快照；结束页不再给六行重复的“授权撤销”。
所有证据仍可回查，主界面不直接打印技术原文。

真实验收补强：任务来源与实际核验证据类型放入任务详情，避免将自建项目误认为公开基准。
新增十个实际执行检查点截图评审，覆盖待审、拒绝、生效与撤销；历史回放仍单独记录。
当前源码、真实页面与权限状态相互回查，不为展示添加虚构运行记录。

本轮连接整改：顶栏仅称执行后端可用。DSH 连接详情按“当前进程/域 → 工具回传 → 用户
上下文送达 → 内核记录”的顺序展示事实，原始证据折叠。旧域/结束回传标历史，不据此
宣称在线。明确受管接入、3 秒页面回查、没有独立空闲心跳。收紧标可选分支；主叙事为
默认只读后按需授权，不再把额外用户要求误写成每次执行必须逐步收紧。
