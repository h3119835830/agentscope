# ADR — 文件 Scope Demo 的权限与恢复边界

日期：2026-10-05。状态：采纳。

1. 保留现有控制服务，增加 ScopeManager，复用 Pi 包和 Broker/ActPlane。使用独立数据库、profile、UI 和合成 Git 项目进行验收。
2. 使用完整不可变快照与基础版本绑定的候选。实际生效以探针及执行域回查为准；批准不等于生效。
3. Pi 输出受支持的结构化目录权限，服务器渲染规则。候选理由只作为公开审计内容；追加 DSL 使用固定说明，避免自由文本影响规则解析。
4. 收紧追加同域限制；扩权通过新策略包/新 DSH 执行域实现，保留 prior constraints 的 lineage 与公开检查点。首版不提供自动扩权。
5. 可信转发器与 DSH 分开运行。DSH/探针为低权限 UID，控制 socket root 0600，控制结果由 root 在受保护目录写入；文件事件 root 所有且不可由 Agent 修改。
6. 原生 DSH pre/post 工具事件负责工具边界与公开结果，内核独立负责文件拒绝。已开始的工具不冒充已被暂停，其开始版本单独记录。
7. 首版绑定 backend/frontend/tests/config/output 的登记场景，非通用目录策略平台。指导性要求不伪装成内核规则。
8. 出现已加载但未核验、或未知执行状态时停止执行并要求结束重建；不尝试以旧指针猜测实际规则或自动回滚追加限制。Broker 重启前关闭任务。
9. 原生插件、manifest、输入覆盖文件和凭据始终不可写。DSH 的生成根配置 cordis.yml 每次启动都重写，允许其必要写入而保护真正的代码与配置输入；不修改第三方 DSH 实现。
10. 本机个人 Demo 直接访问，不再使用管理员口令、浏览器票据或 Cookie 会话；复用本机免口令控制入口，DSH/Pi 任务凭据及 Scope 审核保留。详见同日删除登录 ADR。
11. 工作台采用真实快照投影的阶段路径与三个互斥页签，取代长日志外显。审核原文和完整技术证据渐进展开，不能因简化 UI 合并审批、加载、核验状态。新增 scopeView 为纯展示模块，不承担审批、推理、执行或授权职责。采用已核对来源的 frontend-design 工作流；不引入第三方 UI 运行器、hooks 或新前端依赖。2026-10-05 的 Demo 独立顶部导航选择已被第 14 项统一导航决策取代。

取舍：扩权重启存在恢复成本，但允许规则包重新构建并撤销旧凭据。公开检查点能续接实际进展，但不等于完整 DSH 原生会话回放。当前服务使用单例 ActPlane，因此真实验收任务串行运行。

12. 接入真实执行中的页面验收检查点，不用历史状态回放证明待审/拒绝/核验后的实际状态。
    公开素材预检与真实 Agent/内核执行结果分别报告；选用 RQ5 两个文件案例、RQ2 文件约束
    作为首轮公开场景候选，SWE-bench Lite 用于下一轮真实项目任务。原文、版本和目录
    映射保持可追溯，新增动态授权 overlay 作为扩展实验，不冒充原基准成绩。

13. 将任务层按需授权和 ActPlane 同域限制区分展示。收紧明确为用户要求的可选分支；
    扩权继续采用可信审核后换策略包/执行域，而非弱化旧域约束。主区域只显示用途和状态，
    DSH 连接证据在独立详情中渐进展开：服务可用、DSH 进程、工具通信、内核事件分别表述。
    选择复用已有 Broker 进程观察和公开事件，不增加空闲心跳或推送协议；因此不声称持续
    心跳在线。旧进程回传不能证明新进程已通信，结束后的全部时间戳只表示历史。

14. 2026-10-06 采纳用户指定的完整左侧导航与顶部面包屑，固定用于全部七个模块。
    废弃只在 scope-demo 隐藏侧栏的条件布局。保留侧栏折叠与窄屏紧凑模式；取舍是工作台
    内容宽度减小，但模块位置和导航方式保持稳定。App 持有 URL 导航状态，工作台的任务
    选择受同一状态控制，模块/历史页签/任务支持刷新及浏览器前进后退；运行时任务选择
    不改变当前模块。该决策只改变展示与导航，不修改审批、凭据或运行时执行合同。

15. 2026-10-06 明确以被约束 Agent 的启动时点划分策略权威。保留独立 Pi 的候选职责，
    执行 Agent 提供任务需要和公开反馈，可信控制面审核/加载；Pi 不因独立运行而获得高权威。
    接受将 RQ5 原始素材加入独立 DSH Web 供检查，明确标为未绑定策略的预览，不隐式安装
    插件或扩大通用场景支持范围。取舍及代码事实见 ACTPLANE-REVIEW-20261006.md。
