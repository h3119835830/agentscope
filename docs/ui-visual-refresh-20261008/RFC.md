# RFC：按 HTML 原型调整现有界面外观

日期：2026-10-08。状态：本地实现及页面验收通过，未发布到远端或替换现有服务。

## 范围与合同

用户要求先采用 [HTML 原型](../prototype/AgentScope-界面原型-会话安全约束.html) 的视觉外观，现有内容保持不变。[总体设计文档](../AgentScope-界面重设计-会话安全约束可视化-20261008.md) 中的信息架构和新增功能属于后续方案。

本次保留总览、Agent连接、策略工作台、任务历史、历史策略库、持久治理六个入口，以及原有文案、任务对象、字段、状态、操作按钮、URL 参数和键盘交互。

采用原型的 216px 深色侧栏、蓝色选中态、52px 顶栏、浅灰画布、白色卡片、标签页、表单和详情抽屉视觉。窄屏侧栏展开覆盖内容区域，避免压缩正文导致整页横向溢出。

## 实现

- `frontend/src/prototypeTheme.css`：作用域为 `.prototype-theme` 的视觉层，最后导入以统一既有组件样式。
- `frontend/src/main.jsx`：只增加样式导入及根节点样式标识。
- 其余 React 组件、状态计算、接口调用和后端文件保持原样。

现有 API 路径、请求体、鉴权、审批、权限变化、进程与执行域绑定不变。没有新增接口、数据迁移或运行时启动依赖，也没有修改普通业务代码。

## 验收边界

页面只读检查使用独立的本地静态预览，API 转发至已有 18003 实例；未重启或部署 18000、18003、18004。页面读取真实记录，不把原型中的模拟会话或拦截数复制到现有界面。

125 项前端回归、生产构建、六模块桌面和 423px 窄屏检查通过。具体记录见 [REVIEW](REVIEW.md)，本轮发现的问题见 [BUG](BUG.md)。这些结果证明视觉调整的回归范围，不构成新的内核强制执行验收。
