# ADR：用独立样式层采用原型视觉

日期：2026-10-08。状态：采纳。

## 决策

在现有 React 应用根节点添加 `.prototype-theme`，最后导入独立主题样式。保留所有组件结构、文案、导航、数据读取和操作处理。

## 原因与取舍

用户本轮要求先调整外观并保留内容。直接用静态原型替换 React 界面会丢失真实数据与现有操作；同时实施五项导航和安全约束页面会超出本轮范围。因此本轮只采用原型的颜色、字体、间距、侧栏、卡片、标签页、表单和抽屉视觉。

独立样式层便于完整核对业务组件是否改动，并可在后续重设计中逐步替换。代价是它与已有组件样式共同参与级联；新增组件或调整原有选择器时，需要同步检查主题作用域、优先级和窄屏布局。

## 后续边界

原设计的会话中心导航、统一安全清单、审批中心和新的继承树尚未实施。不得将静态原型中的示例状态当作当前运行证据。
