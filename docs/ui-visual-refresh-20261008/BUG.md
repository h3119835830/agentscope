# BUG：原型视觉调整中的窄屏布局回归

日期：2026-10-08。状态：已复现、已修复、复验通过。

## 1. 展开侧栏导致整页横向溢出

复现：在 423px 视口打开总览，点击“展开侧栏”。首轮主题中 `document.documentElement.scrollWidth` 为 529px，大于视口 423px。

原因：展开后的固定侧栏继续占用正文布局宽度，正文中的卡片和内容最小宽度挤出视口。

修复：在 650px 以下保留 58px 正文偏移，216px 展开侧栏覆盖正文；不修改原有展开/折叠状态、按钮和导航处理。

复验：同一 423px 视口下展开侧栏，`scrollWidth=408`，没有整页横向溢出；折叠后的任务页同样通过。

## 2. 窄屏工作台标签页出现多余纵向滚动条

复现：423px 下打开已有任务的“运行前”页，标签栏右侧出现纵向滚动箭头。

原因：原有横向自动滚动容器与新标签按钮的边框、负下边距共同使纵向滚动生效。

修复：主题标签容器明确使用 `overflow-y:hidden`，保留窄屏所需的横向滚动和原有键盘切换。

复验：工作台标签容器的计算样式 `overflowY=hidden`；“运行前、运行时、执行监控、执行审计”四项仍可访问。截图见 [窄屏工作台](evidence/task-mobile.jpg)。

本记录只覆盖本轮已复现的显示问题，不将既有执行层问题标记为已修复。
