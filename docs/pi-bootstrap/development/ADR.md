# ADR：开发控制台采用显式免口令模式

日期：2026-10-04。状态：采纳。用户授权：当前开发阶段取消口令，直接展示功能。

## 决策与取舍

新增后端显式环境开关和前端模式探测，使本机控制面未携带凭据的请求直接进入。默认关闭；当前本机两个实例均开启。前端清除旧 sessionStorage 口令，避免过期凭据导致错误认证。无需在页面填写或保存新凭据。

本地开发获得完整控制面操作能力；不能据此声称本地 Agent 无法使用匿名控制 API。当前模式的权限边界与 2026-10-03 正式 RQ5 运行时管理员鉴权证据分开记录。生成器七工具、插件任务鉴权和批准版本校验继续保留。

原实例与 RQ5 实例使用相同前端代码，分别部署到独立静态目录和数据库。放弃“前端构建 hash 必须不同”的旧展示隔离指标，改用目录分离及实际 HTTP 内容与本实例快照一致性；保留原库无测试任务注入、721 状态保持和 Broker/任务目录隔离。

恢复方式：配置 `AGENTSCOPE_DEV_NO_AUTH=0` 并重启对应 API。此操作恢复原口令流程；无需改变现有口令或策略审批。

## 验收依据

新增五个后端测试覆盖默认认证、本机直接访问、无效 Bearer、生成器与插件独立鉴权以及远端 peer/Host/Origin 不进入开发模式；全套 84 项通过。实际页面与 API 证据见同日 REVIEW。
