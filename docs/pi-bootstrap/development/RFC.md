# RFC：AgentScope 本地开发免口令入口

日期：2026-10-04。状态：已实现并验收。依据：用户明确要求当前开发阶段取消页面口令并展示已实现功能。

## 职责与接口

`AGENTSCOPE_DEV_NO_AUTH` 默认为 `0`，本机现已设置为 `1`。新增公开查询 `GET /api/auth/mode`，返回 `development_no_password` 与 `authentication_required`。只有明确开启配置且请求 peer、Host 为 loopback，并且 Origin 缺省或本地主机时，未提供 Bearer 的控制 API 请求可直接进入。已有 Bearer 仍按原检查处理；生成器及插件路由继续执行各自任务凭据校验。

前端先无凭据查询模式；开发模式清除缓存管理员口令并显示“本地开发 · 免口令”，直接进入工作区。服务不可达时显示连接失败及重新连接入口。默认模式沿用管理员口令入口。未更换或导出口令。

本机匿名控制 API 是此开发模式的实际合同，不代表正式部署的管理员权限隔离。既有候选 hash 审批、编译检查、启动资产检查及 ActPlane 受管域执行仍保留；取消控制台登录不等于取消执行策略。

## 实例与第二层

原实例 18000 使用 `/var/lib/agentscope/agentscope.sqlite3` 与 `/opt/agentscope/frontend/dist`；RQ5 18001 使用 `/var/lib/agentscope-rq5-v1/acceptance.sqlite3`、独立 `ui-dist`、`/r` 工作区和独立 Broker socket。用户本次要求展示开发页面，两个静态目录均部署当前构建；无需要求客户端 hash 不同。隔离检查验证目录不同、实际响应分别匹配对应文件及数据库隔离。

第二层保持固定场景、证据登记、历史 FTS5、七个 Pi 工具、结构化候选、确定性 IR/DSL、整包编译、按 hash 批准、DSH 受管启动、事件和独立评测。第三层仅交接批准版本、绑定回执和事件基线。

## 验收

84 项后端测试与前端构建通过。两个端口浏览器直接进入，实际展示配置场景候选与批准 DSL。原库 721 条策略状态摘要与部署前一致；原库测试历史 0，隔离库测试历史 3，两个实例活动任务均 0。详见 REVIEW 同日记录。
