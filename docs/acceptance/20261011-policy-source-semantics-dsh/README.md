## 证据与边界

`acceptance.json` 保存三阶段 23 项检查和权限指纹；`native-tools.json` 只导出原生 bash 调用与工具输出，排除模型私有推理。`kernel-events.json` 保存 7 条对应受保护文件的真实写阻断记录。事件文件与父目录属于 root 且无组/其他用户写权限；事件的执行域、DSH 来源 PID、编译 source_ref/clause_hash 与加载 receipt 一致。原始会话文件与事件文件摘要在报告中留存。

当前 native DSH 工具事件没有可信 kernel_call_tag，7 条内核记录均为 `shared_executor_unattributed`，不冒称精确归属于某个会话或工具调用。验收以独立单会话连接、真实原生工具输出、执行域及来源证据共同核验。页面“系统调用匹配记录”严格过滤未关联事件，因此本轮不以该页出现记录作为通过条件，也不伪造关联。

批准后只读文件 SHA-256 为 `05ce6e57b658cf1bf233d908fff4a39644b2251d8f9ef02617f7671d539155cd`，全部拒绝操作前后相同。真实 DSH 探针的 namespace PID 与宿主内核 PID 分别记录，不直接混用。该验收覆盖本次只读语义与人工审批边界，不是完整 RQ5 攻击矩阵验收。
