# ADR：会话安全的展示与配置边界

状态：采纳为本轮原型约定；生产实现仍待后续开发。2026-10-08。

1. 沿用已有会话原型的视觉与 session 主入口，增加平台模板配置；不以域树作为用户默认权限入口。域树用于来源和影响范围解释。
2. 原始 RQ1 YAML 与修订模板分开保存。每条模板记录原始 UID、冻结源码链接、来源类别和限制；.ssh 明确作为新增需求。
3. block、notify、kill 显示执行时机。kill 不作为“未发生副作用”的承诺；整个会话终止是独立能力。
4. 按当前编译支持矩阵限制可选处置。Git 分支级策略只能保存需求，完成可信分支/引用强制中介前不输出可执行规则。
5. 父规则在子域锁定。基线草案不自动改变已有 session 快照；Agent 提案与批准/加载分离。
6. 通用语义约束与 OS 规则共同展示，但分别标明执行方和验收方式。

取舍：界面保留用户想表达的安全目标，同时明确未实现能力，避免为了看起来完整而显示虚假的“已生效”。复杂 matcher、hook 和回执放在详情中，首屏仍是用户可读的权限清单。

2026-10-08 界面修订：采用与平台模板一致的记录表，废弃会话首屏的规则卡片、重复模块大标题、英文眉题和统计卡片。反馈原因与技术内容按记录展开；导航定位、任务上下文、规则来源和生效状态各自只承担一项信息职责。
