# REVIEW：研究与安全配置原型

日期：2026-10-08。状态：研究与原型验收通过；生产能力未实施。

## 已确认事实

- 607 个唯一 UID、392 per-event、215 cross-event，所有导出政策体与固定 Git blob 一致；13 条原文证据与 15 类候选模板有映射。
- 当前平台导入的 721 个唯一候选条目不是该 607 编译子集。
- 4 项离线编译检查均返回 ok；其中带参数的 block git commit 明确不支持事前阻断，其余结果见 evidence/compile-support.json。
- 没有 load/attach/run、真实破坏性操作、服务重启或远端推送。

## 必须避免的风险

原始翻译不等于语义正确；编译成功不等于操作受支持；支持不等于已加载；已加载不等于 PID/domain 绑定与当前活性；触发事件不等于对象完整性；日志产生不等于反馈送达 Agent。Git 分支身份、事前引用保护、整个会话终止仍是独立待实现能力。

运行时历史存在保护写入失败的记录，本轮没有复测或修复，不将这次静态能力检查当成该缺陷关闭的依据。

## 原型验收范围

检查 session 列表式权限、继承锁定、D-A/D-A1/D-B 选择、平台模板过滤、自定义/默认反馈、基线草案与既有会话快照隔离、Git 不支持能力提示、语义执行方、草案/检查状态、Agent 提案、键盘关闭、移动端布局及脚本错误。

结果：19/19 项浏览器检查通过；JS 通过 Node 语法检查；桌面 1280px、手机 423px 无页面横向溢出，手机配置对话框在视口内。自定义反馈中的 HTML/引号按文本保留；继承字段禁用；默认反馈可恢复；修改平台草案不会改变现有样例 session；Git argv 的 block 禁用，分支级配置只存不可执行需求；安全检查明确缺少运行时证据；Agent 建议只进入待审草案。浏览器脚本错误 0。

证据：evidence/ui-checks.json、session-desktop.png、session-mobile.png、ssh-config-desktop.png、git-branch-draft.png。原型只在内存保存草案，刷新恢复默认示例；没有持久化配置或调用运行时 API。没有改动 frontend/src、backend 或 actplane 源码，原有 HTML 未修改。

正式实现前需要逐模板完成真实阻断、对象完整性、允许路径、绕过路径和反馈送达验收；本轮原型验收不替代运行时验收。
