# ADR：AgentScope 历史策略库技术决策

日期：2026-10-02。状态：已采纳；与 /opt/agentscope 当前实现一致。

| 决策 | 采纳方案与理由 | 取舍 |
|---|---|---|
| 两段独立 LLM | DeepSeek deepseek-flash 无工具客户端，单 MD 抽取函数、单语句转换函数，provider 注入 | 不复用 Agent 会话上下文；效果必须单独验证，不能套用论文 Codex + GPT-5.5 结果 |
| 四轴分类 | 内容类型、主题、执行层级、上下文依赖独立保存；描述保留 | 模型初标需审核，不能以一个“策略类型”决定执行 |
| 结构化记录为源 | policy_record 渲染调研格式伪代码；编译/部署追加事实 | 不维护第二份人工伪代码；重编译诊断独立展示 |
| 固定快照 | GitHub 固定 commit、hash；403/429 可用关闭 hooks 的 bare Git 只读对象回退 | tree 截断逐目录读取；拒绝 symlink/路径穿越，不执行仓库说明 |
| 不可变审批 | 新版本与内容 hash 绑定；同输出幂等复用；私有标签/规则前缀 | 不能用旧批准覆盖新内容，不能只保存“策略 ID”丢失确切版本 |
| 明确授权范围 | 新上下文版本绑定 task/repo/commit/目录；修改范围使用闭合授权合同 | 不猜“无关”的边界；仓库外不自动纳入此规则，基础限制仍生效 |
| 剩余缺口分离 | required_context/unresolved 只表达未解决项，context_used 表达已提供项 | 防止把已使用的授权范围误当作仍缺参数；不增加针对某条业务规则的特殊提示 |
| 加载批准任务包 | artifact_version_ids 实际进入完整编译，Broker 域/PID 回查，提交 hash +真实回执 | 不接受自由命令或 DSL，不虚构内核 hash 回读；首版不追加运行中历史规则 |
| 顺序后台作业 | 单 API 进程、单 FIFO worker；重启中断可重试，失败保留 | 未验收多 API 进程的 worker 协调；不得直接部署多 worker |
| 诚实能力状态 | 完整编译才可执行；unsupported/requires_context/invalid/partial/失败独立展示 | no access 不降格为 no write；编译成功不等于全部文件系统元数据已覆盖 |
| 加载失败显式重试 | 未产生 Domain/PID、清理确认后，人工重试原批准版本 | 保留失败部署；域绑定不确定时不能走此重试路径 |
| 既有限制继承 | 生成设置缺省继承，Scope 重启继承历史 DSL 与旧限制 | 本次只改变 AgentScope 集成，不改变权威业务接口或内核行为 |

已观察的新建空目录项残留属于 ActPlane hook 覆盖边界，本实施未选用“限制写入等于所有变更禁止”的断言。该缺口保持开放；未来改变内核事件合同需独立设计和验收。

## 2026-10-03 导航归属

保留历史策略库作为左侧一级入口，四个业务模块使用右侧顶部二级导航。收缩仅影响侧栏宽度和一级标签显示；二级选中状态、业务输入和 API 合同不随收缩变化。正文移除重复标题，避免挤占模块操作区域。

## 2026-10-03 记录管理采纳 mac 模式

采纳 mac 41e5c3d 的正文主表、搜索筛选、分页、编辑历史及可恢复归档，统一展示策略目录。语义规则在筛选中统一映射旧来源 semantic 和语句 semantic_only；存储的四个分析轴保持独立。

目录状态与最新不可变语句版本分开保存，页面以最新语句为默认投影。对已选旧 DSL 则展示该 DSL 的来源语句，防止新旧正文混淆。文档语句继续以新版本修订；旧来源/手工记录编辑保存修改前快照、清除审批并退回待审。归档不物理删除来源或撤销历史审计；未来转换/加载重新校验归档标记。
