## 2026-10-03 CI 测试夹具修复

HIST-012：[首轮 GitHub Python CI](https://github.com/h3119835830/agentscope/actions/runs/37122461176) 复现 PermissionError，悬空链接测试把目标组固定为 gid=0，需要 root 权限。本地 root 执行掩盖了夹具的权限依赖。改用测试进程实际主组，仍调用真实 chown 并核验 follow_symlinks=False、外部目标不存在；没有改动生产权限逻辑或提高 CI 权限。普通 happy 用户执行全部 51 项后端测试通过；远端结果以修复后的 CI 为准。

## 2026-10-03 策略记录主表整改

HIST-013：原“策略记录与加载”以 7 个 DSL 产物作为主表，原语句和旧来源被隐藏或截断为 200 条，缺少 mac 记录管理中的检索、分页、编辑历史和归档。改为策略目录主表，SQL 以最新语句投影并先筛选再分页，合并同策略的全部 DSL/部署关联；旧来源和手工记录直接显示，文档修改走不可变版本。实际全库 282 条、20 条分页、已加载筛选及手工记录管理闭环通过。新增源版本/hash 和归档阻断回归，58 项测试通过。状态：已闭环。
