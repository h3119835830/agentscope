# ADR-20261004：外部执行 Agent 采用任务级 HTTP 拉取合同

状态：采纳；范围为通信层第一版。

1. **复用 DSH，增加通用适配器。** 保留既有 task token、Scope 请求及受管
   启动行为，增加独立 HTTP Agent 命名空间。第一版不引入 MCP/A2A 框架依赖；
   后续可在相同鉴权与状态合同上增加协议适配。
2. **拉取优先。** SQLite 持久消息与逐连接回执可重放，不要求控制面连接远端
   callback URL，避免新增出站回调与地址信任面。代价是消息有轮询延迟，DSH
   需要主动调用工具；不能宣称可立即更新运行中的模型上下文。
3. **通信凭据与审批权限分开。** 凭据绑定任务/运行/到期，只保留摘要。开发
   页面继续免管理员口令，但所有 Agent 入口都需任务凭据。
4. **Agent 报告与内核事实分表。** received/handled、scope_blocked 只是自报。
   Broker 域/PID 回查针对本机任务，不证明远程连接的进程归属。核验规则实际
   生效需要独立事件与探针。
5. **先通信，后运行时生成。** 现有第二层 Pi 保持权限范围；运行时 Pi 还未
   接入，反馈日志不自动改变权限。避免把传输功能与完整第三层生效闭环混写。
6. **隔离 profile 的 CLI 与插件使用同一依赖树。** 实验曾因不同模块实例的
   scheduler Symbol 导致 prepare 未定义。改变的是独立预览启动配置与测试
   安装，不修改全局 DSH 安装，也不追加针对模型行为的修补提示词。

取舍：第一版没有任意远端 Agent 启动、主动 session 注入、暂停/恢复或远程
内核管控能力。这些能力须由具体运行时适配器实测声明，再进入运行时快照。
