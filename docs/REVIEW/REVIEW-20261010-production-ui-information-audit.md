## 必须保留的内容

- 产品名（DeepSeek Harness 等）、当前真实 PID、原生会话名称与 ID、适配器实际提供的工作区。真实名称/路径包含实验词时不擅自改写；会话 ID 可在目录简写并支持复制，详情完整回读。
- 策略语句、block/kill/notify、单事件/跨事件、self_contained/project/task、系统/Agent/会话来源、准确的编译/确认/加载/当前运行状态。上下文需求和作用范围不能互相代替。
- 原始 DSL（缺失则未记录）、完整原始文档、编辑/导入/差异与影响预览、人工确认应用。原始 DSL 与实际加载产物分别展示。
- 内核实际操作和目标、声明动作与实际结果、可信命中映射、工具准入/结果和真实反馈回执。notify 不写阻断，kill 不默认写事前阻断；工具成功不等于全部 OS 操作成功。
- 断连、失效、失败暂停、采集覆盖、事件归属不确定等事实必须可见；可以简化措辞和展示层级，不能删除安全事实。
- 运行代次、内部连接主键、域与版本/hash 校验继续在后台使用。PID 可能复用，不能因产品界面按 PID 识别当前进程，就把后台持久归属和防混入校验改成仅 PID。
