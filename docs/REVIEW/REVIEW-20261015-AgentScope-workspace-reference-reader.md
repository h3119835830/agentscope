# 工作区正文读取与策略生成验收

日期：2026-10-15。

## 完成内容

新增实例参考目录与正文读取 API，采用固定受控 UID/GID 的独立读取程序；校验资源、typed/DSL 读取约束、路径、对象类型、链接、字节限额和文件新鲜度。只保存并向模型提供经过权限校验和脱敏的选定材料。

模板生成接受服务端读取回执，模型同时获得系统约束、实例权限、资源事实和已发布模板；共用物化器拒绝未知模板、任意 DSL、额外字段或范围扩张。子配置与生成记录保留可读的资料来源摘要；提交和应用前重读校验，审批列表使用元信息检查。

策略助手增加按需展开的参考目录/文件选择、显式读取和折叠正文依据。选择变化、读取失败或迟到响应不能静默替换资料；待重读期间禁止生成，取消参考是明确操作。原统一范围入口和人工批准/应用保持原合同。

## 已有测试与真实模型证据

最终相关后端回归 132 项通过，其中正文读取专项 45 项；前端 300 项通过，其中新增读取交互 9 项；生产构建与 diff 检查通过。覆盖旧来源失效后的明确停用，以及人工改版不继承旧模型资料绑定。

隔离 18155 HTTP 验收使用新建合成项目、独立数据库、不可用 Broker socket、关闭全部执行 worker。没有启动 DSH/Hermes 或调用正式审批/应用。真实文件读取使用 happy UID / agentscope-task GID，真实模型从 README 正文取得员工资料位置，输出已有 FILE-READ 模板与 /w/0/internal/staff.csv 参数，中文名称“禁止读取员工档案”。模型生成本次样本耗时 1.299 秒，不作性能保证。

验证了读取和生成重试幂等、跨实例回执拒绝、root 可读但读取 UID 不可读文件拒绝、符号链接/越界/凭据文件拒绝；正文变化后旧回执和旧生成重试被拒绝。正式 API、Broker、Agent 身份、权限和 18000/18004 在隔离验收前后相同。精简证据见 evidence/workspace-reference-reader-20261015/real-provider-api.json。

## 失败与修正

初次降权测试使用 nobody UID，开发代码所在 happy 私有目录不可遍历，导致程序启动被 OS 拒绝。测试改为把相同读取程序字节复制到公开测试目录，再验证公开夹具可读、0600 夹具拒绝；生产读取程序安装在 root 持有的 /opt 目录，不放宽开发目录权限。

首次 HTTP 验收误把现有 invoke 合同的冲突响应写成 400；实际为 409，已修正测试预期，未放松服务端拒绝。前端有一次用需求文本与正文的共同短语判断是否传了正文，误报；改为直接核对生成请求仅携回执、无 files/workspace_reference，原请求没有传正文。

新增人工改版验收发现旧手工保存版本只依靠前端默认值显示“手工配置”，没有显式 origin 字段。现已由手工保存服务端明确写入 origin=manual；模型生成仍为 origin=assistant，人工版本不继承 source_read。

## 边界与发布

正文读取不是原 Agent 自己的系统调用，本轮证据不作为新增内核拦截实证。读取守门对条件 DSL 保守拒绝，可能比实时策略更严格；参考目录是已登记资源目录，不宣称是原生工作区目录或独立执行域。

遵照用户“不用 computer use”，本轮不操作浏览器；页面交互由组件测试、转义 HTML 和生产构建验证，正式端由 HTTP 与资产核对验证。没有像素或真人浏览器截图验收声明。

发布前检查完整 diff、保持普通业务零改动、先本地提交再进行保留 Broker/Agent 身份的 API/UI 切换。正式发布结果、HTTP 哈希和最终测试计数补录本文件。未经用户新许可不推送远端。
