# REVIEW — 当前本机新版合入 main

日期：2026-10-07。用户已明确授权将当前本机新版推至 main。此前 WINDOWS 发布范围和等待 main 审批的记录为历史状态，本次以该新授权为准。

## 发布内容

在已推 WINDOWS 的 7cd8a59 上纳入当前本机的 DSL 归一化及来源关联、受管启动与 cgroup 清退、本机无登录页入口、服务托管/恢复及相应测试、文档和公开证据。原开发工作树保留，不在其上切分支、重置或提交。旧版 Pi 工作台不覆盖当前工作台；不包含无关 ERP/Java 业务、数据库、凭据、原始模型会话或依赖目录。

本机入口在整理期间继续更新。发布候选已跟进删除旧登录页、票据、Cookie 会话和相应测试/脚本；已重新执行最后版本的完整后端及前端检查。机器清单记录每个本机文件的哈希和删除项。
