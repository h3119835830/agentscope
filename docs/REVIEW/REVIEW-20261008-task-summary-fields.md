# REVIEW：任务记录优先与辅助技术信息收敛

状态：实现、独立复核、前端回归及真实页面验收通过，2026-10-08。

## 需求与实现

用户主要阅读历史任务的策略记录及其详情。任务编号、源/执行绝对目录、会话和创建更新时间不再默认展开；运行前页从“工作区文件证据”开始的辅助区也不再逐项外露。

- 历史运行前/运行时恢复原六列表格：时间/作业、策略语句、生成/审核、编译/加载、版本、语句/DSL详情。沿用原表格样式；每行保留精确语句身份，缺失材料禁止打开。实际审核、编译、历史加载分别显示，指导不会冒充OS规则。
- 当前工作台的文件证据、生成过程/工具结果、版本与内部元信息统一放进一个默认关闭的“技术详情”。确认、澄清及失败恢复操作仍在外侧。
- 历史策略页将来源信息、生成记录、文件证据、生成过程、工具结果、版本及原始阶段事件收进一个默认关闭的技术入口，保留原懒加载与分页。语句筛选、分页和逐条详情直接可用；运行时Hook与审计未改。
- 历史概况保留状态、目标和约束，技术元信息按需展开；工作台标题保留可识别的工作区名称。

独立只读复核无阻塞：精确语句详情、声明级DSL、审核/恢复、任务关联、分页、Hook和审计均保留。历史加载回执仍明确标为历史。
