# REVIEW：安全亮点公告交互与 trace 对照设计

日期：2026-10-09。状态：v2 设计稿已验收，待用户评阅；本轮未更新正式控制台。

## 本轮范围

用户要求公告改为首页按钮，首次进入展示、叉号关闭，并用工具调用 trace 与系统侧事件呈现具体安全场景。本轮仅制作独立可点击原型，不修改正在运行的 18003 控制台。

原型入口：`docs/home-notice-design-20261009/index.html`。样式与交互在同目录 `notice.css`、`notice.js`。

## 设计候选

首页按钮固定为「安全亮点」。一个公告版本在同一浏览器自动展示一次；关闭后刷新不再弹出，但按钮始终可重新打开。此持久化是设计候选，不等同于运行中的前端已改为该行为。

一次只看一个案例，按「执行与数据」「授权与流程」分组，每组 6 项。默认展示插件自行外联。左侧按场景显示工具调用、用户与应用事件、会话上下文或审批过程；右侧区分系统侧、流程门禁与控制面事件。无工具调用的案例不伪造调用 ID；内核拒绝与控制面暂停分别标注。

保留脚本偷读凭证、链接越界写入、篡改验收证据、后台继续写入、跨任务越权、伪造扩权审批六个案例；新增插件自行外联、跨进程数据外流、上下文丢失约束、验收结果过期、审批后对象变化、保护尚未生效，共 12 个。

用户要求说明以人物、文件和过程表达。本轮给全部案例补齐具名用户、任务、文件或审批对象、三步过程和结果；原折叠项改为「案例过程」，公告正文移除反复强调未实测的文案。设计属性与实现覆盖仍在技术文档中准确记录，不将静态案例改记为运行时证据。

## 证据与安全边界

- 全部 trace 是明确标注的设计样例，没有读取凭证、访问外部目的地或执行恶意脚本。样例状态不能记入安全验收成绩。
- `execve`、`openat` 是系统调用；`file_open`、`file_permission` 是内核安全钩子。进程绑定、对象解析、审批和加载门禁分别标注，不统称为内核拦截。
- 右侧展示关键行为链，不能被理解为当前产品已有完整 syscall 采集。正式接入必须验证采集来源、真实工具 schema 和可证明的同次执行关联。
- 工具返回成功与内层访问拒绝并存的案例，明确解释为插件忽略了读取失败。其余访问拒绝与工具错误相符。
- 链接、已有 FD、mmap、异步 I/O、跨任务 IPC 与网络覆盖均需真实验收，设计稿没有扩大现有保证。
- 插件自行外联要求插件在受管进程域内，不能泛化到受信 DSH 宿主和模型传输。数据外流案例限定文件读写传播与新建连接；不声称检查 HTTPS 内容或所有通信通道。
- 验收过期案例中的代码版本与回执绑定发布门禁属于设计候选，不能据论文的命令时序机制宣称现有工程已完成这一发布集成。
- 审批后对象变化复核已确认快照与实际执行副本；保护尚未生效区分编译、批准、加载、绑定和真实效果，不把控制面暂停描述成内核已拦截。

## 验收

本轮 Node 语法检查通过，浏览器检查 65/65 通过，桌面 1280×720、手机 423×900、窄屏 320×800。覆盖更新版本首次展示、关闭记忆、手动重开、Escape、双向焦点循环、两个分类与 12 案例切换、人物/对象/三步过程/结果、无工具调用不伪造调用 ID、暂停与拒绝区分、横向溢出及浏览器错误。

v1 首次焦点检查发现原生 dialog 的 Tab 边界会移到 body；修复及历史检查保留在 `docs/home-notice-design-20261009/evidence/browser-checks.json`。本轮桌面初次测量发现视口覆盖作用于不同标签，重置后选中独立设计标签并确认实际尺寸，12 案例复检通过；过程与最终结果保存在 `evidence/v2-cases/browser-checks.json`，未抹去初次测量记录。

验收仅证明原型交互与呈现，不证明本机内核防护效果。没有构建或部署正式控制台，没有 API / Broker / DSH 重启，没有审批、加载或策略绑定操作。
