# REVIEW：模板配置 Agent、模块界面与会话安全预览

日期：2026-10-14。范围：读取用户指定对话、图片需求、源码能力及现有合同，形成架构/界面设计并检查本地示例预览。本轮未修改应用/DSH、未触发真实模型或内核策略、未重启/部署服务。

## 需求映射

| 来源 | 需求 | 设计落点 |
|---|---|---|
| 图片 | 每个会话能看清全部当前约束，像 App 权限页一样配置 | 会话当前约束表、参数详情、DSL、通用约束和只读安全检查 |
| 图片 | Agent 可动态配置，参观者能看见 | 同一配置 Agent 的两阶段候选、模板子记录、统一审批/应用及执行证据 |
| 指定对话 | 模板内填参，通过接口，结果像手工配置 | 受限工具白名单、同一 ConfigDraftService 和配置版本，后台确定性生成 |
| 指定对话 | 静态模板下保留多个已做好的子配置 | 版本化父模板与独立同级记录，不对应域继承，不覆盖其他配置 |
| 当前对话 | 接受共享进程，固定到 Agent，其余运行时新增 | 系统/Agent 基线、真实域运行时增量与同域一致视图 |

## 核查边界

当前 `history/capabilities.py` 明确读取/变更访问组及 source/运行反馈边界。两条意图配置不能当成写入/删除已分离；配置存在/批准和实际活动/拒绝/反馈分别展示。没有因图片要求“全部安全约束”就声称具备全部 OS/工具能力。

本地预览为合成示例，只演示导航、运行前/运行时、模板子记录、批准与模拟应用分离、共享会话投影和未支持停用。它不连接真实 API/ActPlane，不向业务场景目录写入指导，不调用模型，不代表接口安全或生产运行验收。
