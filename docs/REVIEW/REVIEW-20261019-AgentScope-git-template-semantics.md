# REVIEW：Git 模板细分、能力边界与其他模板审查（2026-10-19）

## 结论

按动作与跨事件条件拆分 Git，发布 10 个专用模板：6 个有限支持，4 个暂不支持。Git 本地清理的 reset/clean/stash 可通过同一参数匹配合同选择，因此不按每个 token 再复制模板。路径、程序、地址等资源值不同只创建子配置。

## 其余模板逐项审查

| 现有模板 | 判断与理由 |
|---|---|
| RQ1-ENV、FILE-READ | 都是读取路径限制，前者已有助手别名；路径更换不需新模板。保留兼容，不新增分类。|
| RQ1-CONTRACT、FILE-CHANGE | 都是路径变更限制，前者已有助手别名；操作意图仍保存，当前写入/删除共同覆盖必须确认。|
| WRITE-BOUNDARY | 有范围与例外两个参数，语义区别于普通文件保护，保留独立，不按目录复制。|
| RQ1-GENERATED | 执行链约束独立；producer/path 足以换资源，不拆成 Python/Node 等模板。|
| RQ1-DELETE | 提醒型预设，操作与路径可参数化；本次不改旧默认行为，不新增“删除某类文件”模板。|
| EXEC-BLOCK、EXEC-AUDIT | 同类程序执行事件但默认处置不同；既有独立预设保留，程序变化只填参数，不按程序细分。|
| NET-BLOCK、NET-AUDIT | IPv4 新连接事件；地址/前缀参数足够。DNS 名称、已有连接发送是缺少执行能力，不能当作现有参数可覆盖。|
| SECRET-EGRESS | 来源路径与连接目标已参数化。读取后建立连接是跨事件，不等于提交内容或所有网络发送；本次不添加缺少后端的“完整外泄”模板。|
| REMOTE-EXEC | 网络来源后执行事件；程序已参数化，不按 shell、解释器拆分。内容/签名校验属于其他语义，暂不实现。|
| SYS-env | 后缀匹配；.env 等值使用同一模板。|
| SYS-ssh、SYS-cloud | 路径后缀匹配的领域预设，匹配对象可改，不再按不同密钥/云服务拆模板。|
| SYS-system-files | 绝对文件匹配；不同系统文件只改对象参数。|
| SYS-policy-store、SYS-audit-store | 目录匹配的领域预设；路径、操作、动作已参数化，不按项目复制。|
| SYS-instructions | 文件名匹配；AGENTS.md 等文件名使用参数。|
| SYS-privilege、SYS-process-audit | 程序匹配预设；程序名与动作可配置，无需按 sudo/su 等拆分。|
| SYS-network-audit | IPv4 新连接记录；地址与动作使用参数，不宣称完整流量审计。|
| SYS-secret-egress | 敏感文件后缀→连接的预设；不同后缀只填参数，指定连接目标已有 SECRET-EGRESS，不再造重复模板。|
| SYS-remote-exec | 网络来源→执行的预设；程序可填参数，与 REMOTE-EXEC 重叠但保留已有合同。|
| RQ1-GIT、RQ1-CHECK | 本次细分；历史版本和配置保留，禁止自动改写已有审批或运行策略。|

未发现其余模板需要立即进行“改参数无法表达且当前后端已有执行能力”的新增细分。领域预设重叠是未来合并议题，本次不改动。

## 验收与证据

- 后端全量 1408 通过，含真实编译、所有/指定 Agent 范围、审批不加载、单独应用、停用审批、参数拒绝与不支持能力的三条提交路径。
- 前端 352 项及 Vite 构建通过；退出码 0 正确显示，不支持草案禁用提交。
- kernel-results.json：13 项隔离真实 Git/ActPlane/BPF，使用独立 pin root、合成仓库、本地裸仓库和专用检查程序。验证 notify 允许继续、选择 token 不影响未选项、commit/push 检查成功放行，缺少/失败/检查后写入均终止命中 Git 进程。
- 该实验的 CLI 事件文件归 happy（UID 1000），不能宣称它提供生产 root 审计日志的防篡改保证；另有测试控制端捕获的子进程返回码及导出的证据。未将 kill 观察解释为副作用发生前的阻断证明。
- service-results.json：独立 18169 数据库、真实模型选择 GIT-COMMIT 与 GIT-PUSH，填写真实参数，所有 Agent 范围；指定实例手工保存检查参数。仅保存、不启动 Agent、不加载策略。
- legacy-contracts.json：54 个历史定义哈希未变。浏览器保存后原始 DSL 显示新的 exits 2；不支持的目标限制没有可用提交按钮及伪造 DSL。
- 桌面、小屏、正式 18003 发布与保留状态证据在同目录。正式环境只发布代码/UI，不创建验收策略或变更用户配置。

能力边界与接口见同日 RFC、决策见 ADR、问题闭环见 BUG。
