# 每轮策略配置快照验收

改动限于生成结果附带快照、历史只读投影与助手消息中的展示；详见对应 RFC、ADR、BUG。没有改动 DSH、Broker、ActPlane、模型提示词、手工配置或审批执行合同。

## 核验项目

- 生成完成状态、配置版本和展示快照在同一事务持久化。
- 后续配置、模板、Agent 名称变更不能覆盖旧轮次内容；幂等重试返回同一生成内容。
- 状态匹配配置编号、生成版本和精确作用范围，不能借用更新版本的审批。批准仍不加载，应用仍需显式操作。
- 所有 Agent 与指定 Agent 历史分开读取。旧记录只能通过不可变版本恢复，缺失内容不推测。
- 页面只有一个需求输入框，附件入口不变；没有增加手工配置或修改模板的入口。窄屏正常换行，消息可以内部滚动。
