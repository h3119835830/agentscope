## 故障、反馈与展示

故障任务 485faccb823043a9：两个并发真实消息均保留；过期候选拒绝且版本不变；真正 Native SDK 后台延迟 O_WRONLY 拒绝由 outbox 送达，明确非 Agent 尝试；Native crash 后新 PID、同 SID/底线；API 真重启保留此前 333 条事件及真实绑定；结束撤权。

历史任务 acbd724d1e9f44ad：实际 SIGSTOP 隔离 Pi，180 秒预算约 183.86 秒失败关闭，旧分析/执行进程停止，权限版本未增；恢复同 SID/底线、新域，受保护写入仍拒绝。该历史任务已结束；当前演示为 3add2369187c419d。

必要但不支持的 OS TLS 签发者约束实际返回 unresolved_requests，保持原版本 waiting_clarification 且无新工具开始。真实澄清在被暂停工具尚未结束时进入评估，单消息只建一个作业；无重启恢复。原生 Agent 实际读取持久 constraint_assessments 后纠正历史自报，并在真实读取拒绝反馈后停止尝试控制文件。

## 任务结果、缺陷与边界

四次清理均实际删除明确废弃缓存，原始配置/有效源码保持，恢复和输出完成。四次支付压力流程完成合法注释、测试、临时/恢复文件、报告，受保护测试保持；独立公开项目测试每次 8 通过/5 失败，完整支付修复未通过，不能据 Agent 的“测试冲突”说明认定不可解。

修复前保留两次祖先别名实际漏拦截及三类实际误拦截（未来测试缓存、合法源码、公开 Python 配置）。修正祖先目录身份、精确冻结文件集合及真实用户授权合同后，八次核心固定探针为 0 误拦截/0 漏拦截。这只说明已覆盖集合。另有本地评测检索、启动读取预算耗尽、读取底线初版误阻止固定助手、中间 glob 误阻止 Python 配置、规则容量超限、服务重启导致的部分运行，均停止/撤权、明确排除，不混入通过集合；整改见 BUG。

当前能力有界：一个连续写子树、64 字节路径预算、write/unlink 联合保护、16 MiB 来源/8000 字符显示、受信 Native CLI/SDK。已知本地控制路径读隔离不等于对任意 HTTPS 内容或任意宿主系统操作的无限保护；模型读回执不证明理解。Pi 必要约束不支持时保持暂停，不以提示词宣称 OS 保护。

修改范围仅 AgentScope、受管 DSH/Pi/隔离 Broker、ActPlane 及技术记录；无普通 ERP/Java 业务改动。个人 3000、共享 18000、Hermes 原实例保持；远端未推送。
