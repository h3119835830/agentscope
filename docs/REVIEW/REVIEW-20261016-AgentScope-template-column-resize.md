# 模板主表可调整列宽验收（2026-10-16）

按用户截图要求，七个模板主表字段的右边界可拖动；列宽临时保存在组件状态，浏览器刷新及页面“刷新”均恢复默认值，不使用 localStorage / 服务端存储。默认像素宽度依次为 200、300、190、108、88、76、152，总宽 1114。表头与记录通过同一 colgroup 对齐，每列有下限 / 上限；超出容器时表内横向滚动，不以固定列覆盖相邻内容。方向键微调，Shift 加大步长；拖动使用 Pointer Capture，松开 / 取消 / 失去捕获停止调整。不改变子配置表、会话同级导航、审批或 DSH。

322 项前端回归及 Vite 构建通过。新增交互回归覆盖仅调整目标列、错误鼠标键 / 指针被忽略、连续拖动以起点计算、最小宽度、松开后不再调整、键盘调整、两种刷新还原及不写策略 API。实际浏览器以真实 GET 数据检查：说明从 300 拖到 440；向左拖到下限 180，再键盘增到 190；页面刷新和浏览器刷新均恢复默认数组。筛选时保留临时 440 宽。表格聚焦后方向键横向滚动 scrollLeft=39，整页无横向溢出；子配置表无新增调整把手且字段保持原样。

此次纯前端交互，不涉及 RFC / ADR 中执行范围或跨服务合同变化，后端测试未重跑。前端资源发布、服务进程 / 策略状态核对及截图记录于 evidence/template-column-resize-20261016。
