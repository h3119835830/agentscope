# AgentScope 安全亮点公告设计稿

2026-10-09。状态：可交互设计稿，尚未迁移至运行中的控制台。

入口为 `index.html`，与同目录的 `notice.css`、`notice.js` 一起打开。当前本机预览地址为 http://127.0.0.1:18121/ ，仅绑定回环地址。

## 展示与交互

- 首页右上角只放「安全亮点」按钮。首次进入自动弹出，叉号、Escape 或「知道了」关闭；关闭后可用按钮再次打开。
- 设计稿按浏览器及公告版本保存关闭状态，刷新不会重复弹出；更换浏览器或清除站点存储后视为首次。设计稿使用独立存储键，不读取正式控制台状态。
- 六个场景每次只展示一个。工具调用与系统侧关键事件并排，移动端上下排列；红色只标记拒绝点。
- 关联字段置于 trace 下方；新增价值一句话表达；链路说明与能力边界折叠。
- 伪造审批场景显示「控制面 trace」，与系统调用、内核事件分开。

## 数据与边界

所有工具名、参数、返回值、调用 ID、PID、域、策略版本、规则与时序均为设计样例，不是历史事件、当前在线观测或验收结果。没有执行工具、系统调用、策略加载或审批。示例里的 `DENY` 只是展示文本。

正式接入须以实际采集 schema 为准，区分系统调用、内核安全钩子、进程绑定和控制面事件；缺失的关联字段不能用相近时间或页面顺序补成已证实的因果链。只有内核命中事件时，不能将其展示为完整 syscall trace。
