GitHub 自动采集遇到仓库内 AGENTS.md 软链时拒绝是保留的安全行为，并非绕过目标。增加 include_instruction_files=false 支持只采集指定证据；首次失败作业保留。

观察到基础工作区边界阻止 DSH 原生 addon 向任务目录外的临时缓存写入。DSH 会话仍成功退出；该事件属于基础限制，不计入任务保护策略的内核效果。独立合法操作探针没有误阻断。未扩张基础写入权限以消除此事件。

页面职责调整追加复现：423px、侧栏展开时，页头状态区域最小宽度导致整页多出7px横向滚动。为页头面包屑/状态组及状态标签设置可收缩和断行，压缩间距；最终423px两种侧栏状态的 scrollWidth 与 clientWidth 均为408，表格独立滚动。筛选控件增加明确无障碍名称，搜索标签保持完整一行。证据位于 REVIEW/AgentScope-history-ui-20261004。
