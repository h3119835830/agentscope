# 安全总览图解与公告阅读合同

状态：此前实现及静态发布记录；用户要求后续恢复旧版，当前场景布局以 RFC-20261013-restore-original-security-overview.md 为准。本文的公告生成与静态发布合同继续适用。整合基线 `e1af002`。关联原始研究与证据：`docs/research/value-reliability-20261012/`。

## 用户入口与阅读顺序

总览保留 Agent 状态表和实时核验时间，在首屏并列提供“安全总览”和“阅读公告”。安全总览默认打开测试插件场景，先呈现批准任务，再以“工具层能看到 / 系统实际约束的行为”并排说明，最后给出一句具体价值。十二类场景通过导航切换，完整记录表作为次级入口。已有防护、攻击者能力、适用边界和实验依据按需展开。

公告从仓库维护的 announcement.md 生成 `/value-announcement.html`，包含完整正文、文章目录和实验报告链接。生成器只接受 HTTP/HTTPS 文本链接并转义内容；源文件哈希置于页面 meta，避免正文堆积内部诊断。它是本地产品阅读页，本轮没有外部渠道发布。

## 证据模型

图解按既有实验结果整理，不冒充原始系统调用记录；不加入虚构 PID、毫秒时序或测试通过数字。只有 evidenceFor 返回完整已验证实证时，图解显示允许/拒绝的实测处置。证据缺失或失败时，标题、处置色彩与结果文字一起降级到待验证说明。复用来源实验的同地址场景不增加独立实验数量。

实证、源码依据、延伸设计继续分级；历史实验不能证明当前 Agent 正受保护。图解和公告只读取静态内容，没有策略提交、批准或应用操作。原有审批及目标隔离合同不变。

## 交互与发布

桌面保留场景导航和并排图解，390 像素窄屏改为下拉选择和单列图解。原生 dialog 管理焦点，场景切换聚焦标题，Escape 关闭并归还触发入口。公告提供返回总览、段落导航与打印样式。
