# RFC：Agent 工作区、任务创建与记录界面

日期：2026-10-07。状态：本机 Scope Demo 18003 已实现并验收。

## 问题与主流程

旧“切换工作区”实际选择历史任务；任务工作台与“任务与启动审核”分别显示同一任务，后者使用长篇候选文档、完整 DSL 和 JSON。用户无法区分执行端、文件目录、任务与策略版本。

控制台主流程改为：Agent 与工作区 → 选择工作区及文件 → 新建任务并生成场景策略 → 确认策略 → 跟进 Agent 执行 → 查看任务记录。控制台显式选择任务，不自动选择唯一活动任务。保留任务、Session、进程及策略域的服务端安全关联。

## 对象与职责

| 对象 | 身份与权威 |
|---|---|
| Agent 执行端 | 当前适配 DSH。实时检查 Broker 返回的执行端配置，连接登记不等同于任务进程在线 |
| 源工作区 | 管理员选择的真实目录，有独立 workspace_id；文件列表来自目录扫描与字节哈希 |
| 任务工作区 | 新任务独立复制的文件快照；Agent 在此执行，源目录保留 |
| 执行工作区 | DSH 已建立会话的任务目录，登记后可以作为后续任务的源目录，读取 Agent 更新后的文件 |
| Pi 候选 | 读取任务与登记证据、检索历史、提交受限策略候选；没有加载权 |
| 控制面 / Broker | 校验证据、编译、绑定确认并加载；执行状态须单独核验进程、domain、cgroup |

新建任务明确显示源目录、文件清单和快照执行说明。工作区文件不会随历史任务选择而改变；结束任务保留记录和可读取的执行目录。旧 RQ5 示例工作区按场景迁移最近可读目录；原始任务历史仍按 task_id 保留。

## 接口合同

| 接口 | 合同 |
|---|---|
| GET /api/workspace-agents | 执行适配器、配置可用性、连接登记和任务记录计数；不伪造在线进程 |
| POST /api/workspace-agents/{agent_id}/connect | 检查已支持的执行端并登记连接；当前仅 DSH |
| GET /api/workspace-agents/{agent_id}/workspaces | 登记文件工作区、既有受管目录及已建立 DSH 会话的执行目录 |
| POST /api/workspace-agents/dsh/workspaces | 创建文件工作区，或登记操作员配置根目录内的现有目录 |
| GET /api/agent-workspaces/{id}/files | 返回路径、类型、大小、哈希、manifest_hash 和读取时间，不返回凭证内容 |
| POST /api/agent-workspaces/{id}/tasks | 以 expected_manifest_hash 比较文件清单；变化则拒绝；保存独立快照与来源绑定 |
| GET /api/workspace-tasks | 任务字段、源目录、历史阶段、最近策略版本；目录缺失不抹掉历史记录 |
| POST /api/managed/tasks/{id}/startup/confirm | 绑定当前 context_hash 与 proposal_hash，复核候选、执行端配置和任务文件；确认不等于加载完成 |

接口沿用管理员认证中间件；本机实例原有回环访问设置不在本次修改范围。新增 workspace_agents、agent_workspaces、workspace_task_sources 表，不删除或重写旧任务证据。

## 状态与展示

普通工作区任务：prepared → generating → policy_review → 确认 → generating（启动加载）→ running；失败为 failed，结束为 ended。未确认时没有策略版本、Session 或 Broker 加载。确认后，真正加载前再次核验快照和执行端配置。既有预授权 RQ5 场景 API 保留原合同，不再作为控制台新建任务入口。

任务历史显示字段及四个分页：场景策略、工作区证据、生成记录、策略版本。规则列表显示类型化操作的中文要求、保护对象、校验状态；原始语句、依据、证据数和对应规则 DSL 在单条详情内。任务指导按记录展开。完整候选文档、整包 DSL、原始 JSON 不再作为任务主界面。

任务工作台继续显示真实执行核验、策略记录与审计。保存的 Session/PID/版本不能单独证明当前有效；已结束任务的版本标记为“历史加载”。

## 文件边界与限制

目录须位于 WORKSPACE_ROOT 或操作员配置的 AGENTSCOPE_DSH_WORKSPACE_ROOTS 内，拒绝路径别名、符号链接和越界目录。扫描逐级使用目录 fd 与 O_NOFOLLOW，读取常规文件；限制 1500 文件、单文件 16 MiB、合计 64 MiB。排除 .git、.actplane、.dsh、.venv、node_modules、__pycache__、.env 系列及 .credentials.yaml。文本证据最多保存 256000 字符/文件；二进制文件保存元数据证据，快照字节保留。

当前清单是 DSH 适配器管理或显式登记的工作区，不代表已经发现任意外部 Agent、个人 DSH 3000 或远程机器目录。未新增执行者权限、远程凭证或生产业务依赖。

实现位于 WSL /opt/agentscope-history-v1 的 workspaces、managed/controller.py、TaskHub.jsx、AgentWorkspaces.jsx、main.jsx 和 ManagedWorkbench.jsx。验收见对应 REVIEW 与 BUG。
