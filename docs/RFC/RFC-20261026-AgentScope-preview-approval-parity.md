# RFC：助手与审批的隔离预览一致性

日期：2026-10-26。状态：修复并隔离验收；正式服务未修改。

18176 仅重放已保存的资料，不是生产流程。助手快照显示已应用时，预览必须同时提供对应范围、配置 ID、版本的真实审批记录与详情。禁止按同名记录补造审批；缺少对应回执时拒绝启动不完整预览。

新增 policy_preview_approvals.mjs：verifyApprovalReplay 验证生成快照的配置版本、approval_revision、approval_current、scope、applied 状态与文档 ID；approvalResponse 只读投影审批列表、已清理列表和按真实 ID 编码的详情，隔离其他目标。预览将可批准、应用、拒绝、清理、恢复等写能力置为 false，状态仍保留真实历史事实。未录入的 API 返回明确的 501，不再用 200 空 records 代替未知页面。

预览仍仅监听回环地址，所有写请求由最外层拒绝，无上游写代理。更新预览启动回执写入新的验收目录，不修改原失败结果或上一轮冻结数据。生产配置、审批、加载、内核状态与历史快照是独立事实。
