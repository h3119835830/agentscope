# AgentScope 记录模块视觉合同

日期：2026-10-09。范围：18003 原生控制台 Agent连接、策略工作台、任务历史、历史策略库、持久治理。总览保留现有布局。

## 问题与职责

总览已使用状态标签和卡片层次，但后续模块仍将连接状态、安全覆盖、处理结果等展示为普通文字，表头和记录区域缺少层次。共用呈现层负责改善可读性，不计算或提升后端安全事实。

## 接口合同

- `RecordBadge` 只接收原有文字及可选 tone、dot、mono，渲染文字与颜色标签；不请求 API，不修改状态。
- `recordTone` 采用明确标签映射；未知标签为中性。已编译、已加载为蓝色；已核验为绿色；暂停、过期、未核验为橙色；失败或拒绝为红色；行为约定和历史连接状态为紫色。
- 连接历史保留“最近历史状态”和“历史状态不代表当前在线”；历史任务“已结束”保持中性，不能据此宣称成功。
- `main[data-page]` 为样式作用域。记录模块统一浅色表头、白色表体、斑马行、悬停提示、带底色的字段值、蓝色操作按钮。入口与版本使用紫色，PID 使用等宽蓝色标签。
- 不改 API、事件处理、确认流程、规则生成、策略编译/加载/执行和核验逻辑。已有“已核验”文字的证据有效性不是本次 UI 修改的结论。

## 布局合同

桌面连接表格在 1146px 和 1280px 视口内完整显示操作列。窄屏保留操作列最小宽度及按钮不换行，由表格容器横向滚动；页面自身不能横向溢出。详情使用原有抽屉与页签，保留渐进展示。
