# RFC：按原任务工作台模式回放历史任务

状态：已实施；真实只读回放、桌面与 423px 验收通过，结果见同名 REVIEW。

## 目标与页面合同

历史任务列表选择一项后，在任务历史模块内进入全宽任务回放页。沿用原任务工作台的任务标题、任务选择、主栏目和逐条记录详情模式，保留运行前策略、运行时策略、执行监控、执行审计，以及任务概况和结束结果。完整任务不再仅放入侧边抽屉；逐条证据仍可就地展开。列表搜索、状态、分页和滚动位置在返回时保留。查询历史不替换当前工作台任务。按用户要求移除工作台右上重复的“历史策略与审计／任务回放”按钮，统一从侧栏“任务历史”选择任务；读取场景后的实时工作台流程保留。

运行前策略保留文件证据、生成过程与工具结果、策略版本入口。策略详情按语句与类型、上下文、DSL、加载组织。执行监控显示历史域图、版本和已记录进程。审计分别展示 OS 拦截与核验、DSH 工具调用、控制面动作；不把工具失败等同内核拒绝。

执行监控沿用关系图、OS 文件操作、关联进程、权限范围四个内部模式。文件资源关联严格核对 task_id、version、domain_id；已载入审计不能冒充全量系统操作。长字段、来源目录和缺失材料说明默认折叠。列表同名任务以创建时间和短 ID 区分；顶部任务选择器明确仅为本页历史，跨页使用列表搜索与分页。

## 数据与权限合同

复用现有 task-archives、archive、archive/events、archive/policies、archive/audit、archive/domains 的只读投影，不创建第二份策略数据，不调用当前受管工作台、Broker 探测、模型、工具或权限加载。所有材料按 task_id 关联，版本切换只读取对应已保存加载回执及经 hash 核验的 DSL。旧 task_id、原始来源和证据引用保持不变。

当前任务最后的历史状态不代表某个所选旧版本的完整 Scope。缺少该版本冻结的结构化 Scope 时明确未记录，不能套用当前 managed state。历史 PID 不核验为在线，也不凭 PID 补造子进程或域成员。缺少底线包预期 hash 时不展示为可信 D0 DSL。运行前生成/校验、人工审批、历史加载与当前生效分别表达。

## 旧 RQ5 任务发现

当前演示数据库已有 117 个 OpenAgentSafety 来源任务，无需切换或导入其它旧库。默认已结束筛选会隐藏未记录结束时间的旧失败任务，因此提供“查看全部旧任务”和“OpenAgentSafety 场景”快捷筛选。任务按逻辑 task_id 区分，不按工作区合并；快捷入口使用来源搜索，不硬编码某一任务 ID。
