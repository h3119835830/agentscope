# 控制台与执行面独立保活、价值证据合同

状态：隔离验收通过，已部署到正式 18003；24 小时观察进行中，不能据此认定长期稳定性已通过。发布与证据见同日 REVIEW。范围仅 AgentScope 与隔离 Agent 运行层。

## 职责和信任边界

控制台 API 负责候选、编译、目标冻结、人工确认和数据库投影。root Broker 负责已批准的启动策略、精确进程身份、cgroup、执行域、watch、内核对象、工具准入及持久回执。ActPlane 负责已覆盖系统操作的规则判定。原生 Agent 只能申请策略，不能签发批准或更新 Broker 的保活证明。API 健康不是内核保护证明。

此前 Broker 每秒读取控制台 `/api/health`，8 秒失联即停止全部受控实例。控制台发布、历史统计拥塞和执行保护丢失因此混为一谈。新版本每秒核验 root 创建的执行对象：generation、策略及 DSL 哈希、watch 和 anchor 的 PID/UID/start_ticks、cgroup 路径/inode、BPF pin 对象身份、watch 策略内容；就绪后另核验原生 Agent PID 身份、cgroup 成员和内核域成员。冻结指纹不一致即关闭准入并终止。Broker 停止或卡住时，独立 runner 仍在 8 秒心跳期限后终止。工具准入的证明有效期为 3 秒。

这不是对抗 root、内核漏洞或恶意管理员的保证。当前核验检查对象身份与可信加载流程，未独立逐字节证明每个 BPF map 内容；root 属于信任根。原生会话仍共享实例执行域，不能宣称会话之间已经隔离。

## 本地执行合同

原生 gateway 的 `/lease` 和 `/result` 在 Broker 内处理，不依赖控制台。身份必须包含 generation、session_id、call_id、tool，generation 必须精确匹配；Bearer token 仅对应当前实例。Broker 冻结已批准的工具规则；deny 和 confirm 不作为 allow。系统/实例/DSL 的策略变更在修改数据库前关闭 Broker 准入门，编译、加载和新运行核验成功后才允许打开。

SQLite 执行队列位于状态目录 `execution-queues/<instance>/admission-<generation>.sqlite3`，末级目录 root:0700、文件 root:0600，拒绝符号链接、不可信属主和宽权限。lease 的 start 记录提交后才能放行；result 必须对应已准入的同一调用，并先持久提交。最多 4096 条待同步记录；准入前为未完成调用预留 result 空间，容量不足暂停新工具。每代最多保留 65536 个调用身份，ACK 不移除完成调用的防重放墓碑。达到上限时要求确认后换代。

控制台按 `(instance_id,generation,sequence)` 及事件哈希事务写入接收凭据；提交后才 ACK。ACK 丢失允许重放同步，不允许重放工具执行；已提交的相同序号内容变化必须拒绝。旧 generation 不可并入新运行。Broker 重启不从队列、数据库快照或历史 PID 恢复授权；先按可信 manifest 清理旧执行域，只能走新的正常启动和保护核验流程。

`/scope`、策略申请仍需要控制台；不可达返回等待恢复与可重试信息，不产生已批准假象。本轮未新增自动提交策略申请的离线 outbox，原生调用需恢复后重试。工具结果队列与策略申请严格分开。

## 读取、状态及总览

健康读取不进入同步线程池；总览历史计数使用 SQL 聚合，不调用历史记录逐条资格核验及原生会话扫描。待审批计数先按候选状态筛选，再保留新鲜度核验；完整目录仍保留详情核验。managed worker 按阶段读取活动任务，终态日志只在 inode、大小、修改时间或权限变化时补采；活动任务即使日志未变化，仍检查执行绑定。末次日志与迟到追加分别有测试。新增索引仅涉及 AgentScope 自有 managed_tasks 状态，不修改普通业务数据库合同。

后台 worker 退出并发等待，uvicorn 设 3 秒请求排空期限，systemd 留足退出预算。历史详情仍可按需检查，不把完整历史分析放在总览轮询路径。

状态分别显示控制台最近成功读取时间、实例保护最近核验时间和最后变化原因。离线或过期时不保留绿色“当前受控”及历史 PID，只能显示未知与最后核验时间。正式入口采用 `localhost` 同源；数字地址在 IAB 请求挂起仍是独立开放 BUG。

历史价值证据格式 `agentscope.value-evidence.v1` 包含日期、环境、实验摘要、重复次数与原始报告哈希。仅有 verified=true 的完整实证显示本机已验证；源码依据、边界和延伸方案分开。历史实验不授予权限、不证明当前执行状态。产品展示人可读报告，原始事件与载荷只保留于研究附件。阅读案例不调用应用或批准接口。
