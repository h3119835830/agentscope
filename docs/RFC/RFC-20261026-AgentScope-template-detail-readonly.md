# RFC：模板只读详情补齐

日期：2026-10-26。状态：已实现并通过隔离验收，未发布到 18003。

模板详情使用同一版本的公开模板定义，展示说明、默认处置、范围、固定命令、参数默认值、填写方式、可选值、整数范围、反馈原因和已有执行边界。空默认值显示“未设置，由子配置填写”；数值 0 和多行值原样保留。参数帮助缺失时仅补充通用填写方式，不推断新的匹配能力。

DSL 使用 GET /api/policy-templates 已有的 dsl_preview，不增加接口、不在打开详情时调用 POST 预览。缺参保留占位和缺失字段；不支持或缺少预览时明确说明，不在客户端生成规则。维护模板继续从显式高级入口进入，保存版本、审批和应用合同保持原状。

改动仅涉及前端只读展示、共享预览结果组件和对应样式。验收通过本机 18177 白名单 GET 代理读取正式服务数据，禁止所有写请求；正式服务静态入口尚未切换。
