# 策略生成 Agent 自主选择工作区资料

日期：2026-10-16。状态：实现及隔离验收完成，正式更新结果见同日 REVIEW。承接 `RFC-20261015-AgentScope-workspace-reference-reader.md`；本次将默认资料选择职责从用户移交给受限策略 Agent，保留原有读取与审批边界。

## 使用方式与职责

用户选择准确的受控 Agent，用中文说明业务场景和约束即可，无需填写参考文件路径。策略 Agent 查看服务端登记的本实例资源目录，根据目录与正文的实际返回结果继续选择资料，结合系统策略和已发布模板填参数。子配置仍显示在原模板下，用户可核对、编辑，再提交审批；批准与实际应用保持两个独立的人工作用步骤。

工作区不是独立策略层，也不是可任意选择的主机目录。允许的工作区由精确实例 ID 和已登记资源决定，参数路径采用该实例执行别名 `/w/N`。全部 Agent 范围的生成不自动扫描任何单实例工作区，历史工作区范围保持原归属。原生工作区浏览、既有 Agent、Broker、ActPlane 引擎及业务接口不改变。

## 接口及多轮合同

| 操作 | 服务端接口或实现 | 返回与边界 |
|---|---|---|
| 获取可用工作区 | GET `/api/agent-instances/{id}/policy-reference-workspaces` | 本实例登记目录、服务端工作区 ID、执行别名；不是任意路径入口 |
| 查看目录 | GET `/api/agent-instances/{id}/policy-reference-workspaces/{workspace_id}/files?path=&cursor=0` | 允许的直接子项及分页，不递归扫描、不返回正文 |
| 读取正文 | POST `/api/agent-instances/{id}/policy-workspace-reads` | 受限文本及冻结回执，复用原有权限、身份、文件新鲜度校验 |
| 分析场景 | POST `/api/agent-instances/{id}/template-configurations/generate`，`context_mode=auto` | 多轮自主选择资料，再保存已有模板的子配置 |

HTTP 管理接口不开放给原生 Agent 凭证。服务内策略 Agent 通过同一受限函数调用接口实现，不回环发送 HTTP、不持有管理 token、不调用电脑界面。模型只获得 `list_directory(workspace_id,path,cursor)` 和 `read_files(workspace_id,paths)` 两个工具合同；不能选择其他实例、主机绝对路径、URL、命令、审批或应用。只接受严格声明的字段。

每轮模型返回工具调用，或返回最终 `configurations/questions/gaps`，两者不得混合。真实结果和拒绝反馈加入下一轮上下文。文件须先被目录接口列出才可读取；禁止凭模型臆测文件名直接读取。最终模板 ID、版本、参数均通过共用模板物化校验，不允许原始 DSL、新模板或额外能力。文件中的命令和授权声明是未经信任的数据，不是工具权限来源。

## 权限、资源与读取限额

读取工作进程沿用固定运行合同：happy UID、agentscope-task 主 GID、无补充组；无 shell、无既有执行域加入行为。逐段 fd 锚定与 O_NOFOLLOW、普通文件及单硬链接检查保持不变。目录也在该身份下打开；无 DAC 读取权限、凭据/私钥、运行私有目录、链接及不支持类型不向模型暴露条目。系统与实例 typed read deny，以及真实 ActPlane AST 中可能匹配的 block/kill read/open 子句，均保守拒绝。

这是控制面资料访问守门，不声称模拟实时标签、全部内核状态或对任意 Agent 启动方式自动适配。当前只适用于现有固定受控身份合同。文件内容在存储和送模型前经过既有脱敏；脱敏不替代权限校验，也不能保证识别一切秘密。

| 资源 | 限额 |
|---|---|
| 分析轮次 | 8 轮 |
| 接口调用 | 累计 12 次，每轮最多 4 次 |
| 正文 | 累计 10 个不同文件、192 KiB，单文件 64 KiB |
| 读取错误 | 最多 2 次可恢复反馈，持续失败则终止 |
| 目录 | 每次 100 个直接子项，最多查看当前目录 1,000 项，并报告截断 |
| 时间与进程 | 分析期限 80 秒；每次模型请求不超过剩余期限/60 秒，每次读取进程不超过剩余期限/5 秒，最多 2 个并发读取进程 |

累计预算跨调用、跨本实例不同工作区共享。根据目录大小先检查预算，固定读取程序再核对服务端传入的剩余额度，拒绝期间变大的文件。已读资料的新鲜度重读不作为新的模型文件选择额度。达到期限后即使模型返回最终配置也不保存。超过预算或合同无效时不保存部分子配置、不放宽权限。

## 来源、新鲜度与幂等

每次生成保存实际调用摘要与全部来源回执 `source_reads`，兼容保留首项 `source_read`。生成历史只记录路径、计数、结果和哈希；不复制项目正文或模型私有推理。脱敏正文仅在原有资料证据表保存。界面默认折叠“本次参考”，实际没读正文时明确标注“未读取正文”。目录浏览不冒充正文读取。

每轮前后核对实例、generation、资源、策略和目录版本；全部正文来源在生成落库、完成请求重试、提审和应用前重新核验。审批列表只做已有元信息检查，避免周期性重读正文。第二个工作区的来源变化也会阻止继续使用，不能只校验首个回执。

生成幂等请求通过短事务原子认领，释放写锁后才做模型调用和文件读取。同键并发只启动一次生成；完成后返回相同子配置，资料失效则拒绝旧结果。读取与模板生成不获得批准、加载或启动 Agent 的权限。

## 发布与验收

以当前统一目录版本为整合基线：27 个 v2 模板及既有审批转交保留。正式更新只允许控制台 API/UI，发布前要求无生成、工具租约、策略变更或活跃会话执行；核对当前运行实例的 PID/start ticks、generation、策略、执行域、Broker 保护与队列。更新后逐项比较。失败时只回滚代码/UI，不恢复旧数据库权限快照。

按照用户明确“不用 computer use”要求，采用真实模型、隔离 HTTP、固定读取进程、组件交互与构建验收；不进行电脑/浏览器自动操作，不宣称像素级浏览器验收。详细可复现证据见同日 REVIEW。
