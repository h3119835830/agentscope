# RFC：在现有 Agent 连接模块展示工作区结构化记录

状态：已实施，验收结论见同名 REVIEW。

## 页面与职责

继续使用 Agent 连接模块及已有的当前连接、连接历史导航，不新增会话安全中心或重复模块。当前连接页不再显示重复的面包屑、大标题、执行后端胶囊或连接状态标签。保留屏幕阅读器标题；实例、接入方式、连接状态、工作区数量作为表格字段。原生与受管实例共用一张实例表，不展示空的受管实例卡片。

工作区表记录真实目录、原生会话数量、来源任务数量、读取状态。工作区抽屉按关联记录、策略记录、文件渐进展示。会话标识来自原生注册表；来源任务仅按保存的 workspace_id 精确匹配，不根据名称、路径或 PID 猜测。原生会话不补造标题、运行状态或执行保护结论。

## 数据接口与展示合同

复用 workspace-agents、实例工作区、workspace-tasks 及只读任务 archive/policies 接口，不新增后端接口或授权。策略阶段支持运行前与运行时，按原接口游标分页。任务选择、阶段变化和抽屉关闭使旧请求失效；加载与失败单独显示。

策略表将已验证禁止型 atom 的操作与全部精确目标合成一句中文，保留通配符、目录和文件名；原始说明折叠保留。只允许 classification_origin=validated_atom_and_evidence_roles 且 effect 为 restrict/block 的记录进行此渲染。普通收紧 delta 可能表示缩小允许列表，不能一概改写成禁止规则。其他记录保留原语句。当前批次优先展示执行规则，行为约定仍完整保留。版本号不进入此模块的主记录表。

## 安全与生效边界

工作区身份关联、来源任务和任务副本策略是不同事实。抽屉明确列出来源目录与任务执行目录，历史加载回执不描述为当前生效。连接证据详情保留进程身份与观测代次；工作区识别不意味着实际执行已经接管。当前改动不实现新的 Hook、执行进程绑定、权限扩展、策略批准或内核装载。

文件清单仅在用户切换到文件页时读取，刷新文件不重新挂载抽屉或丢失选中页。普通业务代码、DSH 实例、Broker 和数据库合同均不修改。
