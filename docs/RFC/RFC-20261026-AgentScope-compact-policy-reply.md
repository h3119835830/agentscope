# RFC：策略助手简洁回复

日期：2026-10-26。状态：隔离验收通过，未更新正式服务。

按用户最新截图要求，助手默认仅展示一句实际资料说明、编号策略清单和版本状态；不按字段分区，不默认显示表格、模板参数、文件标签或长分析。原详细表格与完整公开分析统一收进默认关闭的“查看详情”。这取代同日上一轮回复的默认表格布局，不改变系统策略管理列表。

读取说明来自实际正文回执/上传材料；无正文回执时明确未读取，目录浏览不算正文。长文件列表列前三项并说明总数，其余保留在详情。每条清单由生成时名称、对象和已保存操作/处置作展示投影，不改模型结果或模板参数。

条件型模板保留“具体条件见详情”，不能简写成无条件禁止。状态沿用精确版本审批投影；已应用记录继续显示已应用，不套用截图中的“未审批、未加载”。摘要、原失败和历史全部保留，未执行新模型调用、审批或加载。
