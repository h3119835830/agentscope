# RFC：策略助手回复与生成依据展示

日期：2026-10-26。状态：实现并隔离验收，未部署正式服务。

用户需要快速看清读了什么、据此生成哪些策略，单项与多项结果均按真实候选数量展示。回复采用生成时公开分析摘要、实际已读文件、策略记录表；长分析保留全部字符并按需展开。已读文件来自正文回执和上传文本，不把目录浏览、资源检查、模板填写或验证操作计作正文读取。没有公开分析说明时如实标注，不补造原因或私有推理。

策略表来自 configuration_snapshots，列为名称、匹配对象、操作与处置、审批状态、详情；模板版本、全部参数、固定命令、范围及匹配后反馈在详情保留。生成依据与策略 reason 字段分开：reason 仍是匹配后反馈，不更改策略执行语义。表内使用保存版本的实际操作集合，不能把用户请求的单一操作冒充执行器实际覆盖。

后端快照增加 execution 只读字段，白名单为 requested_operations、effective_operations、effect、reason、coverage_warning。旧快照仅在配置 ID、revision、归属及 configuration_hash 复核通过后，从该精确保存版本补充展示字段；不使用最新模板默认值，不回写原生成记录。缺失来源或版本不可核验时保留已有快照并显示审批状态不可用，不推断缺失字段。

最新轮次默认展开，此前轮次和配置总表默认收起；原失败、问题和能力缺口不删除。无候选时补充问题与待解决事项默认展开；有候选时保持数量入口。此界面状态不改变服务端 continuation 上下文、模板集合、候选数量或审批/应用流程。

隔离预览仅绑定 127.0.0.1:18176，重放真实保存记录和上轮 E3 双策略结果。写请求返回 405，不向正式服务转发请求，不调用模型、Broker 或加载器。预览页明确标注历史重放，不能作为当前生产生效证明。
