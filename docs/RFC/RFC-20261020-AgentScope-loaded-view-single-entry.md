## 旧链接合同

`view=workbench|agent&agentPolicyTab=loaded` 有准确 `policyAgent` 且非历史工作区/全部范围时，进入会话目录，用 `sessionFilterInstance` 固定同一实例。清空残留会话 ID、实例选择、类型/搜索/工作区过滤及游标；不自动选最近会话。

缺少目标时返回助手选择页，不扩大为全部 Agent；失效实例仍保持原实例过滤。历史工作区仍只读；其他模块 URL 中残留的 loaded 参数不改变它们当前选中的会话。前端参数不是授权依据，原后端检查不变。

没有会话映射时继续显示既有不可用状态，不伪造单会话归属。本步不新增无会话执行域入口；原 Agent 加载 API 和未挂载组件保留兼容，不删除历史数据。
