# RFC：受审批的单一规范短路径资源映射

日期：2026-10-21。状态：代码与隔离验收通过；主服务维护已获准，发布结果见同日发布 REVIEW，真实 RQ5 链路尚待界面验收。

## 目的与不可变边界

现有 RQ5 深层路径超过原生 ActPlane 精确路径上限，且一个只读资源根的单个 unless 无法表达两个独立可写范围。解决方式是 AgentScope 受治理的文件系统命名空间映射，不修改 ActPlane DSL 编译器、BPF、runtime、事件 ABI、capability checker 或预编译对象。

**映射不是授权。源码和验收产物的写权限必须由操作者提出，经人工批准、显式应用；Pi 不创建映射、不审批、不加载。不得开放共同父目录，不截短规则，不将读取器提权。**

## 数据与接口合同

原 resources 登记保持不变。实例本地/有效权限 JSON 可新增 resource_views：

```json
{
  "schema": "agentscope.resource-views.v1",
  "views": [
    {
      "source": "/registered/scene/project/src",
      "execution": "/v/012345abcdef",
      "identity": {"device": 1, "inode": 123}
    }
  ]
}
```

execution 由规范 source 的 SHA256 前 12 位确定（示例不是真实映射），独立于列表顺序。最多 8 个已存在、无符号链接祖先的资源子目录；source 不能等于资源根。验证重复、冲突、版本、目录身份。变更纳入现有 policy_hash、候选哈希、审批快照与 generation 合同，不新增数据库迁移。

现有 POST /api/agent-instances/{id}/write-permissions/proposals 增加可选 short_paths、protected_paths 数组。paths 仍是最小可写目录。申请 short_paths 时：

- 将指定项目目录、每个 paths 目录与已有映射合并冻结。
- protected_paths 必填，必须为本实例已有资源子目录；与写目录不得相互包含。
- 自动补充明确的测试写入禁止，不移除现有规则、系统约束或网络限制。
- 返回现有 instance 审批对象；提交、批准、应用为三个独立步骤。
- 已有系统或实例 DSL 生效时，不允许改变路径解释，须先经原治理流程批准停用并应用。
- 仅支持增加映射，不支持移除、改名或替换已批准目录身份；不支持 native_paths 和终端启动。
- 资源/代次/策略/目录身份漂移则拒绝；重复申请按现有幂等键返回原候选。

## 执行边界

保留 /w/N 入口。项目及可写叶目录分别成为 /v/<id> 独立规范挂载。被分流的旧路径仅在沙箱内成为指向规范挂载的链接；没有第二份可写 bind。宿主场景不移动、不覆盖、不创建链接。

AgentScope 只对必要祖先生成只读投影，其余条目只读绑定；合成祖先需要宿主已有公共读取/遍历权限且无访问 ACL，否则拒绝。目录树核验限额 4096。可写树拒绝既有硬链接、符号链接和特殊文件。

Broker 逐组件 O_PATH/O_NOFOLLOW 固定来源身份，使用 bwrap 消费式 bind-fd/ro-bind-fd；payload 不继承宿主来源描述符。父级拒绝要覆盖所有独立挂载；父目录禁止写入通过 remount-ro 保留规范链接，不能重新绑定宿主父目录抹掉投影。

每个规范挂载仍遵守原生单个连续写区间限制。原资源根、只读项目根和 tests 保持阻断，src 与 acceptance-artifacts 分别授权。启动 canary 同时覆盖原资源根和新增规范挂载，不能只检查 /w 根；实际 native syscall 与内核事件必须一致才算验证。

## 路径、Pi 与上下文

读取目录/正文回执、模板参数、Agent 与会话上下文、Broker 会话观察都使用同一映射规则。旧 /w 路径先还原宿主位置，再选最长匹配的规范挂载。会话边界按真实宿主归属核验，不因 /v 前缀不同误拒绝，也不扩大到整个 Agent。

映射进入环境绑定，旧上下文/候选不能跨代次静默复用。读取器 UID/GID、fd 限制、正文预算、来源新鲜度保持原合同。没有添加 RQ5 专用提示词。

AgentScope DSL 适配器仍调用上游解析/编译；只重写应用层资源路径。跨越独立映射的父目录通配符拒绝，不能少保护一部分后仍报成功。精确路径仍受原生 63 字节限制。
