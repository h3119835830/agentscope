## 内容与入口

正文维护在 `research/value-reliability-20261012/announcement.md`，由 `scripts/build_value_announcement.py` 生成独立的 `/value-announcement.html`。围绕插件读取凭证、后台后代、路径实际对象、跨进程来源与测试完整性五个场景，按合法任务、隐藏行为、应用日志缺口、内核侧作用和具体价值展开。应用层任务记录与内核侧关键操作的两行图明确标注“机制示意”。研究附件继续保留实验环境、失败结果与适用边界。

公告说明三种能力：命中事件可审计；操作返回与用户态规则解释可反馈；运行保护绑定和事件处置可监控。内核负责规则检查、处置及事件输出，用户态负责解释与展示；不把用户态说明冒充内核决策，也不把关键事件审计表述为全系统调用的无遗漏记录。来源场景限定为新连接，原生补充任务仅声称可见拒绝后合法读取继续。

本轮只原子替换 `value-announcement.html`，发布脚本 `scripts/publish_value_announcement.py --apply` 先保存旧文章及运行快照，核对 HTTP 内容哈希，再确认其他静态文件、服务身份、实例授权、DSL 修订与其他业务监听不变。失败时仅恢复本次文章。原总览 React 源码、入口 index、JS/CSS 及示意案例均不得改变；不得重启服务或操作 Agent。

桌面保留文章目录，窄屏单列阅读，章节可键盘跳转，打印样式保留。源文哈希在 meta 中，正文不展示部署编号、PID 或诊断 JSON。仅更新本地产品阅读页，没有发送给导师或发布到外部渠道。
