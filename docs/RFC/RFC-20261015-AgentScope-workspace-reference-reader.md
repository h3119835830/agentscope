# 工作区正文读取与模板策略生成接口

日期：2026-10-15。范围：AgentScope 控制面受限资料读取、模板参数生成、审批新鲜度；不改 Broker、Agent 原生进程、ActPlane 内核、普通业务或业务数据库合同。

## 目标与职责

用户通过接口选择对应 Agent 有权限的工作区资料，策略生成 Agent 结合系统约束与已发布模板填写参数。生成端没有 computer use、shell、自由文件读取、模板发布、批准或加载工具。工作区只提供资料；应用目标仍是精确指定 Agent，应用由用户单独确认。

可选工作区来自该实例已登记资源目录，服务端产生与精确实例和资源路径绑定的工作区 ID，并返回执行别名 /w/N。该目录不等于已经运行的原生工作区登记；界面明确称为“已登记资源目录”。目录内项目文件通过相对路径选择。因此 DSH、Hermes 及同一受控启动合同下的其他实例均可起草，关闭状态不需要启动 Agent。原生工作区浏览保持原有只读接口。

## 接口

| 接口 | 合同 |
|---|---|
| GET /api/agent-instances/{id}/policy-reference-workspaces | 只返回此实例已登记的资源目录、别名与限额 |
| POST /api/agent-instances/{id}/policy-workspace-reads | workspace_id、paths、request_key；读取并冻结选定正文，返回脱敏后的材料和读取回执 |
| GET /api/agent-instances/{id}/policy-workspace-reads/{read_id} | 按精确 owner 校验、重读并核对当前资料；不允许跨实例使用 |
| POST /api/agent-instances/{id}/template-configurations/generate | 增加可选 reference_read_id；只接受服务端读取回执，不接受客户端伪造文件证据 |

复用现有管理接口身份校验，原生 Agent token 不能调用。未知参数由严格请求模型拒绝。读取的幂等键绑定实例、工作区和文件选择；生成的幂等键包含引用 ID，不复用其他目标或材料。

## 读取边界

先校验受控实例、登记资源、当前策略阶段及选定工作区。只接受规范相对路径；一次 1–10 个 UTF-8 文本，每个最多 64 KiB，总计最多 192 KiB。拒绝环境凭据、私钥、运行私有目录、不支持的文件类型、路径越界、重复选择。

独立固定 Python 读取程序通过 stdin 接收服务端生成的目录与文件列表。无 shell，无模型工具，无调用者指定程序。subprocess 内置身份切换沿用当前固定受控运行合同：happy UID、agentscope-task 主 GID、无补充组。API 虽以 root 运行，读取工作进程不能利用 root 的 DAC 权限。进程没有加入既有 Agent 的 cgroup，也不改变其 lease、门禁或内核域。

读取从 / 开始逐段 O_NOFOLLOW 打开目录；文件使用 O_NOFOLLOW / O_NONBLOCK，要求普通文件及单一硬链接。读取前后核对设备、inode、大小、mtime、ctime、mode、link count；重开路径核对根和最终对象，拒绝读取期间的替换。单进程 5 秒期限，最多 2 个并发读取。部分失败不保存部分正文。

权限守门同时检查实例和系统 typed read deny，以及现有系统/实例 DSL。DSL 通过真实 ActPlane AST 适配器解析，参考读取对可能匹配的 block/kill read/open 规则保守拒绝；条件、标签和例外不用于放松读取。这是额外的资料访问限制，不模拟全部实时标签状态；可能比实时执行更严格。无法解析或阶段未恢复时不读取。AST 中 managed source 的占位只用于提取所有潜在拒绝子句，既不安装也不声明已核验执行身份。

## 脱敏、资料与权限分离

正文在持久化或送模型前移除已知凭据赋值、私钥块和私有推理标签。仅保存脱敏正文、文件身份/原文哈希、资料快照哈希和来源绑定；不把原文、凭据或模型私有推理写入审计日志或技术文档。审计只记实例、回执、文件数及哈希。脱敏不能代替权限守门和用户对参考文件的明确选择。

新增 template_workspace_reads 是资料证据表，不是权限表。快照绑定实例 ID、generation、资源列表、有效/本地/系统 typed policy hash、系统/实例 DSL hash、读取 UID/GID、工作区根 inode、各文件身份和内容哈希。参考资料不修改 scope；新助手依旧提交 scope=agent, workspace_id=null。

## 生成与审批

模型输入明确区分用户要求与未经信任的项目正文，附带系统 typed/DSL 约束、实例权限、资源事实和本次已发布模板。输出仅允许已提供模板 ID/版本、名称、参数、反馈说明；服务端仍由共用物化函数校验参数、路径和模板能力，拒绝任意 DSL、未知模板、额外字段或范围扩张。

生成前重读和校验参考材料，返回模型后再校验；变更则整个批次不保存。各子配置保存 source_read 回执/哈希及可读来源摘要，聊天记录展示参考目录和路径。文件或权限变化后，旧引用和旧生成重试拒绝继续使用。手工编辑保存新的人工版本时不自动继承旧模型资料绑定。

提交和实际应用前完整重读、核对 DAC 与内容哈希。审批列表刷新只检查绑定和 fd 锚定的文件元信息，不反复读取正文或启动工作进程；最终应用仍做完整校验，发生变化时在停止任何 Agent 前拒绝。停用是人工单独审批/应用的移除操作，不因旧参考文件消失而阻止撤销。

## 界面与发布

策略助手中的“读取工作区参考文件”按需展开。用户选择已登记目录和相对文件，显式读取后才能在本次生成中引用；编辑选择或读取失败会使引用失效并阻止静默退回无资料生成，用户可明确取消参考。迟到响应不覆盖新选择。正文仅在可展开依据中以转义文本呈现。

本次按用户“不用 computer use”要求，通过 HTTP、真实读取进程、真实模型、组件交互与构建验收，不使用浏览器自动操作；不据此声明像素级浏览器验收。

发布采用当前 API 运行产物和上轮统一范围静态页为基线。只切换 API/UI，Broker 和 Agent 原生进程不变。新增只读证据表；不恢复备份库权限、不自动加载或重启 Agent。发布前后冻结并核对 Broker 身份、全部 Agent 的 generation/PID/domain/active/策略及系统约束，保持 18000/18004；保存代码/UI 回滚入口。远端 push 仍需单独授权。
