# Agent 助手单输入框与文件参考合同（2026-10-19）

Agent 策略助手只保留一个文字输入框和“添加文件 / 发送”。移除手工模板选择、新增配置和助手记录中的编辑入口；手工配置仍在系统模板模块。生成结果表只显示助手起草的配置，保留原核对提交、审批定位和审批后停用链路，不增加直接应用入口。

浏览器读取用户通过选择器明确选定的 UTF-8 文本；最多 10 个，每个 8000 字符 / 32000 字节、名称 80 字符。拒绝二进制、空正文、无效 UTF-8、重复名称或超限；整批失败不部分附加，不截断。支持 txt/md/json/csv/yaml/yml/log/ini/toml/xml；PDF、Word、图片暂不支持。沿用 materials[{name,text}] 请求字段，发送前显示文件名并允许移除。附件留在当前对话，后续发送继续引用；刷新页面或切换作用目标会清空浏览器中的附件正文，历史只保留文件名和字符数。

两个 generation POST 接口增加可选 conversation，最多 6 条，每条只接受 role=user/assistant 和不超过 3000 字符的 content；requirements 支持 1–2000 字符，允许简短补充。前端从当前精确目标和作用范围的记录中截取最近 3 轮需求与澄清，不混入其他 Agent。当前要求、前文、材料、工具结果分开传递；历史不授予权限。后端材料回执 provided_files 只记录名称及字符数，不保存附件原始正文到生成记录。

复用 WorkspacePolicyAgent 的 list_directory / read_files 和实际结果回填循环：仅指定 Agent 的已登记资源，固定读取身份、无附加组、策略/DAC/路径/限额校验；最多 8 轮、12 次调用、10 文件、192 KiB。所有 Agent 范围 context_mode=none，只处理明确上传材料，不扫描单实例。当前执行器是 DeepSeekProvider 驱动的受限工具循环，并非直接赋予 Pi CLI 任意文件系统工具。本次不切换模型或 Agent 框架。

仍只生成模板参数候选；提交、批准、应用和实际内核拦截保持独立。附件或对话中的命令不改变工具合同、作用范围或审批权限。不改 DSH、Broker 或原生工作区与会话。
