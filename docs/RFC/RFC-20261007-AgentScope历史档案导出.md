# RFC：AgentScope 历史档案导出

日期：2026-10-07。范围：任务公开历史的静态归档。用户明确授权创建并推送 `history-records` 分支，不顺带推送其他分支。

## 合同

一条任务、一份完整档案。`AgentScopeTaskHistory/1` 包含 task_id、快照时间、任务头、准备/执行/结束阶段、四类事件统计、全部公开事件及可取得的历史域/DSL。策略生成、候选、版本、审核、加载、运行时变更、工具结果、内核记录、控制面与结束回执保留存储及动作来源，不把不同来源混为同一种执行证明。

复用 `agentscope_app.archive.projection` 和 `archive.historical`，不另建策略库，不调用 Broker，不启动或恢复 Agent，不核验历史 PID 当前存活。

SQLite backup API 取得一致性快照，以只读连接和 query_only 运行查询。四类事件必须读完全部分页，数量与快照统计一致；跨任务、重复或截断立即失败。历史加载文件独立与快照回执中的 hash 核对，缺失或变化保持不可用。

`records/<task_id>.json` 是一份完整公开任务档案。旧 ID 不强制为 16 位；不能安全用于文件名的标识符转为 SHA-256 文件名，正文保留原始 ID。索引保留状态、数量、路径及 hash，清单覆盖全部 JSON。

## 公开与版本边界

复用服务字段选择和脱敏后，排除原始正文、未审查摘录、工具原始参数/输出及私有推理，检查常见凭据形态。保留目标、公开候选说明、结构化规则/DSL、路径和内容 hash。快照数据库、原生私有会话及凭据不入 Git。

任务状态是快照状态；不推定当前在线，失败和缺失不补成成功。静态导出不提供数据库导入、会话或权限重放。

分支从已公开 main `b05483960d7d8a19fe4d28f0c400905f0ea3bf39` 建立，只新增档案、工具和说明。读取实现尚有本地修改，因此 provenance 同时记录 checkout HEAD、修改状态和实际 Python 文件 hash；不能把旧 HEAD 说成包含整个读取实现。后续快照采用新版本目录，不覆盖既有档案。
