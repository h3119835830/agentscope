# RFC：运行时提示词与记忆的来源工具试验

日期：2026-10-26。状态：隔离试验，默认关闭；不替换正式 18003。

## 目标与职责

新用户消息由原生会话接纳后，策略 Agent 读取同一作业冻结的用户要求、主 Agent 实际加载的记忆、有效策略和项目材料，自主检索历史策略并解析真实对象。无需用户在提示词中重复写出记忆已经说明的具体路径。工具执行前沿用现有门禁；没有新增限制时不加载 Delta。

复用运行前的工具方式：get_task_context、list_policy_sources、read_policy_source、search_historical_policies(query)、get_enforcement_capabilities、validate_policy_draft；提交使用 submit_runtime_policy_proposal，只接受服务端已验证的候选哈希。历史检索 query 由 Agent 选择，不再固定采用触发文本前 500 字。

## 输入、授权与输出

通过 AGENTSCOPE_RUNTIME_SOURCE_TOOLS=1 为新建作业冻结 runtime-source-tools/1 合同。旧作业和默认路径不变。每条执行限制必须引用已认证用户要求和实际读取的项目对象，引用记忆时须有同作业读取回执；记忆不能独立创建授权。该试验允许 Pi 对“用户要求—记忆事实—具体对象”的语义关系作判断，控制面验证来源身份、读取、登记范围、版本和限制能力，不宣称确定性验证了自然语言语义。

候选为 atoms（语句、对象、操作、证据）、guidance、unresolved_requests。支持工作区相对路径和相同对象的规范绝对执行映射，服务端转换后仍严格匹配登记对象，不扩大作用范围。必要 OS 约束未解决时不同时提交执行增量。候选校验和提交分离，提交再次核对来源哈希及策略 revision，加载再次核对不可变服务端记录与执行域。

## 能力与触发边界

本试验执行能力仍限文件写入与删除的共同保护；不宣称精确删除单操作、文件读取、程序执行、网络连接增量已经支持。实际能力和 draft schema 由工具返回，不让模型凭说明制造执行能力。

本轮不重写原生触发机制：新用户消息和绑定 provider 的实际记忆加载/内容变化可触发评估，内容哈希用于去重。工具结果、内核反馈、Agent 回复和恢复仍不触发生成。记忆首次加载可能使先前用户作业过期；未处理用户要求由下一轮冻结上下文继承。

## 验收

使用完全相同的用户提示词与两个不同的合成实际记忆，分别把生产配置映射到两个内容相同的登记文件。检查候选对象随记忆改变、域身份与基线不变、目标写入/删除被阻断、另一个文件可写，并由真实 DSH 完成允许的新文件写入任务。失败与成功分开保留，不用预写候选代替真实 Pi 输出。

独立服务为 localhost:18007，拥有独立数据库、/rtp 工作区、Broker socket、BPF pin、cgroup 和合成记忆目录。不得操作现有 18000/18003/18005/18006、共享 Agent 或真实用户资料。试验结束关闭试验任务和本轮服务。
