# 子配置记录摘要合同（2026-10-16）

系统策略统一模板下的子配置列表扩展为六列：实际策略名称、范围、保护对象 / 操作、动作、状态、详情。保留原有系统策略表格与参数编辑入口；助手仍在 Agent 页。

摘要读取已保存子配置及其版本定义；动作优先读取子配置 effect / 参数或旧配置 config.effect，不以父模板默认动作覆盖。保护对象摘要保留多条件标签和数量，完整值通过悬停与详情查看；操作优先展示 effective_operations，避免漏掉共同覆盖的修改与删除。无结构化投影的导入 DSL 显示“查看详情”，不猜测执行条件。

状态来源为配置应用标志、版本比较和已有审批状态。已批准待应用与已应用配置分开；旧版仍应用显示为注记。旧库不提供审批投影时，仅展示可核验的未应用 / 有未应用修改 / 已应用配置。配置应用不能证明对应执行域或内核已生效。

本变更仅前端展示，不新增 API、策略作用域或加载入口；保存、提交审批、人工批准、显式应用的合同不变。DSH、Broker 和运行中 Agent 不修改或重启。发布仅覆盖 18003 静态页面。
