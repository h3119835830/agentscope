## 职责与界面

任务工作台作为唯一受管 DSH 运行入口，保留现有左侧导航样式，删除重复的“运行时 Scope”导航。六项为总览、任务工作台、历史策略库、任务与启动审核、运行时 Agent 接入、持久治理。旧 view=runtime 链接恢复到 view=scope-demo 并保留 task。

主页面仅显示已登记工作区路径、运行状态、当前策略版本和三个分页：运行前策略、运行时策略、执行审计。策略记录用对象、原始语句摘录和标签展示；完整内容由详情抽屉“语句与类型 / 上下文 / DSL / 加载”承载。无需变更的运行时评估默认折叠，通过复选框查看，不混成已加载策略。

DSH 只执行任务并收到有界操作反馈，不能读取 AgentScope 控制文件或已确认 OS 策略。新投影接口是管理员只读接口，不新增执行者能力。Pi 只能提交候选和公开识别注释；控制面验证证据及权限合同，Broker 特权加载。

## 工作区自动匹配

匹配依据为服务端登记的 task、workspace 和持久 Session ID；传入多个条件时必须同时一致。无提示条件时仅考虑 prepared/generating/recovering/running 的受管工作区：恰好一个则自动选择，多个则要求选择，没有则显示未登记。不会选最近历史任务，也不会根据浏览器端口或任意本地路径猜测。

已声明进程绑定的任务向 Broker 查询当前状态，单独展示实际进程/域核验结果。显式选择已结束任务可以看历史；自动匹配排除已结束任务。个人 DSH 3000 尚未登记为受管工作区，不能据页面自动匹配声称它已受管。

## 记录合同

| 字段 | 来源与含义 |
|---|---|
| statement | 启动 Pi atom 原句；新运行时 Pi identified_statements 原句；历史增量优先引用已认证目标条款 |
| policy_type | per_event / cross_event / content / semantic_only；类型注释不授予或实现权限 |
| context_required / context_reason | 新运行时由 Pi 显式提交；旧启动记录由已验证 atom 的资产/环境证据角色推导，标注来源 |
| evidence | 来源 ID、路径、哈希和服务端读取回执；不导出模型私有流 |
| trigger | hook 分类、作业、请求、上下文 revision、接受轮次与实际派发轮次 |
| compilation | 校验结果、真实 DSL、SHA256 与 DSL 来源 |
| loading | 是否真正应用该变更、应用或评估回执版本、确认、会话与启动底线 |
| delta | 新增/解除保护、写入范围和输出权限前后值 |

新运行时候选持久保存实际提交编译的完整 DSL 及哈希；读取时校验哈希。历史候选没有原始完整包时仅展示编译器 source_text 去重后的规则片段，明确标为历史重建。启动 atom 按 bootstrap-N 映射对应编译器片段。语义指导没有 OS DSL，no_change/guidance_only 不表示新增或加载 OS 规则。

生成、编译、加载和当前保留的效果分别判断。编译通过不能当成已加载；加载必须有该作业真实 request_resolved 回执。已应用的增量与当前权限比较，分为生效、部分保留、被替代、暂停和撤销；无关输出扩权不会使仍保留的文件保护被误标为失效。必要但未解决约束维持待澄清，未确认扩权维持待确认，过期候选不能应用。

## Hook 合同

| 阶段 | 实际触发 | 顺序 |
|---|---|---|
| 运行前 | 新建受管任务、显式启动或启动澄清 | 必读来源及项目映射 → Pi 识别 → 校验编译 → Broker 加载核验 → 放行 DSH |
| 运行时 | 真实用户消息、system/developer、工具 schema、公开有效上下文、compaction 记忆变化、内核拒绝、已验证误拦截 | Native hook 登记变化 → 冻结公开上下文并暂停新工具 → Pi 增量评估 → 收紧自动加载/扩权待确认 → 核验后继续 |

运行时普通消息允许 no_change。启动底线不可削弱；扩权重建完整策略包及新域，并恢复同一持久会话。页面 Hook 抽屉展示此合同；不能把展示本身当成现场 hook 证据。

## 管理员接口

- GET /api/managed/workspace-binding?task_id=&workspace=&session_id=
- GET /api/managed/tasks/{task}/workbench：轻量状态、Broker 当前域核验，不返回 raw prompt 或事件全量。
- GET /api/managed/tasks/{task}/strategy-records?stage=startup|runtime&include_assessments=&before=
- GET /api/managed/tasks/{task}/strategy-records/{record_id}：限定同一任务，外任务记录拒绝。
- GET /api/managed/tasks/{task}/execution-audit?category=os|tools|control&before=

运行时记录每页 12 条、审计每页 50 条；详情按需读取。分类切换先清空旧列表并显示读取状态，过期请求响应不能覆盖新选择。

## 执行审计口径

| 层 | 记录 | 能证明的事实 |
|---|---|---|
| OS | kernel 与 operation_verified | 实际内核拒绝；独立操作及文件状态核验。未核验的拒绝不直接等同正确拦截 |
| 工具 | tool_start 与 tool_result | DSH 开始/返回工具结果；工具成功不能证明全部 OS 操作允许 |
| 控制面 | pause/failure/feedback_delivery/policy_active/closed | 暂停、故障、反馈送达、加载与撤权 |

独立探针与真实 DSH 工具来源分别标注；探针工具结果继承其开始记录来源。详情展示调用 ID、实际 PID、域、版本、命中规则与原因。后台持久采集继续沿用，不依赖页面打开。
