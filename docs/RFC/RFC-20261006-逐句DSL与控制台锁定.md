# RFC：逐句策略记录及控制台锁定

日期：2026-10-06。状态：实现与专项验收通过。取代上一版把 Pi 作业当成策略记录、在记录详情展示完整策略包的合同。

## 逐句记录

每条运行时记录对应一条已识别策略语句，使用 runtime:{job}:statement:{index} 作为身份。同一 Pi 作业可以产生多个记录，各自展示 policy_type、context_required/reason、对应 evidence、目标、操作、DSL 片段及加载状态。

没有识别语句的普通评估不进入页面策略记录；后台作业和评估计数继续保留。运行时页面可按 OS 执行策略/任务指导筛选，移除“显示无需变更评估”入口。历史权限增量优先保留认证目标条款；缺逐句注释的历史扩权使用原认证请求，明确标为历史增量关联，不追补模型回答。

## 对应 DSL 合同

新候选的完整 compiled_dsl/hash 仍在后台保存并校验，供特权加载及完整性检查使用，不作为单条策略记录的 DSL 内容。

语句与已登记项目来源、认证保护目标或实际增量对象关联；仅采用同名完整路径 token，拒绝把另一个文件的后缀误当成目标。根据实际编译器 target_pattern、clause_text、name、行号和 clause_hash 选取对应子句。即便同一 source_text 包含多个文件，也只展示当前语句对应子句，附其规则名和编译器原因；规则片段哈希仅描述展示片段，不等于完整策略包哈希。

语义指导：不适用 OS DSL。沿用已有文件保护：展示对应旧规则，说明本轮未重新加载。权限授予/解除：没有新增拒绝规则时明确说明。无法可靠关联：显示未登记对应规则，不回退为整包 DSL。

每条语句仅显示相关权限增量，语义指导无 OS 加载回执和权限变化；不能继承同作业内其他规则的“已加载”。分页采用 rowid:statement-index 游标，保证兄弟语句跨页不丢失、不重复。详情身份限定当前任务；旧作业 ID 的兼容详情不展示完整 DSL 包。

## 浏览会话

本地浏览会话保存在 DB，沿用单次本机票据、HttpOnly/SameSite=Strict、同源校验、八小时有效期、显式锁定撤销；不取消认证、不自动解除显式锁定。

现场 API 日志有一次成功 POST /api/auth/local-browser-close，DB 对应会话 used_at 已设置，导致新打开标签出现连接页；不能归因为 DSH 断线或 API 重启。页面“锁”图标改为明确的“锁定管控台”文字，提示锁定会话的含义。close 新增 local_browser_locked 审计，记录 explicit_control_lock，不记录票据、口令或 cookie 值。

通过既有可信本机启动票据恢复浏览入口；不重启受管 DSH、不修改策略域。API 真重启与页面刷新验收确认有效会话持续可用。
