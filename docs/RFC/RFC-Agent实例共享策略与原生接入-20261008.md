# Agent 实例共享策略与原生接入

范围：独立 Scope Demo 18003。一个受控实例拥有一份策略、运行代次、ActPlane 子域及 cgroup；实例全部原生会话和子进程共享。资源目录不拥有另一份策略。既有任务、工作区 API、历史链接不迁移。

## 连接合同

`AgentAdapter` 提供 observe、open、start、stop、sessions、processes、events。控制 API 为 `/api/agent-instances`，实例下有 check/open/start/stop、policy/proposals、sessions、processes、events。浏览器只传实例 ID 和类型化字段，没有任意命令入口。Demo 延续无管理员口令。

DSH 使用独立 DSH_HOME、原生 web CLI 和 Cordis 插件。插件围绕原生工具 execute 取得/释放实例租约，读取真实会话注册表；没有单会话绑定限制。Hermes 固定验证 `/home/happy/.local/bin/hermes` 指向 `/home/happy/.hermes/hermes-agent-v020`，以独立 HERMES_HOME 执行原生 `dashboard --isolated --no-open --skip-build`。插件接入原生 pre_tool_call/post_tool_call、session.create/prompt.submit 及自己的会话数据库。没有修改原生核心或提示词，没有读取 ERP 大管家的运行目录。

原生页面入口由适配器实时返回，界面新标签页打开。已有 DSH 通过当前服务身份和原生启动回执解析认证入口，打开不重启。普通 Python/Node 名称不足以认定 Agent。Windows 只读辅助进程按已知安装路径、PID、创建时间上报候选；WSL 按原生安装、服务与实例桥接发现。发现不等于连接，连接不等于执行受控。没有接入执行 Hook 的 Codex 等候选只显示观测信息。手动登记只接受本机 HTTP 根入口。

## 策略与执行

策略接受 `rules[{action,target,effect,text}]` 和 `network`。action 为 read/write/tool/network/behavior；自然语言 text 仅说明或行为约定，不编译为强制约束。缺省只读已登记资源，运行状态、临时目录、控制端与可信启动层解析的模型 IPv4 连接按需开放。额外网络首轮支持禁止指定非回环 IPv4；IPv6 默认拒绝。模型地址依启动解析结果固定，不因 Agent 请求增加。

文件执行使用只读挂载、明确写入叠加挂载、非特权身份及 ActPlane。保护目标拒绝已有符号链接和硬链接别名。每个资源当前支持一个连续写入范围，可在其中单独禁止测试或配置。工具限制由原生 Hook 在执行前判断；confirm 工具需要用户通过候选修改授权后再执行。无法强制执行的语义要求显示“行为约定”。平台控制目录不映射进 Agent，实例 token 只访问自己的类型化 Agent API，不授予 Broker 或控制 API。

由于当前 ActPlane 规则路径 ABI 是 64 字节，原始资源按固定排序映射成实例挂载空间 `/w/0`、`/w/1` 等。控制层保存原始目录，编译和原生会话使用短路径；Agent 候选经可信映射还原后再校验。映射后仍超限的规则拒绝，不能截断。界面资源表同时展示原始与执行目录。进程 PID 由 cgroup 内 NSpid 加原生可执行身份唯一解析为主机 PID，不能直接把 namespace PID 当主机 PID。

## 动态更新合同

请求携带 generation、base_hash、request_key，候选哈希包括完整候选和基线。重复键不同内容拒绝，过期代次/哈希拒绝。移除允许、增加禁止等可证明的收紧自动应用；不确定变更保守归为扩权。扩权展示全部会话影响和完整替换候选，用户必须确认准确 proposal_hash。

生命周期：关闭整个实例工具入口 → 排空最多 8 秒在途租约 → 原生会话持久化 → 终止整个旧域/cgroup → 编译完整新策略并建立新域 → 启动原生实例 → 正反文件探针、内核事件、网络探针及进程绑定核验 → 开放共享入口。总是重建执行进程，旧 FD、可写 mmap、后台后代随进程终止失效。保留原生会话记录，但不自动继续旧在途任务。Agent 提出的自动收紧先返回候选回执，由可信后台控制层应用，避免等待正在重建的调用者本身。

## 当前证据与异常

控制层按 3 秒观测、8 秒证据过期处理；旧回执不能恢复在线或生效声明。失去原生/域/PID 证据冻结整个实例。Broker 和独立根 relay 都检查控制心跳，超过 8 秒终止登记 cgroup；恢复仅接受 root 私有 manifest 的派生实例 ID、cgroup 路径与 inode、进程启动身份。恢复清理旧域后由新运行代次重新核验。失败保持暂停，不回退成无保护执行。

启动核验在另一个同别名的全可写探针挂载空间执行，避免只读挂载掩盖 ActPlane 漏拦截。授权位置实际写入可丢弃 canary，保护位置仅打开真实文件的写 FD（不写入）或尝试写入 canary，读禁止目标尝试读 FD；拒绝必须关联 root 拥有的内核事件、PID、策略域、操作和精确路径。IPv4/IPv6 拒绝有本机哨兵及过滤计数，控制端必须仍可连接。编译、加载、绑定、实际拦截和 RQ5 功能结果分别记录。

界面首页按 Agent 产品聚合，一种 Agent 显示一行。优先选择当前可打开的入口，再选择可启动的受控连接；首页的 PID、连接情况、安全覆盖和配置仅对应该入口。“实例与进程”列出全部原始连接及其来源、实例 ID、PID、运行环境和覆盖状态；“查看进程”进入该实例的会话与进程页。聚合不改变实例 ID、策略归属或控制接口。

实例详情为连接设置/安全配置/会话与进程/运行记录四页签。安全配置的主表为完整规则语句、当前状态和操作；来源、执行方式、完整绝对路径及补充说明由逐条详情展示。平台底线和默认只读作为只读基础保护，网络范围可编辑，用户配置规则提供添加/编辑/删除。运行记录独立展示已有 Hook、策略变更及执行结果，不堆叠在规则主表下。

界面移除“连接身份与核验详情”，不再展示哈希、运行代次、启动标识等原始技术字段；控制层仍保留并使用这些字段校验安全身份。多个网页标签可共用后端执行器，不根据标签数量推算 PID。Linux 受控进程依据 /proc、cgroup 和策略域核验；Windows 进程需要 Windows OS 观测接口，不能从 WSL 内核直接推断。

规则主表的目标可显示为项目名/相对路径，匹配严格限定已登记资源的目录边界；相同项目名有歧义时保留完整路径。该缩写仅用于展示，详情、编辑、候选和执行仍保留原始精确路径，不改变策略目标。编辑时固定完整候选、generation 和 base_hash，轮询发现基线已变则阻止提交。删除一条规则同样提交完整类型化候选，不新增绕过确认的 DELETE 接口：删除授权属于收紧，删除禁止项保守按扩权待确认，确认展示准确候选差异及可展开的完整替换配置。

连接列表和详情提供 `entry{kind,label,instructions,command?}`。kind 为 web/cli/cli_install/desktop/process，由已接入的适配器、已校验安装入口或手动登记的本机网页决定，不能从 Python/Node 或 Agent 名称推断。DSH 桥接及受控 DSH/Hermes 为 Web；WSL Hermes 的安装记录为 CLI 安装入口，不宣称有活跃 CLI 会话。Windows 未接入原生窗口/终端接口的进程仍是观测记录。

首页与实例明细均显示入口方式。Web 按当前能力提供“打开网页”“启动网页”或“查看入口”；CLI 安装入口提供“CLI 启动方式”，详情显示固定 WSL 原生启动命令。该命令只作文本说明，浏览器不能执行任意命令，直接运行 CLI 不继承受控连接的策略。当前新建受控 Hermes 使用原生 dashboard 网页；没有新增 CLI 受控启动或终端恢复适配器。未连接的当前 OS 进程可显示 PID，但不伪造会话和策略域核验。

SPA HTML 入口（含 `/index.html` 与深链接回退）返回 `Cache-Control: no-cache, max-age=0, must-revalidate`，导航时重新校验当前页面文件。已经加载的标签页需重新加载才会换用新 JS；不自动重载正在编辑配置的页面。

## 2026-10-09：配置详情直接打开 Agent

实例配置详情的公共顶部提供“打开 Agent”，连接设置、安全配置、会话与进程、运行记录页签均可使用。未运行的受控 Web 实例显示“启动并打开 Agent”；CLI、桌面和未知进程沿用原入口说明，不生成网页链接。按钮打开该实例的原生网页；当前 DSH 没有会话 URL 路由，不宣称已定位到某个会话或工作区。

首页、实例明细和配置详情复用同一打开流程：同步预留新标签页，必要时按实例 ID 受控启动，再请求既有 POST open 接口，校验本机 HTTP 地址并保留适配器返回的原生认证信息后跳转。已运行实例只请求 open。弹窗被阻止时不发起启动；接口或地址核验失败时关闭空白页并显示错误。认证入口不缓存到记录或文档。
