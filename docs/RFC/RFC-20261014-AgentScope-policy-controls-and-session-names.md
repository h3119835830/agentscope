# AgentScope 策略结束操作与会话显示名称合同

日期：2026-10-14。范围：控制台、AgentScope API 及隔离验收；不改 Broker、ActPlane 引擎、原安全总览、公告或普通业务。

## 系统策略的展示

审批目录的“适用 Agent”对于 system 仅显示“全部受控 Agent”和提交时涉及的实例数；生成会话仅显示“系统配置”。实例和 PID 明细放到审批详情的影响范围中，默认折叠。单个 Agent、工作区及会话候选保留精确目标导航。历史记录的范围来自提交快照；详情中的提交时身份与当前身份仍分别记录，不将历史应用回执当作当前保护证明。

## 停止、撤回、停用和删除

| 当前对象 | 操作与合同 | 执行影响 |
| --- | --- | --- |
| 策略生成作业 | 停止生成调用既有 generation cancel；先显示正在停止，模型请求返回后 worker 协作退出 | 不改变已加载策略；取消请求不等于执行进程已经停止 |
| 待审批/已批准待应用候选 | 拒绝或撤回仍使用统一审批服务 | 不删除现有生效文档，不自动应用其他候选 |
| 已生效系统策略 | 停用明确文档，合并保留其余文档，重新编译，形成待审批移除候选 | 批准只记录决定；另行应用才关闭门、回收旧执行器、重新加载并核验 |
| 已生效 Agent 文档 | 配置表的停用入口移除整个文档；弹窗说明文档内全部规则将移除 | 仍继承系统约束，其他 Agent 文档保留；操作不是即时撤权或归档 |
| 未生效系统配置 | 删除配置调用既有 revision CAS archive，管理员确认，新增归档审计 | 软归档，历史版本/审批/执行证据保留；生效配置服务端拒绝直接归档 |
| 整个受控 Agent | 停止全部会话前明确确认影响；UI 传 generation、policy_hash | 生命周期锁内复核身份，关闭执行门，回收执行进程，清除租约并记录 stopped；不会自动再启动 |

加载失败遵循现有 blocked/paused 流程，不能凭 UI 成功提示恢复执行。应用的幂等、候选哈希、基线和当前目标检查继续沿用现有权威合同。系统层停用只移除用户系统文档，平台启动底线保留，不能称为仍保留被移除的系统约束。旧管理员 confirm 是批准并应用兼容入口，新页面继续分开 approve/apply。

停止接口兼容无请求体及空对象的旧调用；新 UI 带身份确认，身份或策略变化返回 409 并且不关闭新的执行门。仅携带 generation 而无 policy_hash 返回 422。兼容入口不宣称具备 UI 的版本确认语义。

## 会话中文名称

新增管理员元数据表 instance_session_display_names，主键 (instance_id, session_id)。POST /api/agent-instances/{ident}/sessions/{sid}/name 接受 name 和 required expected_name（可为 null）；仅处理当前实例已知原生/历史缓存会话，限制单行 1–120 字，BEGIN IMMEDIATE 内再次比较当前名称，漂移返回 409。写入 metadata revision 和审计，不调用原生 rename/resume/prompt/start。

名称投影进入会话目录、详情、策略上下文及审批来源；搜索保留原始 native_name。原生缓存和原始标题保留，显示名称不参与执行身份、来源证明、权限或场景材料指纹。修改历史冷会话不会启动它。中文显示不等于原生客户端全部汉化，也不将显示名称当作可信工作区归属。新任务使用中文输入；不存在按标题自动建立权限或自动翻译后台会话的规则。

## 发布与验收

以当前运行的 d66605e / policy-flow 发布作为整合基线；独立工作树合入当前功能，再 overlay API/UI。发布器逐文件核对运行基线、Broker、空闲状态、权限快照和其他端口，备份 UI/数据库并保留旧发布。API 允许短暂重启，Broker 和既有 Agent 身份、策略不改变。真实删除/停用/停止仅在 18186 独立 DB/socket/BPF pin 测试实例验证。正式环境只写用户已要求的会话显示名称；不批准、撤回或应用正式候选。
