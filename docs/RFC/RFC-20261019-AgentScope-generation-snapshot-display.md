# 每轮策略配置的生成快照

状态：已实现，验收记录见同名 REVIEW。范围仅为 Agent 页对话结果展示。

## 合同

`template_configuration_requests.result_json` 在生成成功的同一事务中，除既有配置编号、版本、问题与能力缺口外，新增 `configuration_snapshots`。每项保存实际策略名称、配置编号与版本、配置内容指纹、模板编号/名称/版本/参数标签与类型、已校验并规范化的参数、精确作用范围及生成时显示名称。调用方不能提交快照字段。配置写入失败时快照与请求完成状态一起回滚。

`GET /api/policy-templates?scope_id=...` 的每轮历史附带这些快照。名称、模板、参数与范围读取生成时内容，不连接当前配置或最新模板来覆盖历史。历史请求没有快照时，仅允许根据既存的同一配置版本、同一模板版本及匹配的模板指纹恢复展示；历史 Agent 名称未记录时明确标注。缺失版本不推测内容，也不自动回填数据库。

审批状态是只读投影，按配置编号、生成版本及精确 scope 关联权威审批对象。其他配置版本的审批不能借用。显示待提交、待审批、已批准待应用、已应用、需重新校验等状态，停用审批单独表述。模板与参数仍保持冻结。无法核验时显示状态暂不可用。

## 界面与边界

每轮助手回复显示实际策略名称、模板及版本、已填写参数、作用范围、审批状态。参数使用该版本模板中的标签，不展示原始 JSON。正文、路径和名称由 React 转义。窄屏参数换行，消息区沿用现有内部滚动。

不新增手工配置入口、模型工具、审批按钮或加载行为。保留一个对话输入框及既有附件能力。既有配置记录中的提交、查看审批、停用流程继续使用原合同。生成、批准、显式应用与内核运行拦截仍是独立事实。

本次不修改 DSH、Broker、ActPlane、模板选择算法、模型提示词或作用范围语义。
