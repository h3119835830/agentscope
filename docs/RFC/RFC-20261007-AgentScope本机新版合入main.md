# RFC — 本机新版发布到 main

日期：2026-10-07。用户已明确授权“都要目前这个本机的新版的，推到 MAIN”，取代此前只推 WINDOWS、等待 main 审批的发布限制。

发布包含已推 WINDOWS 的受管 DSH/Scope 工作台及 ActPlane 依赖，并纳入当前本机的 DSL 归一化、隔离启动/清退、服务托管与最新本机入口改动。以隔离工作树中的固定源码快照进行核验，不切换、重置或提交正在开发的原工作树。

权限职责不变：Pi 提出候选，可信控制面审核、核验和加载，DSH 执行，Broker/ActPlane 强制限制。归一化只对受支持的等价条款复用，保留来源与不可覆盖底线；不能把分析报告或候选审批当作生效证明。

本机入口按当前源码取消登录页、浏览器票据和 Cookie 链路。显式开启的本机演示模式只接收本机请求，网页 Origin 必须匹配来源端口；默认后端身份校验及 DSH/Pi 任务凭据仍保留。界面是本机 Demo，不据此声称支持远程管理。

只发布代码、技术记录及已筛选公开证据；凭据、数据库、任务工作区和原始模型会话不进入 Git。归一化最终六会话验收和开放 BUG 的状态保留，源码发布不等于其全部完成。

机器快照见 [清单](../releases/20261007-main-local-manifest.json)。本次发布不重启或替换正在运行的服务。
