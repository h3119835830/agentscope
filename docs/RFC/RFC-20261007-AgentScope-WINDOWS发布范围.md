# RFC — AgentScope WINDOWS 分支发布范围

日期：2026-10-07。状态：发布候选已通过本次源码回归；只向 WINDOWS 发布，main 合并等待用户明确批准。

本次以 `codex/scope-demo-v1` 的 `83743c3` 为实现基线，包含历史策略审核与任务通信、文件 Scope 生命周期、DSH 连接证据、原生受管 DSH/Pi、隔离执行和逐句策略记录。职责继续为 Pi 提出候选、可信控制面审核和加载、DSH 执行、ActPlane 强制限制。

补入 `23d4eb9` 的七个 ActPlane 文件：工具调用标签、实际进程域、硬链接保护、C 审计读取器、Rust 事件解码与两份预编译对象。审计 ABI 为 392 字节；这些文件必须成套发布。隔离发布工作树中的对应提交为 `51dd3e1`。

本次没有增加授权能力。批准、加载、核验、当前有效 Scope、进程存活及历史回传仍分开记录。同域追加限制；扩权按既有合同更换完整策略包和执行域。此发布不把自建 Demo 或固定 OS 探针等同于公共 benchmark 成绩。

整理开始时归一化开发工作树有 34 个修改文件和 8 个新增文件；其后继续出现的未提交开发文件也全部保留原处，不纳入此发布快照。另一个工作树中的旧 Pi 工作台、候选库等十个独立提交也不混入当前工作台。旧本地 WINDOWS 指针保留在本地归档分支，不删除原提交。

仓库仅推送 `h3119835830/agentscope` 的 `WINDOWS`。技术文档仓库中的其他项目、原始会话、数据库、凭据、临时产物均不发布。GitHub 主分支继续保持审批门；本次用户授权不含 main 合并。
