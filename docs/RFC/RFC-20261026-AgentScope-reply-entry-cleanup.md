# RFC：移除助手详情入口并清理闲置产物

日期：2026-10-26。状态：隔离验收通过；未发布正式服务。

用户要求移除回复中的“查看详情”。PolicyAssistantResponse 仅保留读取说明、编号清单和真实状态；补充问题与能力缺口继续保留。删除该入口对应渲染和样式，不删除服务端生成回执、原失败数据、模板或系统管理端配置能力。

没有详情入口后，条件型策略在清单中直接保留检查程序、退出码等保存参数，以“按模板条件约束”表达；不能留“见详情”死提示，也不能把条件约束改写为无条件禁令。不改模型提示词、候选参数、权限、审批或加载。

清理只涉及已核对的闲置链接、测试缓存及本轮先前的隔离测试克隆；活动依赖、源文件、PPT 产物、业务回滚备份与验收证据保留。Windows 递归清理被自动审批拒绝后改用更小范围和可恢复方式，不跨链接删除共享依赖。/tmp 测试副本移至同文件系统临时回收区，目录会受 WSL 临时目录生命周期影响，不能当长期备份。
