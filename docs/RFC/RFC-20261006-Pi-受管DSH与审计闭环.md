# RFC：Pi 启动策略、受管 DSH 与审计闭环

状态：工程安全验收通过；支付任务完整修复未通过。日期：2026-10-06。

## 架构与职责

Pi 只理解任务并提交结构化候选。控制面拥有来源登记、读回执、哈希、候选校验、上下文版本和确认状态。特权 Broker 执行编译、暂停/终止、完整策略包加载、真实 PID/策略域绑定及同域验证。DSH 原生 Agent 负责执行任务。后台采集真实内核事件并回传原生会话；页面不参与采集。

ActPlane §5.6/RQ5 从任务描述生成启动策略并加载高层域。项目材料读取、原生 DSH 多轮会话、运行时评估/确认、反馈和持久审计是本工程扩展，不作为论文基准成绩。原文 ActPlane-2606.25189v2.pdf 已保存在技术文档目录。

个人 DSH 3000 与受管实例分开；AgentScope 为 18003。每任务独立工作区、原生网页实例、持久 Session ID 和进程策略域，使用 /s/<task>/r 的短路径映射。域切换恢复同一原生会话及公开历史。固定七项左侧导航；主页显示状态、当前策略和事件，DSL/JSON/完整证据放在详情抽屉。

## 启动合同

启动依次要求：原始 task/platform/environment/dsh_config 真实读取回执、相关登记项目材料、审核过的历史模板、原子规则证据、校验与编译、加载回执、PID/域绑定和独立操作验证。仓库事实和危险任务请求不能授予权限。必要约束无法执行、证据未读、输入漂移、编译或加载失败都不得放行任务。

策略生成、策略加载、正在生效分别记录。生成器不能执行任务、访问评测器或批准/加载策略。启动候选的新规则必须引用任务/平台权威与已读项目来源；提交时复核不可变的校验哈希。读取补证不消耗首次加两次语义修复额度；启动总预算仍为 40 工具调用/180 秒。

原始冻结测试集合逐文件保护，不扩大为所有未来测试缓存。原始任务和项目文件保留；未新增场景说明 Markdown。

## 运行时合同

真实 native_user 消息、真实结构化问答、DSH 权限申请、真实内核拒绝、经过独立验证的误拦截都可入队评估。公开请求历史独立保存；保留全部尚未评估 ID。重复事件去重；作业冻结 revision、policy_hash、session、启动底线、当前已核实快照及当前项目哈希。旧作业/候选不得应用。

候选接口仅接受已公布的 allowed_write_dirs、allow_output、protected_paths、evidence_ids、decision 和 unresolved_requests。新增保护必须同时有读回执和 authorized_protection_targets 中的真实用户明确目标条款；项目事实不能自己授权保护目录。精确路径、无歧义登记文件名和明确目录整树条款是有界自动授权能力。纯语义可作为指导；必要而不支持/不明确的 OS 约束必须待澄清，不能静默当作 no_change。

在已授权范围内，启动和收紧自动应用。收紧先关新工具闸门，终止当前域工具子进程及独立持有 FD/共享映射的进程，然后加载新包并验证。扩权保留待确认意图，但旧哈希失效；只有认证管理员确认当前候选，复核全部来源哈希后，才完整重建策略包和新域。启动安全底线始终继承，运行时不得释放。结束撤销临时权限、进程和令牌。

主要接口：/api/managed/scenarios/{case}/tasks；/api/managed/tasks/{id}/{start,prompt,native,close}；/api/managed/tasks/{id}/startup/clarify；/api/managed/tasks/{id}/expansion/confirm；/api/managed/tasks/{id}/{policy,audit,open,verify-operation}。插件和生成器接口使用任务/作业绑定凭据，不能替代管理员确认。

## 审计与证据

根所有的内核日志持续后台采集，关联真实进程域、匹配规则域、PID、继承的调用标识、任务、会话、轮次、策略版本、操作对象、规则和反馈。持久 outbox 处理工具返回后的迟到拒绝；原生 flush 回执后才记录送达。原生 hook 的即时反馈由实际 session context 消息哈希再次核验。导出只保留公开反馈哈希与关联结果，不导出完整原生日志、凭据或模型私有推理。

内核拒绝、Agent 自报拒绝、控制面暂停、独立文件效果核实的实际允许分别展示。独立探针不算 Agent 尝试；Agent 未尝试也不算内核拦截成功。分类审计先在数据库过滤，再按 ID 分页，不能从截断的混合事件窗口猜测是否有拦截。

## 已公布的实际边界

当前运行时结构合同支持一个连续可写子树；protected_paths 联合阻止 write/unlink。引擎路径预算 64 字节，使用短映射并在编译时检查。来源普通文件上限 16 MiB，工具显示材料上限 8000 字符、哈希覆盖完整字节；读回执证明返回了材料，不能证明模型理解。依赖受信 Native CLI/SDK/已安装插件的真实事件来源；不宣称对任意被替换的 Agent 进程提供同样的权威保证。

内核审计 ABI 为 392 字节；C/BPF/Rust 与两份预编译对象一起更新。仅使用隔离的私有 ActPlane 二进制和 pinned engine，未替换共享服务或个人 DSH。


## 已验证的原生消息与事实读取合同

waiting_clarification 时以真实 SDK agent/inbox/spliced 的 user/rpcId 接收记录触发评估，排除 context/canceled；后续 user/message 使用相同 RPC ID 去重，并补齐 dispatched_turn。现场必要 TLS 约束暂停后，真实澄清在原生工具仍等待时生效，未重启即恢复；一个接收消息只产生一个评估作业。

当前加载快照公布 execution_targets，包含任务输出的实际映射、授权状态、版本与哈希；expansion_targets 只表示尚需确认的目标。已授权输出目标不会因待扩权列表为空而丢失。Native get_current_scope 提供有界的真实待澄清/已解决记录；这些记录不授予权限。Agent 已现场据此纠正历史自报。

原生控制面请求对短暂网络/502/503/504 故障重试，保留原请求标识和工具闸门；30 秒预算耗尽失败关闭，不重试认证失败。插件 9 项测试通过；实际暂停隔离 API 15 秒后原请求重试恢复，合法写入完成，同 Native PID/SID/域/策略/底线保持。另一次 API 真重启验证了持久审计及进程绑定。


## 控制资料读取隔离与启动澄清

控制源码及本地评测库、服务数据库/报告/导入数据/日志由启动 OS 底线禁止 Agent 读取；为当前两份固定公开探针代码保留受控只读前缀，否则同域验收助手本身无法启动。项目材料注册隔离与 OS 读取隔离分别验证。受信根协议的三个固定读取探针（评测 manifest、服务 DB、公开控制 canary）均 EPERM 且有实际域/PID 的内核记录，未导出内容。网络仍按平台公布能力执行，不宣称基于 OS 文件规则约束任意 HTTPS 内容。

/api/managed/tasks/{id}/startup/clarify 仅认证控制面可用，且要求未加载过策略的暂停任务。保留原始任务，新增 task 角色权威来源和哈希；撤销旧启动凭据、登记新 context revision，重新生成、读取必读来源并校验。已加载的底线不可经此入口重写。DSH 同时获得真实补充请求。结束任务也撤销仍在生成的启动作业/凭据。


控制读取目标由已登记的专用状态目录解析，使用引擎可准确执行的绝对路径/末尾通配；不使用中间 glob。已公布的 task-python 环境保留读取例外。父子域固定规则容量需同时核验；展开控制目录为大量细粒度规则曾失败关闭，合并目录规则后的完整双场景回归通过。正式验收含 124 核心 OS 探针及 8 个读取检查，功能与保护结果独立报告。
