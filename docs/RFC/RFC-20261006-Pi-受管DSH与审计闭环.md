# RFC：Pi 启动策略、受管 DSH 与审计闭环

状态：前版工程安全验收通过；本次执行沙箱与 Pi 上下文/记忆闭环专项验收通过；支付任务完整修复未通过。日期：2026-10-06。

## 架构与职责

Pi 只理解任务并提交结构化候选。控制面拥有来源登记、读回执、哈希、候选校验、上下文版本和确认状态。特权 Broker 执行编译、暂停/终止、完整策略包加载、真实 PID/策略域绑定及同域验证。DSH 原生 Agent 负责执行任务。后台采集真实内核事件并回传原生会话；页面不参与采集。

ActPlane §5.6/RQ5 从任务描述生成启动策略并加载高层域。项目材料读取、原生 DSH 多轮会话、运行时评估/确认、反馈和持久审计是本工程扩展，不作为论文基准成绩。原文 ActPlane-2606.25189v2.pdf 已保存在技术文档目录。

个人 DSH 3000 与受管实例分开；AgentScope 为 18003。每任务独立工作区、原生网页实例、持久 Session ID 和进程策略域，使用 /s/<task>/r 的短路径映射。域切换恢复同一原生会话及公开历史。固定七项左侧导航；主页显示状态、当前策略和事件，DSL/JSON/完整证据放在详情抽屉。

## 启动合同

启动依次要求：原始 task/platform/environment/dsh_config 真实读取回执、相关登记项目材料、审核过的历史模板、原子规则证据、校验与编译、加载回执、PID/域绑定和独立操作验证。仓库事实和危险任务请求不能授予权限。必要约束无法执行、证据未读、输入漂移、编译或加载失败都不得放行任务。

策略生成、策略加载、正在生效分别记录。生成器不能执行任务、访问评测器或批准/加载策略。启动候选的新规则必须引用任务/平台权威与已读项目来源；提交时复核不可变的校验哈希。读取补证不消耗首次加两次语义修复额度；启动总预算仍为 40 工具调用/180 秒。

原始冻结测试集合逐文件保护，不扩大为所有未来测试缓存。原始任务和项目文件保留；未新增场景说明 Markdown。

## 运行时合同

真实 native_user 消息、真实结构化问答、DSH 权限申请、真实内核拒绝、经过独立验证的误拦截都可入队评估。公开请求历史独立保存；保留全部尚未评估 ID。重复事件去重；作业冻结 revision、policy_hash、session、启动底线、当前已核实快照及当前项目哈希。旧作业/候选不得应用。

候选接口仅接受已公布的 allowed_write_dirs、allow_output、protected_paths、evidence_ids、decision 和 unresolved_requests。新增保护必须同时有读回执和 authorized_protection_targets 中的真实用户明确目标条款；项目事实不能自己授权保护目录。精确路径、无歧义登记文件名和明确目录整树条款是有界自动授权能力。纯语义可作为指导；必要而不支持/不明确的 OS 约束必须待澄清，不能静默当作 no_change。

在已授权范围内，启动和收紧自动应用。收紧先关新工具闸门，终止当前域工具子进程及独立持有 FD/共享映射的进程，然后加载新包并验证。扩权保留待确认意图，但旧哈希失效；只有认证管理员确认当前候选，复核全部来源哈希后，才完整重建策略包和新域。启动安全底线始终继承，运行时不得释放。结束撤销临时权限、进程和令牌。

主要接口：/api/managed/scenarios/{case}/tasks；/api/managed/tasks/{id}/{start,prompt,native,close}；/api/managed/tasks/{id}/startup/clarify；/api/managed/tasks/{id}/expansion/confirm；/api/managed/tasks/{id}/{policy,audit,open,verify-operation,verify-task-sandbox,compact}。插件和生成器接口使用任务/作业绑定凭据，不能替代管理员确认。

## 审计与证据

根所有的内核日志持续后台采集，关联真实进程域、匹配规则域、PID、继承的调用标识、任务、会话、轮次、策略版本、操作对象、规则和反馈。持久 outbox 处理工具返回后的迟到拒绝；原生 flush 回执后才记录送达。原生 hook 的即时反馈由实际 session context 消息哈希再次核验。导出只保留公开反馈哈希与关联结果，不导出完整原生日志、凭据或模型私有推理。

内核拒绝、Agent 自报拒绝、控制面暂停、独立文件效果核实的实际允许分别展示。独立探针不算 Agent 尝试；Agent 未尝试也不算内核拦截成功。分类审计先在数据库过滤，再按 ID 分页，不能从截断的混合事件窗口猜测是否有拦截。

## 已公布的实际边界

当前运行时结构合同支持一个连续可写子树；protected_paths 联合阻止 write/unlink。引擎路径预算 64 字节，使用短映射并在编译时检查。来源普通文件上限 16 MiB，工具显示材料上限 8000 字符、哈希覆盖完整字节；读回执证明返回了材料，不能证明模型理解。依赖受信 Native CLI/SDK/已安装插件的真实事件来源；不宣称对任意被替换的 Agent 进程提供同样的权威保证。

内核审计 ABI 为 392 字节；C/BPF/Rust 与两份预编译对象一起更新。仅使用隔离的私有 ActPlane 二进制和 pinned engine，未替换共享服务或个人 DSH。


## 已验证的原生消息与事实读取合同

waiting_clarification 时以真实 SDK agent/inbox/spliced 的 user/rpcId 接收记录触发评估，排除 context/canceled；后续 user/message 使用相同 RPC ID 去重，并补齐 dispatched_turn。现场必要 TLS 约束暂停后，真实澄清在原生工具仍等待时生效，未重启即恢复；一个接收消息只产生一个评估作业。

当前加载快照公布 execution_targets，包含任务输出的实际映射、授权状态、版本与哈希；expansion_targets 只表示尚需确认的目标。已授权输出目标不会因待扩权列表为空而丢失。这些权限、版本、绑定和待澄清记录只供 Pi 与控制面使用。已移除原生 get_current_scope、scope_change 和策略决定上报工具；DSH 不查询确认 OS 策略。前版查询功能仅保留历史验收证据。

原生控制面请求对短暂网络/502/503/504 故障重试，保留原请求标识和工具闸门；30 秒预算耗尽失败关闭，不重试认证失败。插件 9 项测试通过；实际暂停隔离 API 15 秒后原请求重试恢复，合法写入完成，同 Native PID/SID/域/策略/底线保持。另一次 API 真重启验证了持久审计及进程绑定。


## 控制资料读取隔离与启动澄清

控制源码及本地评测库、服务数据库/报告/导入数据/日志由启动 OS 底线禁止 Agent 读取；为当前两份固定公开探针代码保留受控只读前缀，否则同域验收助手本身无法启动。项目材料注册隔离与 OS 读取隔离分别验证。受信根协议的三个固定读取探针（评测 manifest、服务 DB、公开控制 canary）均 EPERM 且有实际域/PID 的内核记录，未导出内容。当前模型执行世界采用独立网络命名空间，不开放网络工具与主机交互终端；必要网络任务属于未公布执行能力，须暂停而不能回退到主机网络。DSH 受信传输宿主仍联网调用模型与任务 hook；不宣称文件规则可以约束 HTTPS 内容。

/api/managed/tasks/{id}/startup/clarify 仅认证控制面可用，且要求未加载过策略的暂停任务。保留原始任务，新增 task 角色权威来源和哈希；撤销旧启动凭据、登记新 context revision，重新生成、读取必读来源并校验。已加载的底线不可经此入口重写。DSH 同时获得真实补充请求。结束任务也撤销仍在生成的启动作业/凭据。


控制读取目标由已登记的专用状态目录解析，使用引擎可准确执行的绝对路径/末尾通配；不使用中间 glob。已公布的 task-python 环境保留读取例外。父子域固定规则容量需同时核验；展开控制目录为大量细粒度规则曾失败关闭，合并目录规则后的完整双场景回归通过。正式验收含 124 核心 OS 探针及 8 个读取检查，功能与保护结果独立报告。

## 执行角色隔离（2026-10-06 修订）

DSH 模型只获得原始任务、平台语义要求、项目文件及公开路径。启动、恢复和操作反馈不含已确认 DSL/JSON、保护集合、策略版本/哈希、规则 ID、进程域或扩权候选。插件 gate 只返回 phase/gate 的调度状态；完整现行策略属于 Pi/管理员接口。

模型调用的 bash、glob/grep 子进程进入 bubblewrap 新根及 PID/net/ipc/uts/user 命名空间，capabilities 全部移除、环境按固定白名单重新构造。可写挂载仅当前项目、临时和输出目录；输出写入仍受 ActPlane 当前授权约束。标准 /usr、公用 Node 与 Python 依赖只读。控制源码、服务数据、运行套接字、任务 .dsh/凭据、.runtime-control、其他任务和主机进程不挂载；项目 .actplane 被空挂载遮蔽。无不可用时的主机执行回退。

文件能力的 resolve/stat/read/list/write/edit/stream/image 通过相同隔离根中的独立 Native LocalFileSystem 进程执行，复用原生 CAS、版本、UTF-8 校验和原子替换。沙箱外 resolve 只产生词法 target，stat/lstat 返回不存在且不进行主机 IO，使 Native 向上查找 AGENTS.md 可安全停止；内容读取仍拒绝。背景符号链接变化也不能让隔离根内 syscalls 进入主机。文件监视仅限公开任务根。

DSH 的 Node 宿主、模型传输、持久会话和 hook 为受信适配层，仍位于主机上，不能混称为模型执行世界。公开执行工具白名单同时过滤模型 schema 与实际 pre-execute；网络/任意脚本 SDK/终端/子 Agent 工具未开放，避免旁路能力。模型不能通过 bash 的环境、进程、localhost 或文件能力获得宿主控制凭据。

Pi 启动读取与校验加载流程不变。运行时额外观察真实 Native system/message、developer/message、request/header 的公开工具 schema、context 和 compaction/summary/prune；按当前 deriveMessages 表面投影及内容哈希去重，不读取 rawOutput、assistant reasoning/attempt/stream。观察值及最新上下文进入冻结作业，关闭新工具闸门，Pi 可返回 no_change/指导/候选。观察不是用户授权；现行显式目标授权和启动底线继续校验，扩权仍须明确确认。

DSH 只接收本次操作、任务内对象、denied、通用原因和任务修正建议。控制对象显示 outside task execution environment，完整内核规则、PID/域/版本保留 AgentScope/Pi 审计。旧会话含策略上下文，保留为历史且不作为新隔离角色的活动会话恢复。

## 本次合同补全与验收回执

现行 execution_targets 明确公布独立于工作区相对写范围的 task_temporary；可提议的 expansion_targets 与加载所需 confirmation_required 分阶段表达。尚未确认的公开扩权目标可以生成待确认候选，但不能直接执行。未知、含糊或未公布目标继续 unresolved；本次输出 v5→v6 确认后新域加载、同 SID、底线不变和实际文件产出已核验。

feedback_offer 表示 hook 提供的上下文，不等于送达。实际 Native user/message 或未取消的 inbox/spliced context 才形成 feedback_received，服务端与已提供的文本/内核对象精确匹配；同一 Native event 内多段反馈按内容哈希区分。迟到 outbox 以持久 flush 确认并独立读取原生文件中的反馈摘要哈希核对。SDK 固定验收调用也显式转发 additionalContexts 并 flush，不冒充 Agent 尝试。

compact 是认证管理员的固定维护入口，仅接受绑定且 idle/open 的会话，调用已安装原生 compaction-basic 引擎，返回布尔结果与会话标识，不返回私有输出。可选 compaction 服务通过 Cordis 子注入取得；缺失时维护操作失败，但不禁用必需的沙箱 hook。现场手动压缩产生真实 compaction/summary 和新的有效上下文，Pi 读取了相同记忆哈希；该手动路径未产生 compaction/prune，不宣称发生了 prune。

启动/策略替换任一 launch/create/verify 失败都停止替换域、撤销令牌、同步 failed/gate 和任务运行状态，清除活动 PID。恢复保留未批准扩权意图，废弃旧候选哈希，须重新评估及明确确认；不能把保存意图当作加载授权。短生命周期 /proc 进程退出的 ESRCH 只排除该退出成员，不将仍在运行的任务误判失败。
