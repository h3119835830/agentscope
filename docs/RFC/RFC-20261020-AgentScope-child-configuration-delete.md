# 未使用子配置删除入口

日期：2026-10-20。范围：系统 → 策略与配置 → 模板展开 → 子配置行。基线为正式静态前端来源 `3e4e837`，独立工作树 `agentscope-configuration-delete-20261020`；不合入统一状态或并行信息流重写。

## 职责及接口

未应用任何版本的配置显示“删除”；仍有版本在应用的配置显示“停用”，停用继续经审批后单独应用。不能用 Agent 未运行或最新版本被拒绝推断配置已停用。待审批、待应用和应用中的当前变更先在审批模块结束，列表不开放删除。

删除前展示准确配置名、作用范围，说明只移出列表、保留不可变版本与审批/应用历史，不删除模板、不改变当前策略。模板子配置复用 `POST /api/policy-template-configurations/{id}/archive`，旧系统子配置复用 `POST /api/security/system/policy-library/{id}/archive`，提交精确版本。后端已有版本冲突和当前应用文档检查，不改变接口、鉴权、数据库或审批逻辑。

列表删除成功后重新读取；失败不先隐藏记录。没有新增批量删除或物理删除入口。历史可由原审批记录追溯；本次不新增恢复入口。

## 后续职责收敛

Agent 仅策略起草；系统唯一配置管理；会话唯一加载/事件/信息流详情，保留共享执行域范围。旧 RFC/ADR/REVIEW 的重复导航已标注废弃或修正，但导航代码迁移不在本步交付内。

用户已明确授权验收后更新 18003，仅原子切换静态前端，保留旧资源与入口备份。不重启 API、Broker 或 Agent，不修改 ActPlane，不替用户删除现有记录，不推送远端。发布需核对 API 源码基线、当前前端入口哈希、进程身份、策略权威状态和其他服务端口。
