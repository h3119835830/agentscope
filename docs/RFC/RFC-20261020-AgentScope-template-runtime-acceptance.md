# RFC：模板真实运行验收与能力展示

## 范围与合同

为当前 37 个模板逐项提供执行能力事实。运行验收与当前 Agent 的加载/生效回执严格分开，不改 DSH、ActPlane、Broker 或审批/应用协议。可执行模板使用现有服务端渲染器和正式同哈希 ActPlane 二进制，在独立进程与 pin root、合成文件/仓库和本机接收端验证。无法执行的模板验证草案与拒绝路径，不能表示为已通过内核拦截。

`template_support` 从模板执行结构计算合同哈希，读取发布时的验收清单，给模板详情、子配置与 Agent 模板目录提供统一事实。哈希包含执行器、固定命令、参数键/类型/选项及操作合同，不包含名称、说明、标签、默认参数和版本号；实测只证明列出的代表参数场景，不证明全部参数值。保存模板不更新已有配置或审批。

`execution_support.verification` 区分 verified（合成场景真实运行记录）、rejected（已验证无运行能力且拒绝提交）、not_verified（没有匹配合同的记录）。该事实不授予权限。当前实例能否加载仍由权威编译、运行能力与目标核验决定；若匹配清单中缺少某动作，通过配置提交/审批/应用路径拒绝。

## 历史入口

RQ1-CHECK / RQ1-GIT 只读。新建、配置编辑、模板编辑、重新提交、重新校验和应用均在服务端拒绝；UI 同步关闭保存/提交，助手继续排除历史模板。历史版本、生成快照、审批和已生效 DSL 不改写。停用属于独立删除约束申请，仍需批准后单独应用。

## 执行边界

文件修改与删除共享访问组。IPv4 新连接限制不覆盖已有连接发送、域名、端口或 IPv6。信息流来自观测标签，不能替代内容检查。kill 终止进程并不保证此前没有副作用，网络实测可见 TCP 已接受。Git 参数仍为执行后观察，不能事前 block；旧检查只要求执行事件，不校验检查成功退出码。详细结论见同期 REVIEW/BUG。
