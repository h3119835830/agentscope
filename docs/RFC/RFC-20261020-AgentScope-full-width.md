# 全模块主内容区宽度

用户要求所有模块使用全屏可用宽度。本次只调整视图布局，直接修改 main。

- 总览、连接、会话、审批、Agent、系统、历史档案共用 `.main[data-page] .content` 宽度合同：width 100%、max-width none、min-width 0；保留各模块内边距。
- Agent 助手外框与参考选择区使用可用宽度，正文、表单控件、弹窗及抽屉保持现有阅读或交互尺寸。
- 系统策略模板表最小宽度为容器的 100%；原列宽总和超过容器时继续使用横向滚动。子配置保持独立滚动和准确范围。
- 不改变接口、状态投影、配置、审批、加载或 ActPlane。18003 只发布经逐字节核对的 CSS 及其 index 引用，保留生产 JavaScript。

验收覆盖七个模块的 1920、1280、600px 视口、侧栏展开/收起、助手准确目标、系统子页、列宽恢复与子配置滚动。证据见对应 REVIEW。
