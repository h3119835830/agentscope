# ADR：普通页面不承担运行时诊断

日期：2026-10-20；状态：已采纳并联合验收。

采用：子配置表只用于识别、状态与操作，保护对象留详情；每个模板仅一个新增入口。原始运行身份仅保留于后端审计和核验，不以“技术证据”折叠框继续塞进普通页面。可读结果、范围边界、未核验/采集失败提示仍保留。

废弃上一版“所有诊断只要折叠即可展示”的处理。代价：普通页面不直接调试运行身份；收益：减少重复入口与横向拥挤。不删除证据，不降低核验条件，不新增角色权限或标签能力。

该取舍与信息流证据表共同实施，但不改变 ActPlane 原生接口或引擎。信息流技术证据只在记录详情内折叠展示，普通列表保持业务可读。
