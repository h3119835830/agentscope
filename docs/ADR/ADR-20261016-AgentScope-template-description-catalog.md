# 决策：模板字段与子配置字段分别展示（2026-10-16）

撤销上一版“主表套用子配置字段”的展示。模板主表使用自身说明、配置项名称和默认处置信息；点详情才显示对应子配置的实际字段、记录及行内操作。这样即使没有配置，模板也有可理解的用途和输入合同。

说明采用界面与策略 Agent 同源的 description。描述作为目录导出元数据，独立于已发布版本和执行指纹；拒绝为补说明重写执行定义或迁移已有策略。服务器继续验证模板版本、参数、目标和资料依据，描述本身不构成授权。

继续复用参数化配置 API 和结构化计划，不新增可审批或应用的 Agent 工具。助手可以按场景选择模板与填参，缺少参数或能力仍返回待补充 / 缺口，最终由用户审批后再显式应用。

同日按用户截图收窄展示：撤销详情中的重复说明与参数定义表，保留目录说明和实际配置编辑器；恢复主记录展开箭头。默认动作与触发操作分列，窄屏取消覆盖相邻内容的固定操作列。此次只调整界面，不改变目录 / 执行定义、API、审批或权限决策。

同日后续更正：主表删除触发操作值，详情改为模板版本编辑，箭头单独展开子配置。旧说明中详情与箭头同步、操作值列的展示约定已被用户新要求取代，最新合同见 RFC / ADR-20261016-AgentScope-template-version-editor.md。
