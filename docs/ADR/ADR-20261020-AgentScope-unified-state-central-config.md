# ADR：统一状态投影与单一配置入口

日期：2026-10-20。状态：本地实现，正式发布未进行。

## 采纳

1. 三轴状态，后端统一投影。运行、配置进度、当前加载是独立事实，不压缩成“已生效”一词。
2. 使用现有观察器/审批/回执，不另建状态表或改变执行授权。前端只处理显示与过期降级，不能把未知提升为绿色。
3. 当前加载绑定完整运行身份和实际哈希；旧不完整身份回执仅保留历史用途。宁可显示未核验，也不以 PID 或执行门代替加载证据。
4. 系统为唯一配置管理入口，保留模板主表和子配置记录；Agent 助手保留起草能力，审批/应用仍独立。
5. 名称用于人读，实例 ID 用于操作。保留用户命名，同名用稳定短标识；不按研究/演示名称清理记录。
6. 运行页面只展示真实事件；高级入口调整信息层级，不宣称实现权限分层。
7. 已加载版本仅做不可变文档唯一匹配。相同内容多版本不能唯一对应时不猜版本号。

## 废弃/延期

- 废弃前端把 active/loaded/gate 拼成单一产品状态，以及连接、助手、会话重复配置入口。
- 废弃会话独立策略域展示；历史工作区归属保留，只读、不迁移。
- 废弃默认模板编辑、默认暴露技术枚举/进程身份及自动弹出公告。
- RQ4 自动收紧/人工扩权双路径是后续架构方向，不是本期产品已实现能力；本期不展示研发流水线占位块。

## 代价与风险

严格身份要求可能令旧运行代次显示“未核验”，这是兼容性降级而不是策略被卸载。8 秒超时和短暂网络故障会让状态暂时降级；不延长 TTL 来改善表面稳定性。状态只读投影增加有界查询成本，不改变引擎或加载事务。系统入口集中后，旧链接需要明确目标映射；历史目标不可悄悄扩大。

批准、应用、归档、停用、停止 Agent 继续是不同操作；本决定不授权自动批准、热切换或删除历史。
