# 独立 Scope Demo 采用 WSL systemd 托管

日期：2026-10-07。状态：已采纳并在本机部署。

## 决策与理由

18003 无监听，而 WSL、18000 和 18004 正常。原 Demo 只有后台启动脚本，WSL 重启后没有服务恢复配置。采用独立 Broker/API unit，复用原实例，不合并其他实例的启动入口。

API 单独采用 on-failure 恢复；Broker 不自动重启，API 与其绑定生命周期。HTTP 服务恢复与原受管任务是否仍有效分别处理，保留 Broker 维护前结束任务的原要求。

桌面入口先启动该实例，再获取原一次性票据。身份、认证合同及用户任务不因此改变。

## 取舍

适配器依赖已有 /opt/agentscope-history-v1、Python runtime、独立数据库、UI 与配置，属于本机运行适配，不是通用安装器。未为测试自启动配置而重启整个 WSL，以免影响其他实例。WSL 本身反复重启的原因不在本次关闭范围内。
