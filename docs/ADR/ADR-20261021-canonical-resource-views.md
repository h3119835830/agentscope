# ADR：以单一规范挂载适配原生 ActPlane，不维护核心 fork

日期：2026-10-21。决策状态：采纳；本次主服务维护已获准，实际发布状态以发布 REVIEW 为准。

## 决策

在 AgentScope 的权限合同、路径投影、启动沙箱及 DSL 适配层新增受审批的短路径资源映射。每个物理子树只暴露一个规范可访问挂载，旧工作区入口在命名空间内指向该挂载。readonly 项目与两个可写叶目录独立，测试继续只读。

批准映射及写范围均属于登录操作者治理；Pi 只能消费已应用映射并提议模板子配置，不得自行增加、删除映射或改变父级策略。

## 取舍

- 不扩展 ActPlane 路径 ABI、不修改 BPF/runtime：保留原生设计和上游可比性，接受原生路径与表达限制。
- 不以放开项目父目录再补 tests deny 代替两个叶目录授权：父目录其他文件必须仍只读。
- 不提供第二个可写 bind 别名：原生路径规则可能只命中其中一个路径。
- 不移动宿主 RQ5 文件或重登记资源根：保留原工作区、会话和历史证据路径。
- 不直接沿用有歧义的父路径通配符：分流后语义不能完整表达时明确拒绝。
- 先采用只支持既有目录、追加映射、无 ACL 合成祖先的保守合同；不宣称支持任意文件树、在线重映射或目录创建。
- 宿主 fd 仅交给 bwrap 消费，不交给 Agent。隔离测试曾证明普通 /proc/self/fd bind 会留下来源 fd，已废弃该方案。
- 活跃 DSL 下禁止修改映射，避免未经批准重新解释已有规则；控制面审批哈希覆盖有效权限映射，现有文档指纹保持文档+登记资源语义。

## 后果

主服务需要 API/前端、AgentScope DSL 适配器和 Broker/沙箱版本一致。Broker 维护有全体受控 Agent 暂停风险，必须另行获准。每实例批准后应用也会重建该实例进程，旧句柄随进程终止失效；不是运行时热加载。

现有不存在的验收目录仍需受治理准备，不能绕过本决策开放父目录。真实 RQ5 和运行时自动收紧状态由 REVIEW 单独记录，隔离通过不代表线上通过。

## 发布取舍

本次采用独立不可变版本目录和仅 18003 的 systemd drop-in。界面保留旧哈希资源以兼容已有页面，仅原子切换入口。私有 SQLite 备份用于灾难恢复材料，不在失败回退时覆盖在线事实。发布工具不恢复任何 Agent；浏览器访问尚未恢复时暂停治理验收，而非用 API/数据库完成 UI 批准流程。数据库历史 gate 不作为在线证明，以实际执行清单和 cgroup 核验暂停状态。
