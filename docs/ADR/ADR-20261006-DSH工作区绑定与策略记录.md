# ADR：合并运行入口，投影真实策略记录

> 2026-10-07 后续修订：控制台的自动选择、任务创建入口与历史呈现已由 [Agent 工作区与任务记录](../RFC/RFC-20261007-Agent工作区与任务记录.md) 取代。服务端任务/Session/域关联及逐条证据边界继续有效。

> 逐句合同修订：前版作业级完整 DSL 展示与评估复选框已废弃。现行逐句子句、证据及加载隔离见 [RFC](../RFC/RFC-20261006-逐句DSL与控制台锁定.md)；整包 DSL 仅后台用于验真和加载。

日期：2026-10-06。状态：采纳。

## 决策

1. 删除重复“运行时 Scope”页面入口，把运行前/运行时/执行审计作为任务工作台三个分页；旧 URL 保留兼容重定向。保留运行时 hook 和策略更新功能。
2. 管理员界面读取持久结构化投影，不把混合事件数组或原始 JSON 作为主要界面。详情抽屉用四个分页承载语句、来源、DSL、加载。
3. 工作区依赖受管注册和 Session/PID/domain 绑定核验，唯一活动任务自动匹配；多任务不猜测，历史通过显式切换查看。
4. 新增 Pi 的公开 identified_statements 字段，与权限候选分别校验。语句中的 evidence_ids 必须属于已校验候选证据；分类为 content/cross_event 不代表引擎支持此类约束。
5. 新运行时保存真正编译的完整 DSL/hash；旧数据明确展示可追溯的规则片段或原始目标条款，避免为旧记录伪造 Pi 新字段。
6. 当前状态按实际应用回执和仍保留的增量计算；输出扩权不撤销无关文件保护。

## 取舍

无需数据库迁移，读取现有 proposals/events/source receipts；新字段随候选 JSON 持久化，旧候选兼容。编译结果与展示注释分开，新增注释没有权限权威。

自动匹配限于已登记受管实例，不能自动接管任意个人 DSH。历史启动的 context_required 是控制面推导而非追补模型回答；历史完整 DSL 缺失仍然如实说明。

成功工具调用只归工具层，实际允许需效果核验；将探针成绩与 Agent 尝试分开。普通 no_change 默认隐藏以减少噪声，但保留记录并可查看。

执行沙箱和 Pi/Broker 角色边界不改变。修改仅 AgentScope 及其 Pi 集成，不修改普通业务或父 checkout。
