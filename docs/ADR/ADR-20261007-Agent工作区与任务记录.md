# ADR：分离 Agent、工作区与任务，采用字段记录界面

日期：2026-10-07。状态：采纳并在本机 18003 生效。

## 决策

1. 将“Agent 与工作区”放在任务流程前，连接执行适配器后展示真实目录及文件；普通创建入口接受自由任务目标，不再要求选择硬编码 RQ5 场景。
2. workspace_id 标识文件来源，task_id 标识任务与策略生命周期。移除控制台“切换工作区”以及唯一活动任务的自动选择行为；任务选择通过任务列表和 task URL 完成。机器调用的既有受管绑定接口保留。
3. 创建任务时复制已比较哈希的文件快照。执行目录与源目录分别显示，Agent 不直接修改源目录。已建立 DSH 会话的执行目录也登记为可选工作区，供后续任务读取更新后的文件。
4. 新工作区任务在 Pi 生成后等待显式确认。确认绑定当前上下文与候选，确认时及加载前均复核执行端配置和快照文件；批准、加载、运行进程核验分别记录。旧预授权验收场景 API 不改变授权合同。
5. 历史详情使用字段、逐条规则及记录表。以受限 IR 的操作生成中文要求，保留原句与逐规则 DSL 供展开追溯；不翻译或改写历史策略的语义。任务指导分开展开，完整文档与原始 JSON 退出任务主界面。
6. 新登记仅增加目录读取与任务来源元数据，不赋予项目内容权限权威。Pi 仍只提交候选，Broker 仍是加载边界，DSH 仍只执行。

## 取舍

快照提供稳定的策略证据与任务隔离，代价是源目录不会自动接收 Agent 改动。因此界面同时显示两个目录，并允许直接选取上一任务的执行目录继续工作；没有自动回写或隐藏的目录切换。

新增三张表保存连接、工作区和任务来源，沿用旧策略与审计表。任务目录被归档或缺失时仍保留历史字段；读取文件时单独检查目录可用性。旧场景历史不批量删除，也不伪造迁移后的来源关系。

当前仅接入本机 DSH 适配器。其他 Agent 和未登记个人 DSH 需要各自的工作区及执行绑定适配器；不能因名称出现在页面上而宣称已连接或受管。

本决策替代 2026-10-06《DSH工作区绑定与策略记录》中控制台自动选择与旧任务入口部分；逐条 DSL、证据隔离及内核执行边界继续有效。
