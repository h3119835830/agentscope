# 实例策略、执行重建与短路径映射

状态：采纳，适用独立 18003 Demo。

1. 策略归属实例，原生多会话与共享执行器均继承。工作区只是资源；不根据 PID 或 cwd 猜测多会话的策略切换。不同实例各有域、cgroup、配置、端口和状态目录。
2. 既有实例只观测；受控实例从新会话开始。不把历史任务策略或当前未接管的进程自动变为受控。
3. 所有有效策略变更都排空并重建执行器。仅修改内核映射不能证明旧文件描述符与内存映射被撤销；终止整个受控 cgroup 代价是旧在途任务停止，但原生会话可保留。
4. 原始资源目录与执行路径分开。采用 `/w/N` 的实例内短别名，规避当前 ActPlane 64 字节规则 ABI 截断/前缀碰撞。映射后规则仍超限则拒绝；不改变 ActPlane 核心、不扩大匹配范围、不声称任意深度文件名均被完整支持。启动同时核验允许与拒绝，不能只核验 deny。
5. Agent 只有提出类型化候选的权限。收紧经可信控制层自动验证；扩权需准确候选确认。Agent 自动收紧回执与执行应用异步分离，以便自身工具释放租约。Agent 不能签发审批或调用特权 Broker。
6. Hermes 仅使用 WSL 独立原生安装和 `dashboard --isolated`；可信启动层提供模型配置。保留安装与核心源码，不接入 ERP，不修改任何普通业务代码。
7. Windows 发现是可过期的候选，不构成执行接管。扩大到其他 Agent 需要对应原生会话及执行适配器；OS 发现不能替代工具 Hook 与内核绑定。

## 2026-10-09：首页按 Agent 产品聚合

采纳“一种 Agent 一行，实例详情展开”的展示方式。已有可打开入口优先于未运行的受控连接；只有后者可用时显示“启动网页”。平台仍是一实例一策略，不采纳“一种 Agent 一份策略”：不同实例的策略、域、代次、连接状态不合并，首页覆盖状态只属于当前入口。网页标签不是安全主体，也不作为实例或进程数量依据。

## 2026-10-09：入口方式与 Agent 名称分离

Agent 名称继续使用原生产品名，Web、CLI 安装入口、桌面应用、进程观测作为结构化字段展示。安装入口与运行实例有不同事实，不能通过相同名称或 PID 猜测打开方式。浏览器只按实例 ID 调用已实现的网页适配器；没有终端恢复能力时提供明确说明，不能把 CLI 按钮伪装成网页“打开”。

采用 HTML 导航重新校验，保留已有页面和未保存编辑。自动刷新会打断配置，因此不自动替换已运行标签页的 JS；首次从旧标签页切换到新交付仍需重新加载。

## 2026-10-09：安全配置采用逐条管理

将用户可见的“实例策略”更名为“安全配置”。采用三列主表（完整规则、状态、操作）和单条编辑；来源、机制与精确路径按需查看，运行记录单独成页。原始连接身份字段从界面移除，但不从服务端安全校验中移除。

规则删除沿用现有完整候选及准确哈希确认合同，不提供直接改写生效规则的快捷接口。平台底线和默认只读不提供删除；网络范围通过编辑调整。删除禁止规则仍须确认扩权，当前生效规则在确认前保留。缩短目标路径只改变显示，不能改变提交的目标或自动重定向到其他同名项目。
