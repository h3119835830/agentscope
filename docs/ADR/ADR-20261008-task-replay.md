# ADR：保留旧工作台展示模式，复用只读任务档案

状态：采纳。

用户要求恢复原来完整任务界面的展示模式，并在历史任务中选择；只新增几个精简档案页签不能满足该要求。采用历史列表进入全宽任务回放页的方式，保留原工作台的信息层级、主栏目和策略详情子栏目。任务历史仍为唯一任务档案入口，避免新增另一套任务历史。

复用只读 archive 投影与历史域图组件，不直接挂载原 ManagedWorkbench。原组件会轮询 workspace-binding/workbench 等当前运行接口，带有启动、审批和恢复动作；只禁用按钮不能保证查询无运行时副作用。回放只接收读 API，不接收 post 权限。

不从旧数据库复制记录，也不复原未保存的执行器 PID、底线材料或完整 Scope。当前演示库已有旧 RQ5 的真实策略、工具、内核和加载材料。缺失信息保留“未记录”，这是证据边界，不通过推测修补。

入口收敛：移除工作台重复的历史跳转按钮，侧栏任务历史为统一选择入口。此决定仅调整导航，不删除读取场景后的运行前、运行时、监控或审计能力。
