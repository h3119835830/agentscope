# ADR：历史档案以明确功能组织策略与审计

状态：采纳，已实现。

用户无法从“准备与授权/执行与权限”理解运行前、运行时策略及OS拦截在哪里。阶段摘要仍保留，但主要入口改用明确功能名称，三类审计分别展示；任务概况不再作为唯一默认入口，历史列表“策略与审计”直接进入运行前策略。

复用现有权威表和逐条规则映射，为档案提供只读适配。不得为历史页面请求会探测/核验当前进程的workbench或binding接口；历史加载状态固定为历史语义。事件线保留为补充，避免收敛时丢失失败、拒绝、过期、无变化记录。

取舍：档案多一个清楚的内部页签，减少对含糊阶段和嵌套详情的依赖；长DSL和公开工具结果按需展开，主列表保持紧凑。
