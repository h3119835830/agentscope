# ADR：复用现有系统策略样式并关闭旧确认加载

日期：2026-10-15。状态：已采纳并发布验收通过。

采用同一系统目录聚合模板与独立配置，沿用当前系统策略样式。助手只在 Agent 页，手工与助手写入同一种模板参数合同并走统一审批。既有系统记录保留原存储、原文与编辑能力，不复制成新的授权记录。

采用 v2 模板开放所有 / 指定 Agent 范围；v1 作为不可静默改写的历史合同保存。范围保持真实实例身份，重名实例在选项中区分。没有执行支持的配置不因界面合并而获得加载资格。

旧 confirm 只批准，禁止再组合应用。人工 apply 校验批准回执和冻结目标；这有意收紧旧调用方行为，旧客户端应转到统一审批页单独应用。批量提交仅允许同一 scope_id，范围混选分批处理。

不更改 DSH、Broker 或内核引擎；本次为控制台与审批入口收敛。理由和验证边界见 [RFC](../RFC/RFC-20261015-AgentScope-unified-policy-catalog-implementation.md)。
