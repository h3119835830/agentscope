# ADR：隔离试验采用运行前同型来源工具

日期：2026-10-26。状态：仅采用于隔离试验，默认关闭；不取代正式运行时合同。

采用来源读取、模型自选检索 query、能力查询、结构化草稿校验与按哈希提交的原生 Pi 工具链。用户描述对象用途时，由 Pi 结合已加载记忆和登记材料解析具体对象；控制面不再要求同一对象路径必须逐字出现于本轮用户提示词。

保留来源身份、跨任务隔离、只读材料、编译、旧规则不可变、同域追加、效果验证与失败关闭。模型不获得 shell、数据库、应用凭据或直接加载能力。记忆依然不是独立用户授权；每项执行限制须引用已认证用户要求。

取舍：去掉路径关键词预选后，语义关系正确性更多依赖策略 Agent。控制面的确定性检查只能证明对象、来源、状态和操作边界，不能证明“用户要求必须对应此对象”。因此本轮默认关闭，并以同提示词/不同记忆、伪授权记忆和合法任务对照作为验收，不用调换模型或添加针对用例的提示词掩盖上下文接线问题。

暂不扩展文件以外的执行器；能力工具明确返回尚不支持的操作。后续程序和网络增量须单独完成 DSL、原生 Delta、作用范围及实际效果验收，不能从系统模板目录推断已经支持。
