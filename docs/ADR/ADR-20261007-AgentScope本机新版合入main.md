# ADR — main 使用当前本机源码快照

日期：2026-10-07。状态：采纳。

- 用户已明确批准 main 发布，纳入此前为 WINDOWS 保守排除的本机新功能。当前新版作为合并内容；另一开发线的旧 Pi 工作台不替换新版。
- 复用隔离发布工作树，从 WINDOWS 已验证提交继续，复制当前源码及必要删除项。原开发分支、未提交工作和运行任务继续保留。
- 保留上一轮已验证的可移植测试断言、CI 及完整 ActPlane C 审计读取器。内核源文件、事件 ABI 和预编译对象成套记录。
- CI 先构建该提交的 release 编译器，再执行 Python 归一化测试，防止“缺少编译器所以跳过”的假通过。
- 远端 main 仅作 fast-forward 更新；如有并发远端改动，先整合和重新核验，不 force push。发布前后核对远端 SHA。
- 保留已知限制与失败证据，区分源码回归、固定沙箱检查、历史真实执行和仍在进行的最终模型/内核验收。
