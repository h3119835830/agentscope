# 用原生只读元数据补齐会话名称

日期：2026-10-09。状态：已采纳。

现有 DSH 实例桥接返回真实会话 ID、状态和进程关联，但不提供名称。采用原生 session/list 的只读投影补充名称，避免为界面字段重启共享 DSH 执行器。Broker 和原生任务执行进程不需要重启，API 加载新模块后即可使用。

基础会话集合和 PID 以既有实例接口为准。名称只能按会话 ID 与资源目录双重关联；不把原生列表中的其他会话加入实例列表。原生列表调用不 resume Agent。元数据故障允许名称暂时缺失，不能据此推断会话运行或保护有效。

只输出白名单元数据。认证地址与 cookie 仅在单次调用内存中使用，缓存只存白名单名称信息；固定 loopback 地址、固定方法、限时请求、限量响应和拒绝重定向共同约束读取边界。此处没有增加通用 RPC 代理，也没有扩大 Agent 权限。

移除二级实例弹层，所有受控连接直接在主表可配置。会话页删除不相关的资源表和全实例进程表；共享 PID 保留事实，已保存会话不填造 PID。

限制：原生 session/list 是当前安装版本的类型化接口，升级 DSH 时须复核协议。此集成不能替代进程域或内核拦截验收。Hermes 名称补充已在隔离插件源码与测试中实现；当前 Broker 未重启、Hermes 未启动，尚未验收其运行生效。
