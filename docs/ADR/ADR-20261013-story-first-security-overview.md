# 恢复场景对照并将公告接入总览

状态：采纳。用户反馈：旧安全总览去哪了，公告找不到，现版本不易理解。

此前将直观讲解替换为实验目录和多段研究文字，且公告仅保存为 Markdown。证据更完整，但普通读者需要先理解研究术语，无法迅速看清“批准了什么、脚本实际做了什么、哪里受约束”。

采纳任务与过程图解优先：默认具体场景，工具与系统行为左右对照，结果直接落到文件/进程/数据；完整目录和研究依据作为后续阅读。产品首屏提供独立公告入口，完整正文从维护源生成，避免手工复制产生版本分叉。

保留证据分级、传统沙箱重合、来源仅验证新连接等条件。没有恢复旧示例里的虚构 PID/时序或把示意 trace 当实测。没有删除研究内容来获得“简洁”。

本轮选择静态发布以保留正在运行的 24 小时观察：服务、策略和 Agent 身份均不变，发布事实另记录为 UI 资源变更。受控进程的长期稳定性仍等待原窗口完成。
