# ADR：安全亮点采用具体场景与分层证据

日期：2026-10-09。决策：采纳。

首页公告以具体用户任务和隐藏副作用解释安全价值，每次展示一个场景；六个页签可切换，验证依据进入详情。采用独立 React 组件及局部 CSS，保持现有首页数据与导航行为。

公告只陈述防护目标，不自动生成“已防护”“已拦截”或验收百分比。真实策略、执行域、操作结果仍以原有工作台和审计证据为准。选择可折叠公告而非轮播，避免自动切换干扰阅读，支持左右方向键、Home/End 与原生详情键盘操作。

此决策不改变 AgentScope/ActPlane 权限合同，不对任意路径别名、已有 FD、映射或远端服务效果作全面覆盖保证。当前修改仅限 AgentScope 前端与技术文档。
