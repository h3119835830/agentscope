# ADR：安全亮点采用首次展示对话框与双侧 trace

日期：2026-10-09。决策：采纳，替代原首页常驻六页签公告。

用户已确认 v2 设计：保留首页按钮，首次按公告版本打开、关闭后记忆；用原生 dialog 和 portal 承载公告，支持 Escape、双向焦点循环、关闭后返回入口。无需全局状态或后端接口，存储键只记录是否阅读该版本，不记录任务或敏感数据。CSS 局部命名，模态滚动锁定只匹配本组件。

十二个案例按「执行与数据」「授权与流程」分组，左侧因案例展示工具、应用、上下文或审批事件，右侧展示系统、内核或控制面事件。人物、文件和三步故事帮助理解过程，详细过程折叠。选择点击切换而非自动轮播，避免阅读被中断；案例数据独立模块保留能力边界供维护者复核。

UI 案例不接管真实安全判定。发布门禁示例不等于现有发布集成已实现；工具返回、内核拒绝和控制面暂停分别表达。安全规则、审批与执行合同保持原事实，公告验收不抵消内核问题记录。
