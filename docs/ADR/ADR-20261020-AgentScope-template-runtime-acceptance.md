# ADR：真实运行记录作为模板能力事实，退役入口由服务端收口

状态：采纳。日期：2026-10-20。

采用可重跑的模板 DSL 实测及执行结构哈希清单。UI、手工配置和 Agent 看到同一支持/限制说明；清单不充当当前实例的加载或生效凭据。保留不可变历史模板、配置与快照，不迁移旧默认值。

旧 Git 综合模板与旧检查模板不再接受新增、编辑或重新应用。已有运行规则保持；删除约束的停用申请继续走原审批和应用。采用后端守卫和 UI 只读，避免只隐藏按钮而仍可通过接口恢复旧行为。

不在本次修改 ActPlane 的 argv 前置阻断或原生 DSH；不为实测发现的能力缺口增添补救提示词。用明确的不支持说明、真实 Broker 拒绝检查和历史入口封闭来避免误用。原始 CLI 不能可靠拒绝不支持的 argv block，AgentScope 必须坚持现有 Broker 的 unsupported-clause 校验。
