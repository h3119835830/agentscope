# ADR：持久配置与经确认的系统继承

2026-10-11，采纳并实现。

1. 配置版本与运行版本分离。保存追加版本；取消勾选不撤销旧策略，移除独立确认。
2. 复用既有 DSL 候选/审批/确认链，不建设第二套应用流程。系统范围固定全体受控 Agent。
3. 完整 DSL 文档为应用单元，多规则逐条展示。来源、条件和跨事件依赖不拆断，无法转换的原文不交给简化表单覆盖。
4. 可信启动合同绑定身份，执行域隔离目标；系统与 Agent 文档独立命名空间。原文与加载文本分开。
5. 能力取决于核验过的二进制和内核版本，并查询真实已加载特性。后缀与 contains 长度限制分离，超限拒绝。
6. 使用完整匹配缓冲与有界解析。解析失败保护保持明确；仅内核 procfs 只读 mountinfo 保留沙箱启动兼容。
7. 不承诺跨进程原子切换。关门、重载、核验、恢复分阶段进行；失败暂停，停止目标保持停止。
8. 真实 kill 只使用隔离验收子进程。发布备份应用、DB、引擎及能力清单，恢复升级前运行集合，不自动启用候选。
