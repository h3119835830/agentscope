# ADR：服务端恢复多轮来源，原生能力不足时拒绝扩权

日期：2026-10-20。采纳。

采用父生成记录 ID + 当前依据指纹，恢复可信的读取回执、实际执行路径与冻结候选。
正文仍是不可信项目数据。浏览器不携带“已读取”的授权声明，旧记录缺少绑定不能自动迁移成新事实。
拒绝针对 RQ5 增加提示词、按同名文件猜来源、手工改候选路径来掩盖上下文丢失。

目录写权限使用人工申请 → 审批 → 显式应用原合同，只追加准确子目录候选；
保留现存保护和权限，不把审批接口开放给 Pi。
当前原生单例外/路径长度能力不足则拒绝；拒绝用共同父目录扩权或修改 ActPlane 核心补产品缺口。

代价：历史对话需开始新场景重新读取；策略/文件漂移导致旧上下文不可续用；
当前 RQ5 深层布局仍可能无法形成可应用策略，必须单独处理执行映射后再验收。

界面实测后补齐产品 console 只读路由；允许有界资料说明 summary 作为无授权的响应字段，
使只读分析可以进入真实多轮记录。未知输出字段仍失败；失败只保留公开工作流事实，
不把未校验模型输出当成配置，也不存储推理过程。
