# ADR：任务档案、当前连接与人工权限变化

日期：2026-10-07。状态：采用。

## 决策

以task_id定义唯一档案；同来源路径不合并新任务，恢复/版本作为子事实。来源实例保存创建快照，历史执行绑定来自原收据。采用现有表只读投影和数据库列表分页，避免第二套策略数据与浏览器全量合并。

主阶段摘要与完整时序分开：每阶段独立查询最多20条关键证据，真实装载/结束优先，完整events继续原分页。不从近期50条里再挑重要事件，因为真实任务的大量probe/pause会掩盖更早v3/v4加载。关键数超过上限时返回highlight_total，不能暗示摘要就是全部记录。

restrict和expand统一人工审核；Pi输出与编译成功不产生权限。拒绝/澄清离线可执行；approve核验冻结来源和live绑定，quiesce后再验hash。审核收尾遵守原revision/version/hash/binding，恢复保留未审批意图。

当前可操作性与历史可恢复性分开。failed不进入DB活动fallback，仅本轮Broker connected证据可处理竞争窗口。native offline注册可保留，但不能借native连接推定受管任务在线。

审计action_source与source/storage_source分开；工具、内核、control gate和独立effects不互相替代。没有可靠任务、版本或引用时显示未记录，禁止按PID或路径凑关联。

## 取舍

分页和折叠增加展开操作，但防止工具日志压住主流程。独立关键摘要提高默认可见性，仍有20条上限，完整证据必须继续分页。只读历史无需Broker在线，但无法追补未持久化的数据或证明live有效。

保留既有DSL路径64字节上限。最终回归的长临时目录失败通过短TMPDIR重跑处理，不放宽安全编译器，不归咎Agent能力。精确测试和运行证据集中在REVIEW。

## 历史图决策

为档案提供独立历史接口，复用已存加载收据及root-owned、hash匹配材料，不调用含workbench/Broker的实时topology.graph。不创建第二套策略数据。版本归属与材料可用性分开：前者不匹配404，后者缺失available:false及明确原因。底线无expected bundle_hash不导出DSL，watch只表示控制面监控关联；历史PID永不标live有效。

## 字段记录界面收敛

采纳用户后续字段＋记录表要求：同一档案内部四个页签、关键权限记录与全部记录切换、字段详情按需展开。取消旧纵向阶段锚点作为最终展示方式，保留原数据、分页和证据关联。历史图可折叠，不依赖实时Broker；图线使用短标签，完整关联语义保留在证据与提示中。
