# ADR：全局策略摘要、显式结束操作与独立会话显示元数据

日期：2026-10-14。状态：采纳。依据：RFC-20261014-AgentScope-policy-controls-and-session-names.md。

1. 系统策略使用全局范围摘要，逐实例影响默认折叠；避免每行枚举全部产品/PID及重复范围。保留详情和精确实例导航，范围与实时运行状态仍分别核验。
2. 继续采用候选、批准回执和显式应用三段权威链。停用生成新移除候选；删除未生效配置为软归档。UI 不把停止生成、拒绝候选、停用策略、删除配置和停止 Agent 合并成一个含混“停止”动作。
3. 停止确认带当前 generation/policy_hash，在现有生命周期锁内校验；保留旧空请求兼容性。这样可拒绝旧弹窗停止新一代进程，又不改变现有管理脚本合同。
4. 会话改名采用按精确实例/会话键保存的管理员显示元数据。核对原生 DSH rename 先 resolve/resume 会话，可能启动冷会话，所以不批量调用此原生接口。独立显示字段保留原始标题和来源，可审计、可 CAS 修改；代价是原生界面标题仍可能英文，当前不宣称完整原生汉化。
5. 整合以当前运行版本为基线。初始实验工作树缺少后续 Agent 基线与 approve/apply 功能，已停止直接 overlay，改在 d66605e 新工作树合入；最终验收必须在此整合版本进行，旧基线测试数不计作最终验收。

未新增引擎能力、会话独立执行域或授权捷径；原生工作区/会话独立加载和失效审批恢复入口仍按既有开放问题管理。
