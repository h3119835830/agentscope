# ADR：保留累计源码并同步两个本地发布分支

日期：2026-10-16。状态：采纳用于本次本地交付；远端推送未执行。

1. 选择已发布功能的累计分支 cd32860，保留原有历史；main/WINDOWS 原先相同且为其祖先，验收通过后使用可快进的同一提交，不重写历史。
2. 对旧脏工作树以内容 blob 和目标分支历史核验收录情况，不把未提交状态等同于缺少代码；不 reset、清理或覆盖用户原工作树。
3. 补入独立文档分支的当前架构修订和公开实验依据，保留原日期、研究/提案状态及源码哈希，不将文档设计当作已实现运行能力。较旧功能变体由累计分支的后续实现取代，不重新应用其旧补丁。
4. CI 增加 DSL adapter 编译、历史 /tmp/a fixture、实际身份降权所需的隔离测试身份及前端回归。桥接测试改用系统 tmpdir，避免依赖开发机 /tmp/atf。权限拒绝逻辑保持原合同。
5. 本地分支更新与 push 分开；每次 push 前按用户 AGENTS.md 取得明确允许。运行服务继续使用既有发布目录，提交不自动部署。
