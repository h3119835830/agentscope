# ADR：以作用范围字段统一 Agent 策略入口

日期：2026-10-15。状态：采纳。

## 决策

移除 Agent 长期基线 / 工作区策略的入口切换，以“全部受控 Agent / 指定 Agent”字段组织配置。工作区作为参考资料入口；保护对象通过模板参数表达。前端复用现有系统、实例配置与审批组件，不增加新的授权层或策略存储。

## 原因与取舍

工作区目录是资料与匹配对象，不能仅因目录不同就暗示存在独立执行域。统一入口降低使用成本，同时保留服务端明确的系统与实例作用范围。相同配置对象使用同一个 API，原系统管理入口保留兼容。

不把历史工作区草案自动迁移为实例策略，因为这会扩大作用范围。旧链接仅展示原记录和原审批；用户可以明确新建实例配置。没有删除历史数据，也没有放宽工作区独立应用条件。

全部范围复用现有人工系统配置，不将仅支持实例参数生成的模型接口伪装为全局生成。工作区文件元信息浏览也不等于模型读取正文。正文读取的受限资料合同另行实施。

## 后果与验证

系统范围和指定实例仍有不同服务端合同，页面通过字段和范围列呈现。范围切换不发送变更请求；旧工作区视图没有生成或提交控制；切换实例清除工作区目标。采用静态资产发布，API、Broker、Agent 运行身份与策略保持不变。
