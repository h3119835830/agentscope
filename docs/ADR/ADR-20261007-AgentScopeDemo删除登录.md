# ADR：AgentScope Demo 删除登录流程

日期：2026-10-07。状态：采纳并已部署。

用户明确要求个人 Demo 删除管理员口令和多余过渡设计。废弃一次性票据、8 小时 Cookie 会话、自动连接及 401 续期；不再以自动认证包装原登录流程。

采纳：前端直接进入工作台，复用既有本机 development.passwordless，Scope 控制接口一并放行本机无凭据请求。18003 启动环境删除管理员凭据；启动脚本和验收驱动直接访问普通 URL/API。

取舍：信任本机操作者，减少登录、会话、存储和到期处理。Origin 限制防止其他网页直接跨源调用，但不认证能够构造 HTTP 请求的本机进程。DSH/Pi 绑定任务的凭据、Scope 审批和 ActPlane 执行隔离继续保留；不把去除控制台口令等同于取消任务策略审批。

废弃记录：RFC-20261007-AgentScope本机浏览器自动连接.md、ADR-20261007-AgentScope本机自用自动会话.md 描述历史方案，不能作为当前实现说明。
