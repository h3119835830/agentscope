# ADR：策略语句是档案策略页的主要记录

状态：采纳并实施。

此前以生成作业作为一行，主标题优先显示“保持当前权限”，多条策略语句被隐藏；详情又优先显示完整候选包，用户无法判断哪条语句对应哪段 DSL。

采用逐句展示和逐句详情，保留作业关联与无语句作业占位。原作业接口不删除，新增语句视图使用独立分页合同，避免旧消费者或历史材料丢失。完整包作为可选上下文，不能占用逐句 DSL 的位置。

拒绝通过说明文字的相似度猜测规则归因。复用已登记证据、受信任务路径、权限快照和编译子句；不足以关联时明确未记录。语义内容与文件操作分开表达，不将候选通过编译、历史包已加载或相同目标路径单独当作该语句已强制执行的证明。

取舍：同一作业会展示多条简短语句，数量增加但关系清楚；长语句、规则、公开证据及整包留在详情中。此决策修订之前仅按生成批次展示的界面规则，不复制权威策略数据。
