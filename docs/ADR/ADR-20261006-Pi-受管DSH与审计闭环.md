# ADR：受管原生 DSH 与候选式策略控制

> 界面合同更新：本记录中的七项导航及旧当前权限/混合事件展示为历史版本。现行六项导航、运行前/运行时策略记录与分层审计见 [RFC](../RFC/RFC-20261006-DSH工作区绑定与策略记录.md)，此前安全验收计数保持历史口径。

状态：前版安全验收及本次执行角色隔离专项验收通过。日期：2026-10-06。

1. **Pi 与特权执行分离。** Pi 用七个启动工具/四个受管运行时工具提出候选；控制面验证，Broker 加载。取舍：多一个可信控制环节，换取不可由模型批准、加载或削弱启动底线的边界。
2. **沿用原生网页和每任务实例。** 不复刻聊天界面；独立进程域、工作区、Session 与实例。个人 3000 保持独立。代价是实例资源和域重建时原生连接的重新连接成本；持久 SID 和公开历史保持。
3. **收紧也完整换域。** 先停止域成员，包括工具后台子进程、已有可写 FD 和共享映射，再完整构建/验证。舍弃仅热加规则却保留历史写能力的方案。扩权额外要求当前候选的明确管理员确认。
4. **精确对象集合与独立祖先身份保护。** “保留现有测试”只保护冻结文件集，不覆盖未来缓存；祖先目录自身禁止重命名/替换，避免别名逃逸，又允许相邻合法文件写入。具体规则由来源事实解析，非硬编码 Demo 目录判断。
5. **来源事实不等于用户授权。** 服务端发布真实用户条款绑定的保护目标和写入范围；读回执只解析对象。自动范围有界，不能把普通测试/报告消息推成实现目录整树禁止。未知必要 OS 约束进入待澄清；后续真实消息重新评估。
6. **当前事实优先的上下文投影。** 已核实的快照/版本/哈希/域为当前权限事实。历史 DSH 报告仅是观察版本的自报；未评估请求和待确认意图独立保留。避免旧报告造成重复扩权或丢失候选。
7. **真实内核归因与公开导出。** PID→64 位调用标识继承到 fork 子进程，事件区分实际进程域和匹配规则域。ABI 由 384 改为 392 字节，全组件配套升级。保留后台审计与原生上下文反馈回执，私有推理/原始完整会话不进入控制面文档。
8. **如实限制结论。** 独立 OS 探针是权限 oracle，Agent 自报和未尝试分别统计。本工程扩展不冒充论文 RQ5 成绩。清理任务效果与支付任务测试结果单独报告，权限保护通过不能证明任务修复完成。

废弃：DSH 运行中禁止任何策略更新；backend/frontend 的 Demo 专用生成判断；tests/** 强制全树保护；等价 restrict 反复换域；只看最近 300 条混合事件；仅凭编译/handled/Agent 拒绝文本认定内核保护生效。

保留实际能力边界：单连续写子树、64 字节路径预算、联合 write/unlink 保护、受信 Native CLI/SDK 事件。必要但超出这些能力的约束必须暂停澄清，不能用提示词伪造已执行保护。

9. **消息接收与轮次派发分开。** 接收时基于真实 Native user/rpcId 评估，派发时只补轮次并去重，避免暂停工具等待澄清、澄清等待工具结束的循环。不得用假 user/message 或专用提示词越过暂停。
10. **已加载执行目标持续可见。** 待扩权目标与现行授权目标使用不同合同；历史工具报告不能代替当前加载回执。该快照只向 Pi 和控制面公布；废弃原生模型 scope 查询，旧查询验收作为历史记录。
11. **控制面短暂断连保留执行暂停与请求标识。** 有界重试恢复通信，认证错误不重试，超过预算要求安全恢复；不以清除错误标志丢弃尚未送达的用户约束。原生 9 项单测和实际 15 秒服务中断恢复通过；恢复后的受保护写入仍被内核拒绝。

12. **本地控制与 Oracle 文件使用内核读取边界。** 排除证据注册不足以隔离原生工具；控制源码、本地评测数据与服务 DB/报告/日志加入启动底线。仅固定公开探针程序的受控只读前缀例外，以允许独立同域验收。三个实际读取探针通过；这不等于约束任意公网 HTTP 内容。
13. **启动澄清成为新的真实输入来源。** 保留原始任务，认证补充信息进入 task 权威来源、哈希和新生成作业。旧输入不得复用为新策略，已加载底线不可在此入口改写。现场已验证补充来源读取后才加载；不以模型“应该理解”或场景专用提示词绕过校验。


14. **按已公布的内核匹配和容量建模。** 中间 glob 降为前缀会误阻止公开运行时；逐文件展开又可能超过父子域容量。采用已登记控制目录、公布运行时读取例外和末尾通配。单测、两次完整回归及精确对象读取矩阵通过；不以 Agent 使用 -S 的替代路径掩盖误拦截。

15. **模型执行世界与受信 Native 宿主分离。** 采用最小挂载与独立 PID/net namespace，而不是继续全主机只读挂载。Native 宿主保留模型传输/持久会话，模型工具不能访问宿主秘密；每个文件 syscall 使用同一隔离执行世界，避免仅用提示词或路径检查保护读取。代价是每次文件能力创建隔离进程、流式文本最多 16 MiB，并暂未开放网络任务与交互终端。
16. **OS 策略归 Pi/控制面，DSH 得到操作反馈。** 废弃策略查询/申请工具以及启动、恢复、反馈中的保护集与策略版本；保留平台任务语义和最小运行反馈。完整规则保留后台审计。
17. **观察原生有效上下文，而非让 DSH 自报策略变化。** 增加公开 prompt、instructions、tools、context、compaction memory 的真实事件投影、哈希去重和过期候选校验；私有推理不进入合同。普通变化可以 no_change，观察不构成扩权授权。

18. **公布实际能力，并分开候选与应用阶段。** 任务临时区是现行固定能力；输出等公开扩权目标尚未获准执行时仍可提议待确认候选。缺少确认不是目标不受支持，确认也不能省略。修复合同而不添加某个场景专用提示词。
19. **必需隔离与可选维护服务独立加载。** 官方 compaction-basic 为受管会话提供原生记忆更新；Cordis 子注入隔离可选服务依赖，维护不可用不应让整个沙箱 hook 停止加载。策略替换失败停止域并同步状态，避免页面错误显示仍在应用。
20. **送达依赖实际 Native context。** hook 返回只记 offer，原生 admission 和持久文本哈希才支持送达结论。允许多个同 event context 的不同回执；SDK 检查和真实 Agent 尝试分开计数。恢复只保存未批准意图，旧候选哈希仍无效。
