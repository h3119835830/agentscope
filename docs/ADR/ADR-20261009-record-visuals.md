# 采用共享记录配色与字段表面

日期：2026-10-09。状态：已采纳、已部署至 18003 静态前端。

## 决策

使用独立 `RecordBadge`、明确状态映射和限定页面作用域的样式文件，统一总览之后的记录模块。颜色与完整文字同时保留；不单靠颜色传递状态。当前连接页标签实测文本对比度最低 4.866:1。

绿色表示原有成功/连接/核验标签，蓝色表示信息或加载状态，橙色表示暂停/待确认/未核验，红色表示失败或拒绝，紫色表示历史/入口/版本/行为约定，中性色处理未知值和已结束。禁止根据包含“已”字等模糊规则推断成功。连接历史强制使用紫色并保留历史说明。

采用白色表面、浅蓝表头与较轻的边框，字段名称弱化、值增加底色，避免每个字段都使用高饱和颜色。窄窗口采用紧凑表格间距，手机表格在容器内滚动，保持按钮完整文字。

## 取舍与边界

共享样式可覆盖多个模块，后续新增表格仍需检查宽度和长文本。保留原有状态计算与操作处理，降低 UI 改动对安全控制链的影响。颜色不能作为当前内核保护、进程归属或策略执行的独立证据；本次没有新增内核验收结论。
