# ADR：执行连接、启动入口与安全配置分离

状态：已采纳，已实现并发布。

将启动命令、cwd、网页/PTY 入口归连接；资源授权、系统/Agent 策略及审批归安全配置。DSH 继续负责原生工作区和会话，AgentScope 按实例与原生 workspace ID 读取，不创建第二套工作区来源。保留旧连接启动行为，通过独立配置表逐个显式转换。

命令用 argv 在非特权进程内执行，运行层仍是受信控制边界；不扩展 root Broker 为任意 shell。初版支持已安装 Node/Python 与明确原生适配器，后续程序类型必须补充身份、启动、策略和观察合同。无原生适配器时仅声明 OS 进程管控，不伪造工具/session 覆盖。

终端采用本机 PTY 与代次绑定的类型化 relay，共用已有控制 API 身份检查；不用脱离受控域的系统终端进程。命令配置进入审批身份快照，策略改变按整个域撤销；文件夹清单在 Agent 的目录权限内读取，使用 FD 锚定和 O_NOFOLLOW 避免路径检查与使用之间的替换。
