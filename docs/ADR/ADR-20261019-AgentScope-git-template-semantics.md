# ADR：按 Git 动作和执行语义发布模板，缺失能力禁止应用（2026-10-19）

决策：采用独立 commit / push 及各自的检查事件模板；资源差异使用参数。保留旧版本，不将旧审批改为新语义。用服务端声明并校验执行能力，未实现的 Git 语义只保存参数草案且不生成 DSL。

理由：旧 Git 模板参数为空且混合 reset/clean/stash/--no-verify；普通 exec token 事件不能证明目标分支、暂存区、测试结果与提交版本一致。前端新增远端/分支输入后若仍生成普通 exec 规则，会形成虚假的保护声明。

取舍：本次不引入 Git 包装器、DSH hook、托管平台连接器、SHA 级测试回执或一次性推送授权服务。有限能力保留 notify/kill，并清晰告知执行后匹配边界；复杂需求可以保存以供查看，执行前必须由后续实现提供完整合同。

禁止：用网络 IP 当远端仓库身份、用打开/禁止读取文件代替提交内容扫描、用运行过 pytest 代替指定代码测试成功、用策略配置审批代替某次 push 的行为授权、用共享会话事件伪造独立会话结果。

兼容性：27 个既有模板的 v1/v2 共 54 个定义哈希与修改前一致，既有子配置、审批和运行策略不迁移。模板编辑仅新增版本。
