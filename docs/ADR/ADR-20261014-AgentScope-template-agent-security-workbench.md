# ADR：同一个模板配置 Agent 服务运行前与运行时安全配置

日期：2026-10-14。状态：设计决定与示例预览；实现和真实运行验收待后续。

1. 策略生成 Agent 定位为配置助手：检索已发布模板、填写允许参数、通过受限 API 保存配置候选。手工表单和助手使用同一服务与记录；不通过 computer use，也不开放自由 DSL/任意代码或执行面权限。
2. 固定基线仍为系统/Agent；运行时目标为真实共享域，工作区/会话为来源与查看入口。同一个 Agent 采用分阶段上下文，不复制两套审批/策略库。
3. 静态模板版本与独立配置子记录分开。子记录是目录组织，不是策略域；新增不覆盖，编辑产生新版本，助手无发布/修改模板语义权。
4. 现有统一审批保持“批准后显式应用”，无加载/批准工具交给模型。后端身份、Schema、语义、资源和实际能力强制校验；提示词不是安全边界。
5. 会话安全面板是共同读模型，展示 DSL 和通用约束，区分当前保护、候选、指导与未知；勾选/文字输入只形成草案。能力不足明确阻塞，不能从 UI 开关推导已撤销。
6. 运行前无会话也可起草基线；运行时增量以真实域范围确认。已有高级 DSL 与历史候选保留原语义，不静默转换。
7. 写入/删除别名按真实变更组处理：精确请求不支持时阻塞；用户接受更广范围后形成新候选。多条子记录不增加底层粒度。

本决定具体化[共享基线架构](../RFC/RFC-20261014-AgentScope-agent-baseline-runtime-policy.md)中的生成模块，不采纳另一对话旧工作区/会话固定层目标；不批准未实施热更新引擎或修改 DSH。

架构、模块功能矩阵、两条用户路径和验收条件见[本轮 RFC](../RFC/RFC-20261014-AgentScope-template-agent-security-workbench.md)。[REVIEW](../REVIEW/REVIEW-20261014-AgentScope-template-agent-security-workbench.md)记录设计检查，开放项见[BUG](../BUG/BUG-20261014-AgentScope-template-agent-security-workbench.md)。
