# 决策：行内操作复用统一审批链路（2026-10-16）

将高频提交、查看审批及停用入口放在记录行，详情保留；操作两列排列，窄屏仅记录区域横向滚动，不隐藏字段。不新增直接启停开关或应用按钮。

采用只读的 configuration_approvals 关联投影，旧系统库和新模板配置共用准确配置 ID / 作用范围 / 版本查询。当前版本优先，历史审批可打开但不代表当前草案已批准。拒绝按名称搜索审批、浏览器本地保存“已审批”或从 UI 猜测停用完成。

停用继续复用统一候选接口和既有独立审批 / 应用机制。未应用的新版本与已应用旧版本不混淆，核对实际应用参数，服务端仍校验提交的当前版本及策略基线。
