# ADR：策略语句是记录单位，完整包留在后台

日期：2026-10-06。状态：采纳。

1. 以策略语句而非 Pi 作业作为前台记录单位。同一作业内 OS 规则和语义指导必须分开。
2. 通过真实编译器子句关联目标，不在单条记录里展示完整 source_text 或 compiled_dsl。整包仍用于加载、权限合同及哈希验真。
3. 无可靠映射时显式缺失，不从全包挑选看似相关的其他规则；语义指导不得展示 OS DSL 或加载状态。
4. 分页游标包含语句索引，防止一个作业内 20 条语句被 12 条分页丢弃。
5. 保留显式锁定与现行认证合同，恢复本机浏览会话；把图标动作改为清晰文字并记录锁定审计。未取消锁定或延长权限期限。

取舍：历史无逐句注释数据只能使用已认证的条款/请求关联并标明来源；无法映射的历史语句不展示 DSL。展示片段保留原子句文本，包装规则头及编译原因，单独计算片段哈希。

此次修改限 AgentScope 记录投影、页面和锁定审计，不涉及 Pi 任务权限逻辑、ActPlane 引擎或普通业务。
