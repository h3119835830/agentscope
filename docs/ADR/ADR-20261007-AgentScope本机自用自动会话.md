# ADR：本机自用采用自动浏览器会话

> 状态：已废弃。2026-10-07 用户要求直接删除登录流程，当前实现见 ADR-20261007-AgentScopeDemo删除登录.md。以下为历史方案及当时验收，不代表当前代码。

日期：2026-10-07。决定：接受。用户明确要求本机自用免管理员口令。

采用显式 opt-in、同源 loopback 浏览器自动建立和过期续接会话。保留 Cookie 与控制 API 的身份校验，不启用通用开发匿名 API，不把管理员口令写进静态前端或浏览器存储。

一次性启动票据继续兼容，但不再是 18003 日常进入的前置条件。其余部署默认仍须正常认证。自用模式以本机用户及本机程序可信为前提，不声称请求头能够识别恶意本机进程。

执行 Agent 的任务凭据不会变成控制凭据；其沙箱、网络隔离、ActPlane 规则及扩权确认保持原合同。只变更本机用户的页面连接体验。
