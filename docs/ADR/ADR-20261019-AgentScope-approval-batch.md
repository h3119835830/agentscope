# 批量操作复用单条审批合同

状态：采纳。

采用界面批量协调，先读取并冻结所选内容与范围，一次确认后顺序调用既有单条接口。没有增加服务端批量授权、批量回滚或跨策略域事务。

保留逐项幂等、精确候选/目标/批准回执核对，以及先批准、后显式应用。提交后逐项读取权威状态，网络失败不能显示为已应用。部分失败保留结果，不自动重试加载、重新批准或用新基线代替用户批准的内容。

同一范围原本只有一个待应用批准槽位。批量选择冲突时全部提示跳过，避免隐式优先选择列表第一项。合并多份候选并形成新授权不在本次范围内，需由用户回到配置中明确整理并重新提交。

需要处理采用明确分类及按能力恢复。支持重新校验的记录生成新候选，其他记录保留返回配置入口。旧历史继续保留，不能把重新校验等同于旧记录变为已应用。

代价是批量执行可能部分成功，用户需要根据逐项结果继续处理；收益是无需改变已经验证的服务端执行与安全边界。
