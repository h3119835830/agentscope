# ADR DSL 规则复用与安全边界

日期：2026-10-07。状态：已采纳，实施中，发布门未通过。

相关：[RFC](../RFC/RFC-20261007-DSL规则归一化与重叠校验.md)、[REVIEW](../REVIEW/REVIEW-20261007-DSL规则归一化与重叠校验.md)、[BUG](../BUG/BUG-20261007-DSL规则归一化与重叠校验.md)。

## 决策

1. 使用服务端确定性规则分析，Pi 继续只提交候选；自然语言相似度不能证明执行规则等价。
2. 保留全部策略语句和证据，多条语句可引用一条逻辑规则。执行身份与来源身份分开，审计能逆向找到全部来源。
3. 首版仅去除同权限分区、同生命周期、同标签绑定、无门控和转换副作用的简单文件阻断重复条款。其他条款报告关系并保留。
4. 路径包含先展示覆盖关系，不据此删除规则；不采用最新规则覆盖，也不按 kill、block、notify 的强弱替代其他规则。
5. 启动底线独立封存。运行时重述可以引用它，不能迁移底线身份或取得其撤销权。
6. 无执行变化不产生新加载版本；权限扩张继续走确认、新包和新域。加载前重新检查证据、版本和进程域。
7. 先只分析，再启用简单等价复用。旧数据标记未分析，迁移不重写历史候选和加载回执。

## 取舍

保守复用留下部分范围冗余，但避免复杂 glob、时间门、不同撤销权和反馈原因被错误消除。重复来源保留使存储不会按执行条款数同步减少，换取完整溯源与可解释的反馈。

分析器接在现有服务端构建链，便于启动和运行时共用；它不能取代内核权限检查。即使分析器有错误，继承底线也必须保留，失败的候选不能放行任务。

## 废弃方案

不使用 DSL 文本哈希直接决定权限等价，不让 Pi 自报“已经去重”成为加载依据，不以同路径为合并条件，不以去重名义删除父域规则，不在页面展示层去重后宣称执行策略已经优化。

## 实施补充（2026-10-07）

保留部署门：observe 与 deduplicate 分离。无语义元数据的历史记录返回 legacy_unanalysed，不推断已去重。候选身份排除临时编译文件名；同一策略的多次校验必须保持身份稳定。加载实例另带 load_version，避免恢复后复用同一分析报告造成回执版本丢失。

审计分别保存父域底线与子域规范包的包哈希、条款 ID；命中父域时验证父域编译条款哈希，不把父域数字编号当成子域编号。启动失败清理其独立进程与 BPF pins，不能留下无人持有的引擎。

## 实施补充决策

1. 编译结果临时文件 policy_ref 不参与候选身份；完整条件、标签绑定、实际匹配方式及引擎二进制哈希仍参与校验。
2. 生成器业务可行性判断与安全策略准入分离。公开任务风险可留在 guidance，不因业务失败预测放松保护；必要 OS 安全缺口继续 fail closed。空已审策略库是终止检索状态，不提示模型无意义地换查询。
3. 测试探针自身不得改写任务内容，不通过给 DSH 读取控制面脚本来运行探针。使用固定受信 relay + stdin，同域低权限操作保持不变。
4. 实时进程取证读取 Broker status，不能从首次加载回执推断当前执行 PID。重复约束核对 runner/executor PID、两者启动时间、域、版本、加载次数和包哈希。

以上决策已实现并通过后端回归；最终真实六会话复测尚未完成，保留 observe 默认值。

## 受管 relay 启动握手（实施补充）

采纳 root-only 一次性启动握手，确保精确 PID 登记完成后才读取受保护 relay 代码。拒绝让整个 root 用户、DSH 或后代继承读取例外。握手验证文件 owner、mode、no-follow 与本次 nonce，超时关闭；策略加载和 DSH 放行核验仍独立执行。该决策修复实际启动竞态，不改变 DSL 求值语义或底线。

## 线程生命周期与独立清退决策

采纳TGID作为进程策略身份，线程共享进程状态，不为短线程长期保存独立域条目。已复现旧TID条目耗尽map后子进程漏绑定及文件漏拦截。为新受管任务建立root-owned cgroup，root relay在一次性握手释放前加入；全部后代继承，DSH沙箱不可读写cgroup控制。

清退不再只依赖域表。先冻结/终止任务cgroup并核验空组，再核查内核域成员；cgroup路径、owner及inode绑定回执。固定探针在目标操作前独立读取真实域映射和进程组归属，缺失即拒绝。旧任务不自动重启或迁移。
