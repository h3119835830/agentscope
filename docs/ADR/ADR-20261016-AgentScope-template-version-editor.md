# 决策：模板编辑追加版本，详情与展开分别负责（2026-10-16）

用户确认“详情”用于改模板，并选择编辑配置项定义和默认动作。撤销详情充当展开按钮的行为；箭头独立展开子配置，模板主表不再将可变触发操作显示为固定值。

采用追加不可变模板版本，拒绝原地改写执行定义、批量迁移旧子配置或使原审批静默换模板。新版本只影响以后起草，已有子配置与审批按原 template_version / template_hash 验证。编辑范围为现有字段标签、默认值、名称、说明和动作；参数键、类型及 renderer 不变，避免保存执行器无法解释的结构。暂不支持新增 / 删除 / 改参数类型，在 UI 明确标注。

持久化使用同一服务数据库和原管理员权限，事务 CAS 防止覆盖并发修改，请求键提供幂等。目录读取失败不退回静态旧模板。编辑默认动作接入实际渲染器，避免出现列表动作已变而 DSL 仍使用硬编码旧动作。新增版本不构成策略批准、应用或内核生效。

## 2026-10-16 去除额外汇总列

按用户明确要求移除主表“配置项”汇总列，模板参数定义只在详情编辑，避免主列表重复展示；这是展示收口，不改变执行定义或审批边界。
