# 决策：连接布局与打开恢复分开交付

- 采纳：在 main 小步提交；布局选择器只覆盖 `#instance-pane-connection`。
- 采纳：布局发布只切换 CSS 引用，不复制当前构建中的 JavaScript，避免把尚未授权一起发布的加载页签改动带入 18003。
- 采纳：预览复用当前生产 JavaScript，代理只允许 GET；禁止配置、启动、停止及策略写入。
- 采纳：未知运行状态仍可提供检查入口，但不得借此自动恢复或重启。用户已同意下一步单独修复这一交互。
- 不采纳：把缺失观察视为未运行、把 gate 或历史回执当当前事实、直接合并旧分支。
- 不变：保存、审批、应用分离；ActPlane 原生路径、标签语义、会话关联保持现状。
