# 决策：连接布局与打开恢复分开交付

- 采纳：在 main 小步提交；布局选择器只覆盖 `#instance-pane-connection`。
- 采纳：布局发布只切换 CSS 引用，不复制当前构建中的 JavaScript，避免把尚未授权一起发布的加载页签改动带入 18003。
- 采纳：预览复用当前生产 JavaScript，代理只允许 GET；禁止配置、启动、停止及策略写入。
- 采纳：未知运行状态仍可提供检查入口，但不得借此自动恢复或重启。用户已同意下一步单独修复这一交互。
- 不采纳：把缺失观察视为未运行、把 gate 或历史回执当当前事实、直接合并旧分支。
- 不变：保存、审批、应用分离；ActPlane 原生路径、标签语义、会话关联保持现状。
- 第二步发布：从线上 `b37b4fd` 的前端源码生成临时构建包，覆盖精确六个连接源文件（其中一个为已发布 CSS）。临时目录不是 Git 分支；所有源文件逐个与基线或已提交的 allowlist 校验。保留其他 main 改动未发布，保留并行工作区修改未提交。只切换 main JS，CSS 与终端资源不变。
- 并行发布后不放宽基线检查：先重建并证明当前线上 JS 来源，再保留已发布总览说明入口的固定内容哈希。此次只在更新后的线上基线叠加连接改动；不覆盖并行发布，也不把未审查的工作区内容作为发布输入。
- 第三步采纳列表专用名称与 PID 展示函数，不修改全站 agentName 或保存的连接名称。多条同产品记录保留独立操作；未核验 PID 不展示，停止后的同名连接可在配置详情区分，不能按名称合并。
- 第三步发布以已上线 JS `main-BlhRh--D.js` 为基准，先从已提交源码独立重建并比对完整 SHA-256；只允许 `AgentInstances.jsx`、`agentInstancePresentation.mjs` 两个生产源文件改变，其他已发布连接文件固定为 `0584530` 内容。不使用 main 全量构建上线，不携带 `0d526d2`。
