# ADR：预览不得用空列表冒充未采集数据

日期：2026-10-26。状态：采纳；隔离验收通过。

根因是独立预览仅接入助手记录，却将全部未覆盖的 API 返回空 records，使真实已应用快照与空审批页矛盾。决定补齐真实审批只读快照，未知接口明确报未提供，不改生产审批流程，也不通过把已应用改成草案来掩盖缺失。

审批关联按配置 ID、版本、所属目标和回执核验，名称不作身份。同一名称的其他草案不能代替已经应用的那一版；完成记录位于“已处理”，不应出现在默认待审批列表。只读预览降低写能力，不修改其历史状态。

本次来源为正式服务 GET 返回的三条记录及详情，捕获之后为固定快照。生产记录仍存在只证明本次关联完整，不代表新执行或当前内核已生效。不会重新审批、重新应用、恢复或删除任何记录。
