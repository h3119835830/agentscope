# ADR：复用受保护 DSL 流程承接模板候选

日期：2026-10-10；状态：已采纳。

1. 原型只作为界面与模板依据，迁移为真实 React 组件，不合并整份 HTML 演示数据。
2. 保留原 workbench/strategies URL，增加 agent/system 别名及 policyAgent、agentPolicyTab、systemTab，旧生成记录深链继续可达。候选 DSL 不放 URL。
3. Agent 产品用于展示，精确连接 ID 用于权限与导入。模板候选只能指向一个受控实例。不会按产品名推断多个连接共用策略。
4. 采用现有 DSL proposals 持久化和校验，保留既有确认接口及其 CAS/冻结目标校验。起草、编译与应用是独立动作，页面挂载和模板跳转不发确认请求。
5. 模板采用版本化前端目录，第一批无需新增 API、数据库迁移或服务重启。研究原文折叠展示，日常列表以语句、动作、类型和状态为主。
6. 策略助手采用独立会话框，连接现有真实候选生成服务；模板目录只在系统的记录表展示。助手仅产出候选，不能审核、确认或调用 Broker，不宣称是 DSH/Hermes 原生聊天。
7. 保留 compile、approved、loaded、active 的事实边界。第一批测试通过只证明页面/读取/候选校验闭环，不证明新策略的内核执行。

代价：未保存编辑内容刷新即丢失；已保存草案须重新校验再应用。历史生成/审核沿用现有页面，助手产物若有 DSL 可带入精确 Agent 的编辑器；现有生成服务对执行环境的要求继续保留。Agent 层通用环境适配尚未完成，不用浏览器传入路径冒充服务端核验。

## 本次修订决策

- 采纳“记录中展示字段，详情展示配置”，废弃首版模板卡片与右侧常驻表单。详情使用分区、匹配条件行、反馈区域、DSL 预览和固定操作栏。
- 系统基础配置与 RQ1 Agent 模板分开声明 scope_type。共享候选编辑器，但追加前检查候选类型、目标 ID、当前 scope_id；跨层候选被拒绝。
- Agent 身份是路由和适用范围信息，不是自然语言策略中的未绑定执行参数。历史生成服务保留自己的任务环境核验条件；没有环境时显示待配置，而不是移除验证。
- 会话指针暂存于当前浏览器标签，生成记录服务端持久化。跨浏览器聊天记录同步、真正的流式 Agent 推理与 Agent 环境适配不在此次 UI 修订范围。
