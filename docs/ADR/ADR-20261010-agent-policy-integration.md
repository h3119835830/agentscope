# ADR：复用受保护 DSL 流程承接模板候选

日期：2026-10-10；状态：已采纳。

1. 原型只作为界面与模板依据，迁移为真实 React 组件，不合并整份 HTML 演示数据。
2. 保留原 workbench/strategies URL，增加 agent/system 别名及 policyAgent、agentPolicyTab、systemTab，旧生成记录深链继续可达。候选 DSL 不放 URL。
3. Agent 产品用于展示，精确连接 ID 用于权限与导入。模板候选只能指向一个受控实例。不会按产品名推断多个连接共用策略。
4. 采用现有 DSL proposals 持久化和校验，保留既有确认接口及其 CAS/冻结目标校验。起草、编译与应用是独立动作，页面挂载和模板跳转不发确认请求。
5. 模板采用版本化前端目录，第一批无需新增 API、数据库迁移或服务重启。研究原文折叠展示，日常列表以语句、动作、类型和状态为主。
6. 当前策略助手提供模板起草，不模拟模型对话或宣称已接入真实 Agent 生成。后续助手只能产出候选，不能确认或调用 Broker。
7. 保留 compile、approved、loaded、active 的事实边界。第一批测试通过只证明页面/读取/候选校验闭环，不证明新策略的内核执行。

代价：未保存编辑内容刷新即丢失；已保存草案须重新校验再应用。历史生成/审核沿用现有页面，尚未新增将其结果导入指定 Agent 的按钮。后续引入模型前需要单独评审上下文、来源追踪和候选边界。
