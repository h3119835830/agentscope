# ADR：复用纯展示组件，先固定可执行路径再生成策略

状态：采纳。

用户要求恢复原界面的记录展示方式，不能只保留栏目名称另做表格。抽取原 ManagedWorkbench / RuntimeOverview 的纯展示组件供当前与历史共用，保持两个入口的读取和执行职责隔离。历史默认真实语句，生成批次另折叠，不补造未记录的模型输出。

64 字节是执行引擎 ABI，不能通过放宽前端/服务端校验解决。采用任务创建前、来源字节不变且有证据映射的独立项目根别名；已固定失败任务保留，新建同源任务验证。拒绝重命名内部包/叶文件、用更宽目录规则掩盖精确目标超限，以及改写旧上下文。

通用项目搬根不能保证所有跨项目外部相对引用等价。父项目构建 marker 明确存在时不搬嵌套包；不可表示的路径如实报告。此次同源任务验收覆盖策略生成和编译，不能据此宣称执行所有来源工程都语义等价。

修复工作流状态、能力合同和诊断传播，不增加专门针对这条任务的提示词，不降低服务器验证、不自动批准。
