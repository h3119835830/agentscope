# ADR：分开展示 Hook 当前定义和历史实际触发

状态：采纳，实现验收中，2026-10-08。

旧工作台直接返回当前 `HOOKS` 定义并通过“触发方式”展示。新历史档案采用独立投影时漏掉了该入口，但逐作业触发信息仍有保存。

恢复时保留两个独立来源：当前机制定义用于解释接入点和处理链；历史作业与请求证据用于说明该任务实际记录到的触发。当前定义不能被标成旧任务冻结配置，也不能证明每种接入点都曾触发。

采用独立纯读取接口，避免为展示机制而调用旧受管工作台或实时连接检查。以保存的作业身份组织记录并关联请求，避免逐语句列表把同次触发重复计算；同请求的不同评估作业仍分别保留。缺失材料显式保留，避免通过默认 actor 或当前 state 推断来源。

前端恢复明确入口及可读字段，不重新推导策略，不暴露原始提示词、凭证或模型私有推理。
