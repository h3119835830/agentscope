# ADR：以绑定场景证据扩展策略助手

日期：2026-10-11。决定：采纳。

复用已有受控文件读取实现，新增独立 agent_policy_scene 历史作业及不可变证据记录。未复用旧任务草稿结果为策略建议，避免把任务创建、场景观察和策略批准混成一个对象；也不复制文件浏览器或新增工作区管理界面。

场景分析使用现有无工具 JSON 模型提供方。没有项目执行工具、Broker 令牌、加载接口或自我批准能力。建议经用户采用后作为策略需求进入现有生成与审批链，而非直接将模型输出变成 DSL 或有效权限。

采用场景引用而非将全部文件拼进长期对话：证据可复核、同 Agent 不同会话隔离、上下文不无限膨胀。重新读取产生新场景标识，后续对话只携带同一场景的此前需求，避免旧场景要求污染新请求。初始记录恢复不得覆盖新发起的读取，状态轮询串行，切换目标后忽略旧响应。

取舍：读取白名单和容量限制可能要求用户缩小项目或补充任务说明；不退回宽泛工作区授权。文件变化使未应用候选失效，但已经应用的原文档沿用既有生命周期，不因文件日常变化自动修改或撤销权限。语义正确性仍需人工审阅和独立执行验收，不能由引用定位或编译代替。
