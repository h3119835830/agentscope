# ADR-20261011 策略来源使用实际进程执行事实

状态：采纳。补充 ADR-20261011-agent-policy-environment。

1. 统一使用服务端实际执行程序事实，不按 DSH/Hermes 产品名称映射 Node/Python。产品名只用于界面展示；入口脚本仍作为启动 entry 留存，不能替代 /proc/PID/exe。代价是离线连接不能自动形成完整来源，界面须明确等待核验。
2. 保留 API 独立账号隔离。采用窄范围只读 observer 提供短时、root 所有的最小快照；不授予 API 读取任意进程的能力，也不为了这项读取重启持有 Agent 内存状态的 Broker。代价是增加一个只读服务和八秒新鲜度管理；停止/异常时失败关闭。
3. 快照不作为任意 PID 查询代理。仅采样数据库已登记、受控、gate=open、verified 且 generation/boot 相符的运行身份；API 再核对全部身份元组。即使权限导致直接读取失败，也不能使用其他 Agent、旧代次或过期事实。
4. 新草案直接采用核验来源，旧文档通过显式按钮更新本地草案。不能静默重写已保存或已应用策略。该按钮不保存、不生成 proposal、不应用；确认路径仍由用户操作。
5. source 是程序条件，Broker 进程域才承载实例隔离。不承诺 **/node 唯一对应一个 DSH，也不把同解释器的程序匹配当作跨实例授权。既有受影响连接预览、CAS、生成绑定与应用重核验保持有效。
6. 不改 Agent 提示词来掩盖控制面环境缺失，不依靠模型猜测执行器。修正上下文供给与来源读取。既有候选 hash 失配显式要求重新生成/核验，保留历史事实。

2026-10-11 复核：保留程序条件与实例进程域两项独立约束，不把完整 executable 路径当作实例隔离补丁。当前域及其子域继承本地策略，兄弟/独立连接不继承；系统策略仍按系统范围分发。依据实际 BPF 域判定与只读绑定验收，见 REVIEW-20261011-agent-node-isolation。
