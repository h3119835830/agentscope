# 用可恢复的可见性标记实现清理

状态：采纳。

用户要求一键及多选清理审批记录。审批记录同时是授权与执行证据，因此清理采用持久化列表收起，不删除候选、批准回执、应用记录、配置版本或审计。恢复入口作为清理的配套能力，用户可自行撤销。

复用已有列表保留表，新增独立审批种类，保留字段中的结构化标记仅包含指纹、版本、状态和请求信息。审批原文与敏感参数不复制到标记或审计。恢复后保留可见性版本，避免旧页面或网络重试重新收起刚恢复的记录。

状态限制由服务端决定，并复用审批生命周期锁。清理标记绑定具体内容与状态；新状态不能被旧标记吞掉。批量协调沿用逐条接口，独立处理失败，不引入批量批准、撤回或停用副作用。

代价是清理后的原始证据仍占用存储空间，列表清理不等于数据销毁。物理清除审计和处理未完成授权不在本次范围内。
