# ADR：工作区记录复用 Agent 连接入口

状态：采纳。

用户要求按工作区理解安全配置，取消重复标题、V1/V2 和胶囊标签，采用字段与记录形式。决定在现有 Agent 连接入口内统一实例记录，并在工作区行打开关联、策略与文件详情，不新增独立安全模块。

关联使用原生工作区注册信息与保存的任务 workspace_id；不通过相同名称、目录前缀或共享 PID 自动推断。选择这一方式可以复用现有可信来源，并避免把任务执行副本误归为原生会话。

本轮策略区使用只读档案接口，因此仅展示保存的语句、处理结果和加载回执。它不承担当前生效判定或可视化授权。新建任务和完整任务记录继续使用现有流程。代价是原生会话未提供的标题、活动状态和权限无法直接填充；界面据实说明缺失信息。

允许把已验证禁止型 atom 渲染为包含操作和精确对象的一句中文；保留原始说明。放弃根据任意 restrict 决策生成禁止语句，因为缩小允许列表也属于收紧，直接改写会改变策略含义。
