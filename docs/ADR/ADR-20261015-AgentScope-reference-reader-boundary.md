# ADR：使用固定受限读取进程提供模板生成资料

日期：2026-10-15。状态：采纳。

2026-10-20 补充：固定读取身份、路径和策略边界保持；正式 API 为非 root，
原文关于 root API 的假设不适用。启动器预建低权限私有读取通道，
不改变 API 身份，见 ADR-20261020-Pi-reader-inherited-channel.md。

## 决策

以服务端登记的实例资源目录作为参考工作区目录，通过固定 UID/GID、fd 锚定、限额读取程序读取显式选择的正文，并把版本化资料回执接入现有模板参数生成与人工审批链路。读取进程与既有 Agent 执行进程隔离。

## 取舍

不在运行中的 DSH 适配器热加正文操作，避免重启或改变用户当前 Agent；也不让 root API 直接按浏览器传入的绝对路径读取正文。资源目录属于已登记的实例，不根据当前页面、产品名、历史 PID 或会话猜测归属。

不为资料读取模拟实时内核标签和完整业务执行语义。真实 AST 解析出所有潜在拒绝读取子句，条件和例外不放松参考读取；未知状态拒绝。代价是部分实际上可读的文件也可能不能作为参考，收益是不会利用 API 的特权绕过已有拒绝约束。此限制不修改 Agent 原有策略。

工作区资料是上下文，不是新的权限层或自动审批依据。模型只选择已发布模板和参数；来源回执不改变 Agent 作用范围，也不能向模板目录注册新能力。生成或保存成功不代表策略已应用。

审批列表只核验元信息，最终提交/应用重读内容，避免后台轮询造成重复扫描。旧资料失效阻止继续新增或应用；明确停用允许移除已经应用的子配置，保持撤销链路可用。

## 验证依据

隔离 HTTP 与真实模型验收由中文项目说明得到 /w/0/internal/staff.csv，并选择现有 FILE-READ 模板，未启动 Agent 或应用策略。真实降权进程拒绝 root 可读而指定 UID 不可读的合成文件。攻击与漂移测试、审批/加载回归和前端交互测试见本次 REVIEW。
