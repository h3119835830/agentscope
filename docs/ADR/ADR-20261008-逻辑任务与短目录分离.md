# ADR：逻辑任务与真实短目录分离

日期：2026-10-08。状态：实施中、待真实 Pi/DSH 验收；本决策不表示权限已经加载或完成本轮真实执行。

## 决策

完整 16 位 task_id 继续标识任务、凭据、候选、策略与执行域。执行目录的物理名称独立分配，不能通过截短 task_id 推导任务身份。

常规目录能够满足预算时保持兼容。出现超长资产时，在既有管理根下分配两字符 base62 真实目录，项目外层根使用单字母别名；package、tests、内部相对文件名与来源字节保持不变。源目录不移动、不回写。映射在新上下文中冻结，Pi 与 DSH 共用；不修改原始任务文本。

不采用 symlink/bind 路径别名、执行器静默截断、扩大父目录保护、重写项目内部名称或调整测试来绕过限制。ActPlane 的 64 字节缓冲区包含 NUL，共享合同按实际可表示的 63 UTF-8 字节拒绝超长目标，执行引擎 ABI 保持不变。

## 永久分配与安全合同

两字符 base62 共 3844 槽，容量显式有限。SQLite reservation 独立事务先提交，再排他创建目录及发布任务。既有对象、历史引用、复制失败、任务事务回滚或丢失目录都不释放槽；保留永久占位和失败 tombstone。目录不可用不能触发同路径重建或另一个任务接管。

存储身份包含完整 task_id、canonical 根、workspace/output 配对、设备号及 inode，并纳入上下文 hash；当前加载前重新核验。短别名不是秘密或身份凭据，访问控制继续依赖既有认证、任务关联、可信加载及实际执行域。

任务结束保留目录与占位，撤销进程域、凭据及临时授权。本轮不增加自动清理或槽位复用；容量和失败占位成本明确接受。无法在不改变项目内部结构的情况下满足预算时，仍保留执行快照与全部资产；仅将对应不可表示的执行目标报告为 unresolved，阻止其直接准入，不自动变更语义或硬拒绝创建快照。

## 恢复、来源与审核

失败任务的上下文和候选保持不可变，通过既有恢复接口建立新关联任务及独立快照。新任务保留同源 manifest、原任务目标、全部已接受约束、平台底线和来源实例身份；重复恢复请求复用关联 child。旧失败结果不改成成功，新候选不写回旧记录。

completed 生成作业若绑定真实 needs_clarification 候选且尚未授权、加载或建立执行绑定，可进入同一恢复流程。必须核验候选正文与摘要、task/job/context 及未解决缺口；不能把任意 completed 作业视为可恢复失败。

来源的原生 DSH 没有打开会话时可以记录空 SID，来源身份仍由实例、代次及原生 workspace 约束；受管 DSH 的实际绑定 SID 继续单独核验。二者不共用或继承执行凭据。

资产证明的 `/workspace/<project>` 别名与实际目录写入新冻结上下文，最长匹配，原任务文本不改。来源仍为本轮登记的 20 个项目资产；oracle、评测器、预期答案和私有推理继续排除。

新 Pi 候选必须重新生成和校验，再人工确认；确认、加载和实际生效证据分别保存。变更目录位置不自动批准规则，也不解决候选适用条件或任务业务正确性问题。

## 取舍与验收状态

独立分配增加少量永久元数据与有限槽位占用，换取原件、内部布局和历史证据稳定；不引入执行引擎 ABI 改动。两字符路径需要大小写精确保留，不能由前端名称或外部用户参数直接指定。

待验收：并发/耗尽/失败占位、目录丢失及替换、跨任务关联、常规兼容、63/64 字节边界、原件完整性、恢复幂等，以及新 Pi→人工确认→DSH→内核探针→结束撤权全链路。当前没有本轮新 DSH/kernel 已完成证据。

实施合同见 [RFC：执行快照短路径](../RFC/RFC-20261008-执行快照短路径.md)。本决策补充 [启动失败恢复 ADR](ADR-20261008-startup-recovery.md) 的路径预算与 completed/needs_clarification 处理；原失败证据、恢复关联和人工确认边界继续有效。
