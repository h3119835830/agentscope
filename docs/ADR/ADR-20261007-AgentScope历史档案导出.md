# ADR：以完整公开任务档案发布历史

日期：2026-10-07。状态：采纳。

用户要求同一任务的策略、权限与执行结果在一条历史中查看，并在英文新分支发布。

采用静态 JSON、一任务一文件，复用统一档案投影和历史域读取合同，另附索引、来源 hash、清单和验收。原始 SQLite 只用于本机一致性读取；原生私有会话、凭据和未审查原文排除。

这样能在 GitHub 追溯完整公开过程，保留各类证据的不同含义。取舍是不能恢复原生私有会话、凭据、原始文件正文或已经缺失的可信加载材料；静态状态不代表在线状态。

历史分支从公开 main 建立，读取实现的实际源码 hash 单独记录，不夹带并行代码。其他实现分支遵守各自的推送授权。
