# ADR：命令作为不可变模板事实，预览与执行共用渲染（2026-10-20）

采用：固定 Git 命令和服务端 DSL 骨架；只暴露变量参数。新增版本追加到当前版本之后，兼容自定义历史版本；不覆盖已有定义。新建和助手禁止选择旧 Git 合同来绕过固定字段。

原因：仅将输入框禁用仍能通过接口改变 program；另写前端示例 DSL 会与保存/编译规则漂移。共享实际渲染函数可由预览与保存结果逐字对比验证。

取舍：预览不调用实际加载或审批、不赋予执行权；DSL 源结构只读，未引入任意模板脚本或新 DSL 编辑授权。缺少参数显示未绑定位置，未支持能力继续不生成 DSL。当前没有 Git 子命令级事前 block，不能将 kill 重命名或自动禁止整个 Git。

验证：旧 v1/v2 定义与配置不变，新版本的固定字段在 API 和界面一致；生成时快照冻结命令；旧审批仍可核验。预览的 latest-request 保护避免快速改参时旧响应覆盖新输入。
