# ADR：撤销默认会话 worker，采用能力驱动的执行绑定

2026-10-14 后续收敛决定：四层固定归属已由系统/Agent 基线与真实域运行时增量取代；真实执行映射、共享与停止边界仍保留。 见 [当前合同](ADR-20261014-AgentScope-agent-baseline-runtime-policy.md)。历史验收及既有批准范围不变，本轮仅文档修订。

日期：2026-10-14。状态：采纳为设计合同；完整实现与运行验收未完成。

## 背景

[四层 ADR](ADR-20261012-AgentScope-four-layer-policy.md)原第 4 项及[四层 RFC](../RFC/RFC-20261012-AgentScope-four-layer-policy.md)原 §4 选择“一原生受控会话一个 DSH worker”，并将会话结束、cgroup 回收和其他会话可用建立在独占 worker 上。原生创建/恢复、上下文、工具和并发语义尚未证明，用户也明确要求不改 DSH 原生流程，应按各 Agent 已有能力接入并提取共性。

ActPlane 当前复核源码在单一引擎内以进程标识绑定一个直接活动域，父域约束可继承。逻辑会话与进程不必一一对应；热更新不能补出会话粒度。

## 决定

1. 部分取代 2026-10-12 第 4 项和对应首版 worker 路径；同步改写原条款，审批、生成材料及局部不支持时拒绝的决定保留；四层归属由后续决定收敛。原会话面板第二阶段和无条件停止会话 cgroup 的条款一并修订。
2. 共性对象采用 Connection、AgentInstance、NativeSubject、ExecutionUnit、EnforcementCapability、PolicyBinding。适配器报告原生事实，不用工具标签、cwd、名称猜安全边界。
3. 按机制投影两层基线及适用运行时目标策略，展开共享执行和可用性影响闭包。共享执行的冲突或未知拒绝，不静默取严格/宽松合并，不回退为整个 Agent 应用。
4. 域身份使用 engine_ref + domain_id；独立进程、独立 watcher、原生工具授权、内核父域继承分别描述，不混成“会话隔离”。
5. 会话取消、逻辑结束、停用规则和停止单元分开。只有可信独占且覆盖后代时，才可承诺不影响其他会话的终止；系统故障按明确合同处理并记录真实共享影响。
6. 会话视图区分基线/运行时目标规则与实际加载规则，并显示共享范围、覆盖机制和未支持项。本轮只修改设计文档，不提前将这些视图标为已实现。
7. 热更新提案保留为未实施备选，增加共享范围门禁；不通过本次 ADR 选择其完整引擎实现或声称已验收。

## 取舍

撤销默认 worker 可以避免为了画出四层而破坏原生会话上下文、恢复和工具语义；代价是当前部分 Agent 的工作区/会话配置只能起草与审查，不能独立执行。已有独占原生 worker/沙箱可以成为能力，但须证明实际身份、覆盖和生命周期，不能仅凭进程数量选择方案。

不采纳强制工具代理、动态逐会话换域、最严格共享合并或统一放宽：分别存在原生流程侵入、并发串权、扩大未批准影响或失去保护的问题。并非禁止所有原生授权或独占执行方案，而是在具体适配器具备证据后另案决定。
