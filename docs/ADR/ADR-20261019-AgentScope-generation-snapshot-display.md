# 冻结生成内容，按相同配置版本投影审批

状态：采纳。

对话需要回答当时生成了什么，配置库则展示现在配置成什么。如果历史回复按配置编号读取最新版，编辑名称、参数或发布新版模板都会改写旧轮次的含义。

因此在生成事务中保存最小展示快照，沿用现有请求 JSON，不新增数据库表或可写入口。模板标签和名称也冻结，不能仅保存模板编号后再读取最新定义。保留原有 `items` 引用，兼容后续对话摘要与已有调用方。

审批状态继续来自权威审批对象，但必须匹配生成时的配置版本和作用范围。把待提交状态永久冻结会掩盖后续审批进展；使用最新配置审批则会把不同内容的授权混淆。界面用“生成时配置 · 审批状态对应此配置版本”说明两者关系。没有自动轮询；沿用页面刷新、提交后的重新读取及返回页面时的读取。

旧记录仅通过不可变版本恢复，不能恢复的历史名称或内容直接标为未记录或不可用。读取历史不产生配置、审批、应用或模型调用。代价是保存一份小型展示数据，并对最多十二轮已有历史逐项读取审批状态；本次不扩大历史窗口。
