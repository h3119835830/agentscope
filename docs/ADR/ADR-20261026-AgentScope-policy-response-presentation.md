# ADR：使用结构化展示解决回复冗长

日期：2026-10-26。状态：采纳；隔离验收通过，未发布。

决策：保持生成模型提示词、模板与候选算法不变，通过独立 PolicyAssistantResponse 组件和只读快照投影改善可读性，不让模型为某个测试场景增加规则或生成指定数量的候选。

取舍：摘要展示保留原文前段，其余内容展开查看，不调用额外模型总结，以免改变原分析含义。旧轮次默认收起但完整可查，不删除失败结果，也不将 UI 历史折叠当作丢弃 Agent 上下文。

策略 reason 继续表示触发后的反馈，生成依据使用公开 summary 和实际读文件回执。展示操作采用精确保存版本的 effective_operations，缺失时明确未记录，不从当前目录默认值推断。旧记录的补充投影须先复核版本和 hash，读取不得修改数据库。

仅改变展示与只读响应字段，不批准、加载或验证内核拦截；已应用状态仍来自原有精确版本审批投影。文档和截图区分隔离重放、历史审批状态和生产服务。
