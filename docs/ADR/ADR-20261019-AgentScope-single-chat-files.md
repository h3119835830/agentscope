# 决策：单一对话输入，文件经现有材料合同送达助手（2026-10-19）

按用户要求，Agent 策略助手去掉第二个“补充参考材料”文本框及手工模板工具栏，以一个输入框配附件选择器承载当前需求；发送不暴露模板填参实现词。结果仍由已有模板校验、保存为独立草案，不自动提交或加载。

文件使用已有 materials 合同，不引入通用文件上传服务或主机任意路径读取。浏览器只读明确选择的文本，格式、尺寸和数量先校验；服务端继续按已有材料结构校验。上传文本和受限工作区工具读取分别展示，避免有附件却被标成“未读取正文”。附件不写入长期生成正文存储；代价是刷新后需重新附加文件。

将有限的前文作为独立 conversation 字段传递，替代只有当前一句话的请求。仅接受用户/助手角色、限制长度和轮数，不接受 system 角色或权限字段。此上下文不等于授权，也不恢复过去读取的文件能力。模型可继续澄清或报告缺口，不保证每句话生成配置。

保留现有读文件工具的隔离和权限限制；测试资料权限不对时修正隔离测试目录归属，不放宽正式读取边界、不为个别案例增加路径提示规则。当前受限工具循环的框架保持，未将其描述为新的 Pi SDK 接入。
