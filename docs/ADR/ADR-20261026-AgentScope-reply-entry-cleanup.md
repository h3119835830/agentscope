# ADR：简洁回复不再提供详情入口

日期：2026-10-26。状态：采纳；隔离验收通过。

按用户最新要求，移除助手回复的详情入口，而不是继续折叠表格。服务端仍保留公开分析与原始回执，系统管理端保留完整配置能力；不因此删除审计依据或更改规则。

条件型清单直接展示已有检查参数，不保留“见详情”提示。原结果的历史应用状态沿用权威投影，不能统一写成未加载。

清理使用逐目标核对与可恢复移动。三个看似重复的 PPT node_modules 实为指向共享 Codex 运行库的 junction，仅非递归移除链接；不把各链接遍历出的文件大小重复计算为空间回收。五个测试克隆在确认 origin、可识别测试覆盖及无活动进程后，移入 /tmp/.Trash-0，未删除共享 Git 对象。
